# ADR 0142：上下文栏收到零宽，重开在左轨顶部

## 背景

桌面转写的上下文栏收起后留一条 32px 竖条：上面是展开按钮，下面竖排稿件名和语段序号。按钮放在稿件区头里。竖条占着主区的位置，也和切页面的左轨抢同一级。

层名列自己的收起仍是时间尺上的那一颗，收起后留 16px。那是另一件事，不在本篇。

## 决定

1. **上下文栏收起后宽度为零。** 不留重开条，不竖排当前位置。稿件、层和语段仍在展开的栏里。`--chrome-context-bg` 只涂展开的栏，不再涂一条竖条。
2. **收起和重开在左轨顶部，不在稿件行里。** 只在桌面转写出现。其他页仍用侧栏外缘的把手。
3. **它比左轨页面项低一档。** 页面项仍按 [ADR-0124](./0124-left-rail-current-item-matches-pixso-shell.md)：44×44、图标 20px、当前项实心靛青。这个开关是 28×28 紧凑按钮，图标 16px，颜色用辅助文字色，悬停才回到次级文字。不用页面项的实心底。
4. **中线对齐播放栏里的 28px 按钮。** 播放栏高 61px，按钮在栏内居中。左轨顶留白 4px，所以开关的上边距是 `(61px - 28px) / 2 - 4px`。
5. **重开后回到收起前的宽度、选择和焦点。** 窄窗同样收到零宽，不改成竖条。

## 未选方案

- **继续留 32px 竖条并写稿件名。** 收起之后主区仍被占住。
- **把开关做成和页面项一样的 44×44。** 它不是一个目的地。
- **放在波形左侧的层名列顶上。** 那一列是层名，不是切页面的左轨。

## 影响

- `DESIGN.md` 不再写「收起后留 32px 重开条」。
- 精稿页的对照帧和设计系统页「15 导航与结构」里的收起样例改成零宽；组件页增加「左轨上下文开关」。
- 实现是左轨上的 `.app-left-rail-pane-toggle`。收起时 `--side-pane-width` 为 `0px`。
