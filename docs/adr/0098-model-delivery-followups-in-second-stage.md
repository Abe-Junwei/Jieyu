# ADR 0098：模型交付余项移至第二程，不阻塞第一程

用户 2026-10-30 明确：模型下载、持久管理、转码和随包分发放到后期第二程，当前不做，不阻塞前面的工作。此前 ADR-0086 与 2026-10-14 试用决定把本机转写完整交付列为首发门槛；本篇仅替换这些余项的阶段与阻塞关系，其他存储、安全和格式决定不变。

- 已完成的模型宿主、模拟候选/人工采纳、本机 Whisper 开发闭环保留，以提交 `ef3edf36` 的实际测试为证据；不等于安装包具备开箱即用的本机转写。
- #303/#305 剩余的应用内下载（镜像、进度、取消、断网与哈希）、持久模型设置/版本管理、音频转码与随包引擎/动态库/签名移至第二程 #285，当前不实施，不作为 #250、#275、#282 或第一程其他工作的前置。
- #306 的阈值批量/逐条拒绝计数和其他未完成模型产品收口同样留作后续模型队列；当前已验收的逐条人工采纳不重复开工。保留默认关闭与自用收口，不自动打开或删除开关。
- #303/#305/#306 保持 open，区分已完成证据与未实施余项；不把延期当验收通过，不自动关闭单库总计划或发布检查单。
- 第一程按现有剩余队列推进反馈/诊断 #312、示例产品入口 #313 和桌面测试/CI 替代 #329/#280；本次只更新规划与 issue，不启动它们。安装、Windows、升级与真实系统垃圾箱沿既有后移决定处理。

协议与写入合同仍按 ADR-0057/0094，模型身份、候选不落库、人工采纳事务、迟到结果保护和 user_version 27 不变。首发平台与许可要求在真正分发相应能力时仍需验收，不能用开发 CLI 的通过结果冒充。
