# ADR 0139：桌面文本语段用纸色和短标记

## 背景

贴在一起的空文本语段没有边界。整行通高线和每张卡一个盒子都会把文本轨画成标注软件的层。选中若再用 `--brand-tint` 加输入焦点晕，卡片会像表单控件。

## 决定

1. **播放头只留在波形画布里。** 文本轨不画播放头。
2. **相接才画短标记。** 同一轨上前一段的结束时间与后一段的开始时间在整数毫秒上相等时，在行高中部画 1×14px、`--text-tertiary` 的标记。有时间空隙、或孤立段的外端，不画。拖边界时，已有的拖缝盖住这个标记。
3. **三态。** 有段但没选中：无边、无投影；空段仍用很淡的空底。选中但没在输入、以及正在输入：都是纸色 `--surface-panel`、4px 圆角、1px 边（亮 `#DCDCDC`，暗 `#393937`）和很轻的下投影（亮约 3.5% `#3C4043`，暗 6% 黑，模糊 5px）。输入只多一个插入符，不再加淡墨晕，也不改成品牌浅底或中性灰底。
4. **跳过处理的斜纹保留。** 层拖动的品牌浅底和拖建预览也不改。

## 未选方案

- **改写 [ADR-0117](./0117-active-segment-uses-input-focus-chrome.md)。** 那次决定保持原样。桌面文本卡改走本记录。
- **整行通高分割线，或给每张卡加框。** 这是 Praat / ELAN 的层线，不是这段要的边界。
- **选中用品牌浅底或中性灰。** 有边之后，纸色就够把选中和未选中分开。

## 影响

- 标记由同一轨上的时间算出来，不能只靠相邻空段的 CSS。
- `DESIGN.md` 里桌面文本卡的选中和输入改记本决定。
