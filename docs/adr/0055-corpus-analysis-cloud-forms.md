# ADR 0055：语料分析可以把词形发给用户自选的云端模型

## 状态

accepted。

## 背景

语料分析要能讨论词形本身。同日曾定过「云端只见 gloss、词类、次数和行 id」。用户随后改了这个决定：选定云端模型时，词形和转写可以发出去。例句仍必须来自本机已存的行，不能来自模型写的字符串。

## 决策

1. 用户选定的云端模型可以收到当前文稿里的词形和转写，用来分析词形。外发仍走 A9 脱敏。
2. 复制正文里的例句按工具结果的行 id 从已存行填回。主张里不带词形字段。对不上本次工具结果的主张删去；全部对不上则不出正文。
3. 这条只覆盖语料分析这条工作流。不把本机模型或微调设为默认。不设写作工作区。

## 后果

文献、网页和外部语料仍是后面的证据源，不在本决定里接上。浏览器构建不拉起本机文献进程。
