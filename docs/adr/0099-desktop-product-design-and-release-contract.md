# ADR 0099：桌面产品设计与首发验收合同

## 背景与效力

用户于 2026-11-01 对照 PRODUCT、Penpot 与 Electron 代码完成逐项访谈并确认全部范围。本文记录产品决定，不表示设计精稿、实现、性能或发布验收已经通过。Penpot 现有 00–18 是视觉与局部交互基线，新增业务板以本文编号为验收指针。

本篇将完整专业词典编辑器和专业查询语言加入首发阻断条件，局部替换 ADR-0086 关于这些能力冻结或第二程的限制；不是其余新功能全面解冻。ADR-0098 后移的模型下载、持久模型管理、转码、随包分发与其他模型余项仍后移，模型是否默认可用以代码及实际交付为准。

本文关于建议持久保留的产品要求局部替换 ADR-0094 的临时候选不保留要求；建议仍不得未经采纳进入正式转写或分析。冻结格式不得直接补列，持久化方案须另行 Research、SDD 与格式决策。本文关于义项删除前迁移／明确解除的用户操作准入，优先于 ADR-0090 允许直接删除并遗留失效核心词义链接的产品入口规则；其他自定义引用与失效身份规则不变。其他 ADR 继续有效，旧正文保留。

## 已确认合同

### R01 范围与事实标识

规范负责 PRODUCT 与已接受 ADR 的完整首发桌面验收，明确区分设计要求、Electron 可达实现、待实现、待验证。浏览器实现或序列化工具存在，不等于 Electron 已交付；每项验收必须附入口、数据链、失败状态和实际证据。
完整专业词典与专业查询语言未交付时不能通过首发，不以隐藏入口或默认关闭冒充满足要求。其余条件功能按实际启用边界呈现。

### R02 统一壳与自动保存

项目、稿件、层、片段上下文跨工作区保持；词条与检索结果可以返回原片段。普通编辑自动保存；写入中或失败保留草稿，跨项目或关闭前阻止离开，提供重试和明确放弃。删除、合并、批量迁移等破坏性操作例外：先预览影响并确认，再作为一次完整操作提交，失败不留半份结果。

### R03 正文变更与复核

正文自动保存后，旧分析保留为可查看、可恢复的历史，当前分析标为待复核。默认排除其分析内容进入有效分析检索、统计、AI 上下文和普通导出；可显式查看／筛选待复核项，原始转写仍可检索与导出。项目备份保留研究历史，不受普通成果导出的过滤规则替代。
复核逐项展示旧分析与新原文对应，保留有效项，人工修正失配项，通过边界与关联校验后才提交生效；不允许一键把不合法旧边界当作有效分析恢复。

### R04 时间轴与 IGT

时间轴按说话人／层区分轨道，容纳合法跨轨重叠，主要编辑句段与时间边界；不能把所有重叠一概拒绝。逐句 IGT 是词／语素／gloss 的主要编辑入口，按对应关系排列，义项与备注在检查器处理。验收使用长词、空 gloss、多语素、多语言释义及多说话人重叠合成材料。

### R05 专业词典与引用

覆盖现有数据模型全部可编辑字段，而非仅词头与单释义；系统生成身份、派生值不因此变为任意可编辑字段。提供候选但由用户确认具体义项；无匹配可就地新建并关联，已有绑定不自动替换。
删除／合并被引用义项前展示影响范围，须迁移到指定义项或明确解除引用后才完成，保留例句和标注内容。普通字段自动保存；破坏性操作按 R02 确认与完整提交。

### R06 专业查询与结果

支持词序、相邻关系、跨层约束和复杂组合；跨片段必须限定同一稿件内的相邻范围或时间窗口。可视化条件构建器与文本查询对应，提供语法校验和错误定位。合法文本超过构建器表达能力时保留原样并可执行，构建器只读展示不支持部分；用户明确确认简化后才能回到可编辑构建器，不静默丢条件。具体语法、算子和执行实现另经 Research 与 SDD，设计不自创未验证语法。
同片段多次命中合并为一条片段结果，显示上下文、对应 IGT／层和全部命中；跨片段命中显示完整范围、相关说话人与层，可播放、定位原片段。

### R07 查询与写入互斥

启动前先保存草稿，等待已有写入完成；保存失败不启动。执行期间禁止修改相关语料并暂停新写入，AI 可保留候选但不得采纳写入。完成立即解锁，后续语料变化提示结果可能过期，跳转核对目标有效性。
始终可取消；显示正在取消，确认执行停止、解除写入锁后才继续编辑或切项目，不能仅丢弃返回值却留下后台执行或锁。锁粒度、崩溃释放、长任务取消与性能需实施前专项设计和故障验证；本文不指定全项目锁实现。

### R08 AI 审核、持久建议与离线边界

建议可编辑，可逐项或批量采纳；批量作为一次完整操作，冲突不写入且保留建议。建议随项目保存，切页／重启可继续审核或明确放弃；重启后运行任务标中断，不自动重跑，采纳前重新校验版本。建议不是正式分析或转写。
无网络、无 API Key 时，手动转写、标注、专业词典、专业检索、本地导出仍可完成。云端 AI 明示发送范围，由用户主动启用；本地模型单独标识，不把开发 CLI 跑通视为安装包开箱可用。

### R09 删除与恢复

先展示影响范围，确认后保存草稿、停止相关任务，确认停止后再软删除；任一步失败不生效。已删除列表明确区分稿件与录音，恢复前展示恢复依赖、不会恢复的同录音稿件与保留期限。90 天保留、实际提醒后至少 7 天、系统垃圾箱确认／失败／未知、重新登记和旧备份责任沿 ADR-0087/0096，不重定义为到第 90 天自动删除。

### R10 项目、导入、导出与备份

有效项目在媒体缺失时仍可打开，只禁用相关播放并提供重定位；备份失败持续提示可重试。锁冲突、不兼容项目格式阻断打开。备份恢复为副本，与当前项目切换仍守 R02。
外部标注导入先预览层角色映射、媒体绑定与冲突，必填歧义解决后一次提交；失败不留半份稿件，原文件保留。普通成果导出、项目交换包、含媒体备份分别说明范围与恢复用途。格式清单根据 Electron 端可达路径和实际往返／损失证据确定，不因旧浏览器有工具就承诺支持。损失事前具体展示，可返回修改选择，明确确认后生成并附报告。

### R11 窗口与无障碍

收窄或字体放大后保留主编辑区与导航轨，先收检查器再收上下文栏；提供明确重开入口并保留选择、恢复焦点。核心流程全键盘可完成、焦点可见并正确返回、状态不只靠颜色。明暗对比、字体放大、减少动态均实测，例外记入验收，不以开关存在宣称通过完整 WCAG 符合性。

### R12 录音起点

首发以导入已有录音为必需起点；已有段落录音按实际能力验收，完整田野录音采集不作首发阻断。不由此隐藏已有效交付功能，也不新增连续采集产品承诺。

## 成熟方案边界与后续实施

- 词典适配仓库已有 DMLex 模型与 [OASIS DMLex 1.0](https://docs.oasis-open.org/lexidma/dmlex/v1.0/os/dmlex-v1.0-OS.html)，不另造词条模型。
- 查询参考 [ELAN 多层查询](https://www.mpi.nl/tools/elan/docs/manual/Sec_Multiple_Layer_Search_Tab.html) 的层与时间约束，以及 [ANNIS AQL](https://korpling.github.io/ANNIS/4/user-guide/aql/) 的顺序、相邻与层关系。仅借鉴成熟表达与交互；未选择引擎、语法或新增依赖，不能声称已兼容 AQL。
- 不复用旧浏览器页面作为 Electron 交付证据；复用其序列化和领域逻辑须通过实际数据链验证。
- 执行门槛见[首发设计验收清单](../execution/release-gates/desktop-product-design-acceptance.md)。代码实现仍按仓库 Explore → Research → SDD/Plan → Implement → Verify 分片，不在本次文档与 Penpot 调整中实施查询引擎或改冻结格式。
