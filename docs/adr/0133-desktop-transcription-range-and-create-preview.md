# ADR 0133：桌面转写区分已有语段、拖建预览与文本卡焦点

## 背景

恢复波形与文本轨拖建后，同一时间窗可以同时对应转写和翻译卡。如果波形选区、文本卡焦点和未提交预览复用相同的强调样式，用户很难判断正在操作哪张卡、语段是否已经建成。不透明选区也会削弱波形本身的可读性。

## 决定

1. 桌面转写的波形选中范围以透明主题色标示，不画上下或左右实线。已有未选中段使用淡中性色和两端细线。局部替代 ADR-0115 的波形选区样式，不改播放头和概览。
2. 只有尚未提交的创建预览使用滚动虚线。波形与目标文本轨表达同一时间范围；系统启用减少动态效果时保留静态虚线。成功后回到普通选中态，取消或未创建时撤掉。预览不改变 ADR-0132 的创建路由、时间段或正文存储。
3. 一个波形选区可以对应多个文本层，但文本轨同一时刻只有一张焦点卡。焦点切层不等于切换时间范围；卡片焦点仍沿用 ADR-0117，不能因波形选区无描边而去掉。

## 取舍

保留选中范围的实线会让已有语段和仅靠边界标示的创建预览更相似；用不透明底色或依赖动画本身区分，则分别牺牲波形可读性和减少动态效果下的可辨识性。透明底与虚线分别承担选中和预览的含义，静态时也能区分。

具体参数与实现对照见 [设计系统 §7](../../design/jieyu-paper/DESIGN.md#7-领域-ui-模式)。
