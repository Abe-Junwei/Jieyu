# ADR 0097：桌面写入口、创建初始化与引用身份

## 状态与背景

accepted。用户于 2026-10-30 逐项选择并最终确认四项合同，结束 grill。单库不变量重构结束后，入口 SQL、项目字段初始化、具名来源创建和跨语段自定义引用仍需明确语义。本篇记录已确认取舍，不表示产品实现或验收已完成，不重新打开已删除的重构计划。

## 决策

### 1. 脚本入口按用途和目标限制 SQL

真实项目的脚本写入只走授权的具名业务入口，并遵守项目锁和领域事务。现有文件夹导入入口可以保留，不强迫脚本开启桌面会话或模拟 IPC。页面和外部业务调用仍不传 SQL、表名或事务回调，领域实现可以使用参数化 SQL。
只读诊断可以直接使用只读连接访问已有数据库，不建库、不补表、不修复。直接 SQL 写入仅限脚本自行创建的临时合成项目；此类写探针不能接收真实项目路径进行写入。
选择分层限制，保留诊断与合成故障测试能力；不采用全仓禁止 SQL，也不要求只读诊断逐项增加业务查询操作。检查入口来源及允许能力，不能把 SQL 关键字扫描当成完整保障。

### 2. 项目新建严格初始化，已有项目仍可打开

新项目带必填字段定义时，创建操作必须接受并一次提供全部合法字段值。项目行与字段值同事务成功；缺值或非法值时整次回滚，不自动填默认值，不留下待补全新项目。
已有项目后来新增必填定义而缺值时，仍可正常打开并随后补齐。打开与新建语义分开，不能将初始化检查扩大为拒绝打开已有缺填项目。
选择新建严格、已有可打开，既保护新数据完整性，也不因定义变化将已有研究项目锁在门外。

### 3. 来源独立存在，身份不靠名称或外部编号

结构化来源允许具名创建，录音关联可为空，以后可显式关联。新关联只接受当前项目的有效录音；创建来源不自动复制文件。
来源行与必填字段值同事务初始化，不填默认值；缺值或非法关联整次回滚。每次创建获得新 id，名称和外部编号不作唯一身份；重复时仍独立创建，不自动合并。
来源记录与 sources/ 中保留的导入原文件分开。来源创建不是音频导入或原件复制，不因同名、同编号而猜测两条研究来源相同。

### 4. 自定义引用保留目标身份

同项目跨语段自定义引用按目标身份解释。切分复制字段时，即使原值引用本语段的节点，也继续指向原节点；需要指向副本时必须显式修改。图结构边和 surfaceParts 等结构引用仍按新图结构重映射，与自定义引用分开。
目标被合并或删除后，已有引用保留原身份并标失效，不自动指向保留对象；同 id 恢复后重新校验，同名新 id 不接替。失效引用不计入必填有效基数，也不阻止字段所属旧对象的无关编辑，沿用 ADR-0090。
切分产生的新语段及其复制出的新对象必须满足必填校验。复制后缺必填值或必填引用失效，整次切分回滚；先补齐原对象的字段或引用，再重新切分，不留下待补全副本。
选择保留引用原义，而非随复制静默改指向。代价是需要用户显式调整部分引用；不为未来可能的自动迁移增加通用模式或格式字段。

## 实施与验收边界

- 本篇不修改冻结 DDL、user_version、交换包或引用编码。若后续实现确需改变冻结格式，另立决定。
- 脚本检查须覆盖单双引号、空格、静态/动态加载与别名；合法只读诊断、临时探针和具名导入仍可运行。
- 新项目与来源分别验证缺值回滚、合法值关闭重开读回；已有缺填项目保持可打开，重复来源不被合并。
- 引用验证复制、合并/删除、同 id 恢复、同名新 id，以及必填失败后的整次切分回滚；图结构与自定义引用分别断言。
- 产品修复、新能力和界面接线按各自小切片实施并提供当次证据。决定已接受不等于功能已交付。
