# ADR 0042 — 层名对不上时，日期正文记入丢失

## 背景

[ADR 0038](./0038-eaf-tier-pick-by-content.md) 的正文规则只把语料编号、`<p:>` 和纯数字降成锚点。层名对不上已知记号时，其余正文仍走翻译回退，日期列会变成翻译行。独立的日期层还可能被选成句子层。Tabaq 的 `dt` 已由层名记入丢失；层名是 `when`、`session` 这类未知名字时，同一份日期不会。

录音机型号、自由译文和音标不用正文改角色。Tabaq 的 `tx` 本身是音标，实用正字也像译文。没有一份稳定的型号名单之前，不认录音机型号。

## 决策

1. 只在层名对不上已有记号时看日期。已有记号包括 FLEx 槽位、`ph`、`nt`、录音元数据词干，以及转写、翻译、锚点、词层记号。`tx`、`ft`、`fn`、`dt` 仍按层名归类。已保存的层角色优先。
2. 去掉 `<p:>` 和只含星号的占位后，非空格子里至少五分之四是闭集日期，该层与 `dt` 一样记入 `unmapped-field`，不进翻译行，也不当锚点。形状限于整格：`2013-04-10`、`2013/4/10`、`10/04/2013`、`10/Apr/2013`（月份为英文三字母或全称）。
3. 选转写层时，这种日期层不进入转写候选，也不进入「第一条非空独立层」和最后兜底。角色对话框不列出它。

## 影响

- 父层 `ref`、子层 `tx` 与 `ft`、子层 `when@NOBODY` 全是日期时，句子和译文照常写入，`when@NOBODY` 在丢失清单里。
- 层名是 `tx` 或 `ft` 而正文碰巧是日期时，仍分别是转写和翻译。

## 不采纳

- 用正文把未知层升成自由译文或音标层。
- 用型号字符串认录音机。没有闭集名单之前不加。
- 把日期层写成备注。
- 改 TextGrid、Toolbox、TRS 的「第一条当转写」。

## 回顾

本决定给 ADR 0038 的正文形状补上日期，方向仍是把错层移出句子和翻译，不把陌生正文升成转写。ADR 0038 的其余条款继续有效。
