# ADR 0062：桌面存储的八条决定（2026-10-16 设计树走完）

## 状态

accepted。用户 2026-10-16 在逐张确认的设计访谈里选定，每条都有对应的选项记录。本篇不取代任何已有 ADR，也不改它们的正文。与旧条款冲突时，以本篇和 [ADR 目录的「当前有效条款」](./README.md#桌面存储当前有效条款) 为准。

这是产品和架构决定，不表示工程可以发布，也不表示 D14 可以冻结。冻结仍要求 [0061](./0061-jyd-manuscript-file-audio-stays-plain.md) 列出的几项验证。

## 背景

[ADR-0061](./0061-jyd-manuscript-file-audio-stays-plain.md) 定了文件夹的形状：音频是原文件，一份文稿一个 `.jyd`。之后的访谈又补了几处规则，包括多录音文稿的迁移、备份、同名判断、笔记和关系的归属、跨文稿关系、旧数据的迁移路径，以及存储接口的边界。这些决定分散在对话里，规格和索引里有的已经落地，有的还在旧措辞上。这篇把它们合在一起，免得后面的人再从对话里拼。

## 决策

1. **备份必须带可播放的音频。** 将来替换每日 JYM 的备份，必须包含音频字节（相同哈希只复制一次），并做一次从备份恢复后播放的演练。在这次演练通过之前，[ADR-0046](./0046-desktop-sqlite-project-folder.md) 第 6 条的每日 JYM 快照保持不动，不替换、不并行删除。本篇不批准替换方案本身。
2. **同名判断把隐藏文件算进去。** 「已隐藏/」里的文件参加唯一性检查。导入或改名时发现冲突，提示用户，不自动选择，也不静默重名。隐藏只影响看板显示，不改变同名判断。
3. **`user_notes` 和 `unit_relations` 按行归属。** 每一行看它指向的对象：指语段、词、词素的随所在的 `.jyd`；指项目对象（语言、说话人、正字法）的进项目库。不按整表划定去向。
4. **跨文稿关系一律不存。** 不仅父子链接（[0061](./0061-jyd-manuscript-file-audio-stays-plain.md) 已定），其他类型的 `unit_relations` 也不允许两端在不同的 `.jyd` 里。
5. **已经挂着多条录音的旧文稿，迁移时拆开，先列清单再执行。** 每条录音对应一份新文稿。拆分前列出完整清单，经用户确认后才写入。不自动拆。原文稿 id 的分配、旧关系的处理，由实施规格决定，本篇不定。
6. **旧浏览器数据先导出 JYB 再迁入。** 先在浏览器导出一份带音频的 JYB，再导入桌面端项目文件夹，导入前做容量预检。[ADR-0046](./0046-desktop-sqlite-project-folder.md) 第 2 条「JYB 只在浏览器构建」因此要放宽，其余不变。
7. **存储接口分两类。** 业务操作（写项目库、写 `.jyd`、删除、导入）走存储端口，一次操作一个事务，读回校验，符合 [ADR-0048](./0048-storage-port.md)。弹窗（选文件夹）和订阅（看板变化）走单独的通道，不进事务，也不放进同一个可选的 `files` 对象。调用方只看到当前可用的业务方法。
8. **原型要加 better-sqlite3，但要等批准。** 下一步是写临时目录原型，验证写入速度、强制退出、满盘和关闭后复制。这要新增依赖，先由用户批准，再动代码。

## 影响

- [`docs/execution/specs/card-sqlite-file/design.md`](../execution/specs/card-sqlite-file/design.md) §2 的 `unit_relations` 行要改成本篇第 3、4 条的口径（原写「跨文件的其他关系类型还没定」，已过时）。
- 同名判断的范围在规格里不再待定，统一为第 2 条。
- 迁移的入口在规格里不再待定，统一为第 5、6 条。
- 每日 JYM 备份在规格里保持有效，替换方案仍未批准。
- 旧的"声文稿最多一条音频、可有多份文稿"（[0058](./0058-card-sqlite-file.md) 第 2 节）中的"多份文稿"部分，本篇没有处理。它是否仍成立，需要另外确认。

## 被放弃的备选方案

1. 批准整套合成架构，不分项：被否决。用户要求逐条确认。
2. 备份直接替换成「数据库加音频哈希清单」：被否决。音频字节必须在备份里，且要先通过恢复演练。
3. 跨文稿关系只禁父子链接：被否决。用户选了全部禁止。
4. 旧文稿自动拆分，不先列清单：被否决。用户要求先确认。
5. 旧数据直接从浏览器 IndexedDB 写 `.jyd`：被否决。用户选了 JYB 路径。
6. 存储接口收成一个 `files` 对象，弹窗和订阅也在里面：被否决。用户选了分开。
