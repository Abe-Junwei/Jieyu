# ADR 0002：开放工作台范围

> 2026-10-14：开放门槛清单已从工作区删除。标注、词典、语料库工作台已经开放，「仅转写页开放」不再作为现行口径。分析页仍是 [ADR-0033](./0033-analysis-restricted-workspace-no-transcription-dock.md) 的受限工作台。

## 背景

仓库曾同时保留转写、标注、分析、写作、词典等多个页面名义上的“工作台”定位，但真实落地能力高度集中在转写页，其他页面更多承担规划说明或只读入口角色。

## 决策

1. 标注、词典、语料库已经作为工作台开放。转写页不再是唯一开放工作台。
2. 分析页维持 ADR-0033 的受限工作台，不升格为第二转写台。
3. 新工作台复用既有 controller/runtime，不复制转写页 Orchestrator。
4. 不设写作工作台。历史地址 `/writing` 只转到语料库。

## 影响

1. 标注、词典、语料库按已开放工作台维护。
2. 分析页的边界以 ADR-0033 为准。

## 被放弃的备选方案

1. 按页面平均推进，把多个工作台同时维持为活跃交付面。
2. 先补齐空壳页面，再回头处理转写页耦合问题。

## 后续回顾点

1. 若其他工作台出现稳定的 controller/runtime 复用核，再新增 superseding ADR。
2. 每轮发布前都需要核对该决策是否仍与产品表述一致。
