# ADR 0038 — EAF 默认按正文选转写层

## 背景

[ADR 0036](./0036-eaf-import-is-interchange.md) 第 3 条把没有角色表的外来 EAF 定成「第一条独立时间对齐层当转写」。36 份开放语料里 24 份的第一条是 `ref@说话人`，正文是语料编号或 `<p:>`，句子在子层 `tx`。卡马斯语和多尔干语的根层类型标成不可时间对齐，导入得到 0 条语段。冲绳语的第一条是空的 `document_notes`。多续语的第一条是句段编号。

层角色对话框补不上这个洞。`proposeEafTierRoles` 只在两个及以上无父层时弹窗，默认仍是文档顺序。上述 24 份大多只有一个独立层，对话框不出现。

另外两处把已经读到的句子留在时间轴外面。主转写下、一个父标注只对应一条子标注的 `Symbolic_Subdivision` 被当成词项，巽他语的英语译文和卡希纳瓦语的 `tx` 因此不成层。独立时间边界的翻译层在没有 `mediaId` 时整层跳过，黄金样本 `multi-tier-ipa.eaf` 的英语和汉语不进页面。

[ADR 0037](./0037-interchange-loss-report.md) 第 4 条仍适用于 TextGrid、flextext、Toolbox：没有角色表时第一条当转写。本决定只改 EAF。

## 决策

1. 没有已保存的层角色表时，转写层按正文和层名判断，不按文档顺序。判断是纯函数，放在 `EafService` 旁边。`importFromEaf` 在未传入 `tierRoles` 时调用它。已保存的 `eafTierRoles` 优先，本决定不覆盖用户确认过的角色。
2. 层名和语言类型按非字母边界切开后认这些记号，大小写不敏感：转写 `tx`、`trs`、`transcription`、`转写`、含 `txt` 的句子层；翻译 `ft`、`gls`、`translation`、`free`、`翻译`；锚点 `ref`、`segnum`、`document_notes`、`page_no`、`note`、`notes`、`comment`；词层 `wd`、`mb`、`morph`、`word`、`单词`、`ps`、`gl`。非空正文里至少五分之四是语料编号、`<p:>` 或纯数字时，该层是锚点，即使层名像转写。
3. 转写优先取非空、且不像锚点的转写记号层。锚点层只提供时间。语段时间用锚点或父层的可对齐标注，正文用转写子层按 `ANNOTATION_REF` 对齐的文本。锚点上的非空编号写入已有的父标注注释，不占转写正文。没有转写记号时，退回第一条非空、且不像锚点的独立时间对齐层。再没有，才用今天的第一条独立时间对齐层。
4. 根层类型标成不可时间对齐、但带可对齐标注，子层里有转写记号时，仍用子层做转写。空层不能当转写。
5. `Symbolic_Subdivision` 在「某个父标注下有两条及以上子标注」或层名像词层时，继续做词切分。一个父标注最多一条子标注、且层名像转写或翻译时，按短语层处理，不折进词项。
6. 短语级层里有两个及以上非空转写候选，或没有转写记号且独立短语层不少于两个时，才打开现有层角色对话框。对话框列出短语级层，含 `tx` / `ft` 子层，不含词层和语素层。默认值用第 2–4 条。判断唯一时不弹窗。角色仍写入现有文稿元数据 `eafTierRoles`。不新增 Dexie 版本，不新增 controller，不新增 feature flag。
7. 独立时间边界的翻译层，在本文稿没有媒体、但本次已经写下语段时，按现有时间重叠挂到这些语段。不新建 0 时长音频。没有语段可挂时，仍整层跳过并计入 `dropped-translation`。
8. 选中的转写层不是第一条独立时间对齐层时，丢失清单加一条 `guessed-tier`，名字是选中的层 id。已经写入的句子不再另报丢失。

## 影响

- 解析规则在新的纯函数。`useImportExport.importHandlers.ts` 只消费解析结果，不把选层判断写进该文件。
- 解语自己导出、层名为 `default` 且带角色表的文件，行为不变。没有角色表的 `default` 加独立英语层、汉语层，仍是 `default` 转写。
- 木雅语这种根层就叫转写、子层是自由翻译的文件，转写层不变。
- TextGrid、flextext、Toolbox、TRS、LIFT 的默认归类不改。

切片和验证见 [EAF 默认选层](../execution/plans/EAF默认选层-2026-09-28.md)。

## 不采纳

- 用统计模型或外部语种识别给层打分。
- 为 DoReCo 单独写一套导入器。
- 把 `ref` 编号当成转写正文，只在完成提示里解释。
- 没有媒体时新建 0 时长音频，以便独立层有处可挂。ADR 0036 第 7 条仍然有效。
- 改 flextext 的短语级译文条数，或把 LIFT `morph-type` 映射进 DMLex。

## 回顾

若记号表把解语导出的普通层名判成锚点，先收紧记号，不回到文档顺序。本决定取代 ADR 0036 第 3 条里「没有角色表时第一条独立层当转写」，以及第 10 条里「凡是主转写下的 `Symbolic_Subdivision` 都是词层」。ADR 0036 的其余条款继续有效。
