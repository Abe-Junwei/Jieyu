# 仓库现状

产品形状以本页为准。flag 默认值、schema 版本和行数以代码与当次 `npm run check:architecture-guard` 为准，不写在这里。

- 本检出可运行的是浏览器应用：`src/main.tsx` 挂载，存储出口是 Dexie（`src/db/index.ts`）。它不交给用户；Electron 骨架跑通后只作开发与测试，之后删除（ADR-0063、ADR-0064）。
- 桌面外壳骨架在 `electron/` 与 `src/desktop/skeleton/`：一次临时 `project.sqlite` 写入读回、项目锁、同步盘警告、媒体 Range、密钥不进渲染进程（ADR-0059，#276）。它还打不开真实项目。文件夹里放什么以 ADR-0061 为准（音频原文件、一份文稿一个 `.jyd`）；交换包和每日 JYM 备份仍是 ADR-0046 第 2、6 条。哪一条有效见 [ADR 目录](../adr/README.md)。桌面构建剔除协作（ADR-0047）还没接到这条外壳上。存储接口见 ADR-0048，本检出的实现是 Dexie（`src/db/storagePort.ts`），SQLite 产品实现是 #275。`scripts/card-file-portability-check.mjs` 只用 `node:sqlite` 看文件行为，不是桌面验收。快照范围见 ADR-0034。未完成接线见 [试用地图](../wayfinder/trial-handoff/map.md)。
- 标注、词典、语料库已经开放。分析页保持受限，不是第二张转写台（ADR-0033）。不设写作工作台。`/writing` 转到语料库（ADR-0002）。
- 时间轴运行态以 ADR-0009 为准。`timelineMode` 只作导出标签。
- 声学留在转写页。未做项以 [主路线图](../execution/plans/解语-主路线图-master-roadmap-2026-06-01.md) 为准。
