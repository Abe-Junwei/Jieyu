# 术语表（Layer-first）

> 文档角色：长期有效的术语与边界文档。

## 产品词
- **项目**：一份研究材料的整体，在代码里对应 `textId`；桌面版里一个项目就是一个项目文件夹。
- **项目文件夹**：桌面版存放一个项目的磁盘文件夹，是该项目数据的真源。
- **项目包**：JYM 或 JYT 文件，只用于交换和归档，不是日常存储。
- **文稿**：项目里的一份标注文档；一个项目可以有多份文稿。
- **工作区**：只指界面布局，不指数据。

## 目标
- 统一术语，减少 layer / tier / track / lane 混用。
- 明确边界：业务域 layer-first，互操作域 tier-specialized。

## 当前产品语义
- 时间轴运行态以 ADR-0009 为准。`timelineMode` 只作导出标签。
- 建段、拆分、合并、删除的写入去向由 `src/pages/timelineUnitMutationDispatch.ts` 决定：视图行是 unit 走 unit-doc；当前层是 independent-segment 或 time-subdivision 走 segment-layer。
- Layer：内容层（转写/翻译/标注）。独立时间边界可以落在 segment-layer 路径。
- Track：时间轴显示模式（single/multi-auto/multi-locked），仅影响展示与编辑避让。
- 行（Line / Lane）：时间轴 UI 行与行号分配（锁定、重排、折叠等），不引入第二套时间语义。

## 术语定义
- Layer：业务层（转写层/翻译层），用于日常编辑、筛选、统计、权限。
- Tier：语言学/外部格式结构层（EAF/TextGrid/层级约束），用于导入导出和结构校验。
- Track：时间轴显示模式（single/multi-auto/multi-locked）。
- 行（Line / Lane）：时间轴 UI 行与行号分配（锁定、重排、折叠等）。
- Utterance：语段实体（时间边界与说话人上下文）。
- Segment：独立时间边界的编辑对象。当前层为 independent-segment 或 time-subdivision 时，写入走 segment-layer。

## 边界规则
- 业务域（hooks/components/pages）默认只使用 layer 语义。
- tier 语义仅允许出现在桥接/互操作/语言学校验模块。
- 新增业务字段命名统一使用 layerId；Link 语义（`LayerLinkEdge`）统一使用 `linkedTranslationLayerId`；不新增 tierId 作为业务字段名。
- tierId 仅用于 tier 原生语义或桥接上下文。

## 代码落地约束
- TierDefinitionDocType 的导入受静态检查约束（见 scripts/check-tier-boundary-imports.mjs）。
- TierBridgeService 是 tier 概念对业务域暴露的主要边界之一。
- 互操作特例文件（导入导出/快照恢复）允许保留 tierId：`useImportExport`、`useTranscriptionSnapshotLoader`。
- tierId 仅允许在互操作/桥接/测试代码中出现；业务域（hooks/components/pages）禁止新增 tierId。
- 独立 segment 与 time-subdivision 的写入只经 dispatcher 的 segment-layer 路径，不要在页面层另开一套写入。

## 阶段封版标准（术语与边界）
- `npm run check:tier-boundary-imports` 通过。
- `npm run check:tierid-diffusion` 通过，且 `offBoundaryMentions=0`。
- 新增代码在业务域仅使用 layer 语义（`layerId` / `LayerLinkEdge.linkedTranslationLayerId`）。
- 若需保留 tierId，必须在 PR 说明中标注“互操作特例”并给出回收计划。
