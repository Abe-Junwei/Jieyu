# 波形顶栏与克制阴影：官方设计系统调研

调研日期 2026-11-20，只用各产品一方文档、一方设计系统与产品自有源码。本页只给建议，不改代码、token 或其他文档；采纳后写进 ADR / `DESIGN.md`，本页随即删除（ADR-0051）。

## 现有合同

- 工作平面、面板、卡片不加投影；浮层用发丝边加 `--shadow-popover` / `--shadow-float` / `--shadow-modal` 三档（`DESIGN.md:239`；[ADR-0104](../../adr/0104-type-space-shadow-and-ink-only-series.md) 决定 3）。
- 贴边非模态抽屉：1px 分隔线、圆角 0、不加阴影；脱离边缘悬在画布上的面板才用 `--shadow-float`；模态用发丝边加 `--shadow-modal`（`DESIGN.md:283`）。
- 因此"波形上方顶栏加阴影"与现行合同不一致，除非它被定义成"滚动内容压在它下面时才出现"的状态。

## 一方证据：来源证明了什么

| 来源（访问于 2026-11-20） | 来源证明 | 对应位置 |
| --- | --- | --- |
| Apple HIG · [Scroll views](https://developer.apple.com/design/human-interface-guidelines/scroll-views)（数据：[JSON](https://developer.apple.com/tutorials/data/design/human-interface-guidelines/scroll-views.json)） | "只在滚动视图位于浮动界面元素之后时才用 scroll edge effect"；它"不是装饰"，不遮挡也不变暗，只让控件保持可辨；"每个视图一个"；分栏里每个窗格可各有一个，高度保持一致；控件多的顶栏用 hard 样式（更不透明的分隔）。 | 固定顶栏 vs 滚动内容 |
| Apple HIG · [Sidebars](https://developer.apple.com/design/human-interface-guidelines/sidebars)（[JSON](https://developer.apple.com/tutorials/data/design/human-interface-guidelines/sidebars.json)） | 侧栏、工具栏、标签栏在新系统中可以浮在内容之上。证明：只有"浮"才需要层级线索。 | 侧栏边界 |

## 来源共同点（来源显示的）

1. 层级档位很少，且按"离表面多远"命名，不按组件命名（Material、Fluent、Primer）。
2. 静止的固定条默认平的；抬升由滚动内容在其下方这一状态触发（Material `liftOnScroll`、Apple scroll edge）。
3. 越小越近越柔：菜单/Tooltip 最小，模态最大（Fluent、Primer）。
4. 在 Windows 风格里，边界用描边而不是阴影（Fluent）。

## 对解语的推断（非来源原话）

| 位置 | 建议 | 理由 |
| --- | --- | --- |
| 波形上方固定顶栏 | 静止：1px 分隔线，无阴影。仅当下方内容（波形或轨道列表）纵向滚动并压到顶栏下时，加一道很淡的底边阴影，取 `--shadow-popover` 或更淡的专用值，滚回顶部即消失。 | 同 Material lift-on-scroll 与 Apple"仅在内容滚到浮动元素后"。若不引入滚动态，则应撤销阴影，回到合同。 |
| 浮动传输条 / 悬浮操作 | 只有脱离边缘悬在波形上时才用 `--shadow-float`；贴在顶栏或底栏内的传输控件不加。 | 与 `DESIGN.md:283` 一致。 |
| 侧栏边界 | 保持 1px 分隔线，不加阴影；侧栏浮起为临时抽屉时仍遵守"贴边不加阴影"。 | Apple 只在"浮"时需要线索；现行合同已定。 |
| 菜单、popover、Tooltip | `--shadow-popover`，加发丝边。 | Fluent/Primer 小档。 |
| 悬浮面板（备注、层操作） | `--shadow-float`。 | 同上中档。 |
| 模态 | `--shadow-modal` 加发丝边。 | Primer"模态必须用大档"。 |
| 输入框、按下态 | 不用外阴影，用既有焦点环（`--focus-ring`）。可选 inset，不在本次范围。 | Primer inset 规则。 |
| 不加 | 波形画布、轨道行、卡片、列表行、普通按钮、已有分隔线的面板头。 | 合同已禁，且多数来源只给"抬升的物体"阴影。 |

## 采纳前要核对

- 顶栏阴影来自哪个选择器，是否带滚动态；用 `scrollTop > 0` 或 `IntersectionObserver` 切换 data 属性，不用常驻阴影。
- 暗色下阴影不可见，抬升态需补 1px 分隔线增强（Fluent 提示按表面亮度调不透明度）。
- 若采纳"滚动抬升"，要在 `DESIGN.md` 把它写成合同里的唯一例外，并补 ADR；否则撤销顶栏阴影。
