# EAF 导入对齐改进

决策见 [ADR 0036](../../adr/0036-eaf-import-is-interchange.md)。八个切片已经写进解析和导入。本文保持 `active`，合并前不标完成。

`.jyt` / `.jym` 继续做整库原 id 备份。EAF 只交换带层角色和标注 id 的文本。没有 `.jy`。

实现落点：`src/utils/eafTimeUnits.ts`、`src/utils/eafTierRole.ts`、`src/utils/eafImportAlign.ts`、`src/services/EafService.ts`、`src/hooks/importExport/useImportExport.importHandlers.ts`、`src/hooks/importExport/useImportExport.additionalTierHandlers.ts`、`src/hooks/importExport/eafTranscriptionTierWrite.ts`、`src/components/EafTierRoleDialog.tsx`。生产导入由 `useTranscriptionImportExportInput` 打开层角色确认；直接调用 `useImportExport` 的测试不弹窗。第 1 节保留改前读法，用来对照这些切片。

## 1. 现在读什么

`importFromEaf`（`src/services/EafService.ts`）返回：媒体文件名、其余 `MEDIA_DESCRIPTOR` 的文件名 / MIME / URL、时间轴元数据、语段、附加层、默认 locale、层 locale、参与者、转写层名、语言显示名、层约束、层正字法元数据、用户笔记。

| 来源                                                 | 现在                                                                                         |
| ---------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| 第一条 `MEDIA_DESCRIPTOR` 的文件名                   | 读。没有当前媒体且不是 `unknown.wav` 时，`useImportExport.importHandlers.ts` 建 0 时长空音频 |
| 其余媒体描述                                         | 只存文件名、MIME、URL，不存字节                                                              |
| `LANGUAGE` 的 `LANG_ID` → `LANG_LABEL`               | 只作显示名                                                                                   |
| `LINGUISTIC_TYPE` 的 `TIME_ALIGNABLE`、`CONSTRAINTS` | 映射成 `independent_boundary` / `symbolic_association` / `time_subdivision`                  |
| `TIME_SLOT@TIME_VALUE`                               | `parseInt` 后除以 1000。非有限值已丢弃。不读 `TIME_UNITS`                                    |
| 第一条无 `PARENT_REF` 的独立时间层                   | 成为语段。标注 id 放进结果，写入时抄到 `externalRef`，语段 id 仍是 `newId('utt')`            |
| 其后的独立时间层                                     | 进入附加层                                                                                   |
| 主转写层下的 `Symbolic_Subdivision`                  | 词，`form.default`。注释语言写死 `eng`。第一条注释获胜                                       |
| `TIER_ID="notes"`                                    | 按起止 ±50ms 对语段                                                                          |
| 译文                                                 | 必须落在语段内 ±50ms。附加层对不上独立层名或 key 就丢掉；没有 `mediaId` 时整段跳过           |
| `PARTICIPANT`                                        | 按规范化名字查找或创建说话人                                                                 |
| `jieyu:project-meta:timeline`                        | 合并时间轴模式、逻辑时长、时间基标签。坏 JSON 跳过，导入继续                                 |
| `jieyu:layer-meta:{tierId}`                          | 语言、正字法、脚本、地区、变体、bridge                                                       |

不读：受控词表、`LEXICON_REF`、ELAN `EXTERNAL_REF`、说话人方言、原层 id / 语段 id / 词条 id、`layer_links`、词类。词条走 `LinguisticService.lexemes.matchOrCreateByForm`。同一文件导入两次会插入两套语段。

## 2. 为什么头部不够

时间在 `TIME_ORDER`。父子在 `PARENT_REF` 和 `ANNOTATION_REF`。层角色不能从文档顺序推断。往返身份在标注 id 上。头部解语属性只覆盖正字法和逻辑时长，而且只在名字对得上时才读。

## 3. 切片

无角色表的文件保持「第一条独立层当转写」。下表的行为变化都要有失败测试再改。纯函数放在 `EafService` 旁边。`useImportExport.importHandlers.ts` 已超过一千行，只负责调用和写入。

### 3.1 再导入按连接键更新

连接键是当前文稿、外部层 id、标注 id。三者都对上则更新起止、正文、说话人，保留解语语段 id。缺标注 id，或对不上，才 `newId('utt')`。

验证：同一份解语导出的 EAF 导入两次，语段条数不增加，正文更新能读回。两份文件碰巧都有 `a1` 时，不串到另一篇文稿。

### 3.2 时间单位

读 `HEADER@TIME_UNITS`。缺省或无法识别时按毫秒，并记一条诊断。换算：

| 值              | 秒                |
| --------------- | ----------------- |
| `milliseconds`  | 值 / 1000         |
| `PAL-frames`    | 值 / 25           |
| `PAL-50-frames` | 值 / 50           |
| `NTSC-frames`   | 值 × 1001 / 30000 |

验证：`PAL-frames` 且 `TIME_VALUE="25"` 的语段起止是 0 和 1。缺属性时与现在的毫秒结果相同。无法识别的单位不抛异常。已有的 fast-check 仍要求时间为有限数。

### 3.3 先按标注引用挂接

笔记和译文优先用 `ANNOTATION_REF` 找到父标注。没有引用时才用 ±50ms。父标注本身还没有时间时，不靠时间窗猜。

验证：父标注 0–1s、子标注引用它但时间戳写成 10–11s，仍然挂上。没有 `ANNOTATION_REF` 的旧文件，±50ms 结果与现在相同。

### 3.4 注释语言跟层

词注释和语素注释的语言键取该层 `LANG_REF`，没有则用 `DEFAULT_LOCALE`。层上没有语言时保留一条诊断，键用项目分析语言，不用 `eng` 占位。`LANG_ID` 对不上 BCP 47 时原样保存 id，不编造代码。

验证：`LANG_REF="cmn"` 的注释层写入 `gloss.cmn`。没有语言属性时结果里没有 `eng`。

### 3.5 层角色表

角色只有四种：转写、译文（带语言）、笔记、排除。

解语导出把角色写进现有 `jieyu:layer-meta:{tierId}`。外来文件没有这张表时，归类与第 1 节相同。用户第一次导入时选一次，记在现有文稿元数据。放不进去就停，另写 ADR，不在这个切片加 Dexie 版本。

有表之后：每个「转写」独立层各自成转写层。层匹配顺序是外部层 id，然后语言和正字法，然后显示名。`PARTICIPANT` 当代码，不用显示名模糊合并。

选择放在现有导入确认里。文案走 `dictKeys`。不新增 feature flag。不为此新增 controller 时不写 SDD；一旦新增，先补 `docs/execution/specs/eaf-import-alignment/`。

验证：无表的双独立层文件，仍是第一条转写、第二条附加。带表且两条都是转写时，得到两个转写层。排除角色的层不产生语段。同一 `TIER_ID` 再导入时更新原层，不按英文名新建。

### 3.6 媒体只挂已有文件

本文稿里已有同名媒体则绑上。没有则语段不带 `mediaId`，完成信息里说明缺文件。不建 0 时长空 `Blob`。字节仍只来自 `.jym`。

验证：时间轴已有 `speech.wav` 时，EAF 里的同名描述绑到它，媒体行数不变。没有同名文件时，媒体行数不变，语段仍写入。

### 3.7 词条 id 只在解语写过时往返

导出在词标注上写入词条 id。导入见到该 id 且库里仍有这条词，就复用，不按词形另建。没有该 id 的文件继续 `matchOrCreateByForm`。

验证：导出再导入后，`token_lexeme_links.lexemeId` 不变。只有词形、没有 id 的 EAF 仍按词形匹配。

### 3.8 装不下的结构记在父标注

受控词表、说话人方言、受话人写成父标注上的类型化注释，类型是小枚举，正文可见。不进新表。注释不是往返键；往返键仍是 3.1。

验证：带受控词表的标注导入后，父语段注释能读回原值，语段条数不因此增加。

## 4. 借鉴与不借鉴

借鉴 flibl 的四点：项目级层角色，而不是文档顺序；标注 id 放在用户不随手改的字段；参与者是代码；装不下的结构记在父标注。

不借鉴：手改 JSON、Python 命令行、把 flibl 收成依赖、用字符类正则做主词切、只认 `Symbolic_Association`、儿童语料的 target-utterance、往返时必须留着原 EAF。

## 5. 非目标

- 把 EAF 做成 Dexie 图，或承诺与 `.jyt` / `.jym` 同一保真度。
- 恢复外来文件的层 id、语段 id、`layer_links`。
- `LEXICON_REF`、ELAN `EXTERNAL_REF` 升成一等字段。
- AFL++、GitHub Taskflow。
- 词典义项 `indicator` 的编辑界面。本计划不改词典。
- 主路线图里另列的会话隔离、Word 导出、类型化关系、语义域浏览、图片、词汇关系图、DMLex RDF/XML/SQL，以及语料库 / MCP 开关。

## 6. 落地顺序

3.1 → 3.2 → 3.3 → 3.4 → 3.5 → 3.6 → 3.7 → 3.8。前四刀不改变无表文件的层归类。3.5 是第一条需要导入确认界面的切片。每一刀单独验证后再进下一刀。本文件在代码落地前保持 `status: active`。
