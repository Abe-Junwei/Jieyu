## 2026-11-15 FLEx × ELAN 社区需求统筹（102 条来源归属与边界）

对照 2026-11-15 调研基线（82 FR + 20 EF；另有 EC-001/002/004/005/006 共 5 条待核未讨论不纳入），以 [ADR-0099](../../adr/0099-desktop-product-design-and-release-contract.md)、[ADR-0100](../../adr/0100-desktop-engineering-contract.md) 与上节「唯一执行队列」为基线统一吸收：**不另立 102 张工单或平行路线图，不借需求映射扩大第一程首发阻断范围**；设计确认只定语义边界与后续落位，实施仍逐片遵循 Explore → Research → SDD/Plan → Implement → Commit。

### 七条拍板硬边界（不得在后续切片中被简化覆盖）

1. **EF-017 不做（不列远期）**：不做按参与者复制层结构；维持 [ADR-0085](../../adr/0085-desktop-project-one-sqlite.md) 说话人属项目、层属文稿、语段 `speaker_id` 关联的共享层模型。
2. **EF-019 无外部词典映射导入规划**：不做外部异构词典导入向导（不恢复 #537）；保留 ADR-0100 E12/V17 与 #311 面向 FLEx 的固定受限子集 LIFT 0.13 导出→外部保存→重导往返核验，不对外承诺通用外部词典导入。
3. **EF-014 识别/对齐候选两条分流（对齐 ADR-0099 R08 / ADR-0100 E11）**：目标位置**已有任意人工内容**（不缩窄为仅保护「已确认」人工内容）时原样保护，仅接受后写入；**无人工内容**时在工作层轨道原位呈现并标「待确认」（可就地编辑或确认转正），底层仍与正式有效语料隔离，确认前默认不进入有效查询、统计或普通导出。
4. **EF-018 一分为二（对齐 ADR-0100 E06）**：①「合并上级时保留下级内容、顺序与已有时间，只调整上级归属，不给无时间子标注编造时间，层级冲突时阻断合并」并入第一程**切片 1b/2** 合段安全边界（现行 `src/db/desktop/unitSpan.ts` 的 `mergeUnits` 会删被合并段子树，禁止直接冒充满足）；②「自动扫描推荐同层同说话人相邻标注合并候选」归入第二程 #285。
5. **FR-070 临时词汇项及 FR-074/075 连动**：同意放在同一本词典并标「待确认」，默认不对外发布、研究用导出可主动包含。因标准 DMLex 1.0 与 ADR-0100 E05 要求正式词条词头非空，三项打包归入**第二程 #285**；第一程切片 3/6 严禁拿 `lexemes.access_rights` 或 E02 非法输入草稿冒充临时词项。
6. **FR-080 / EF-010 / EF-013 导出扩展排第二程**：第一程切片 6 只交付 ADR-0100 E12 四类首发阻断成果（EAF 3.0、TextGrid、gb4e LaTeX、DMLex+LIFT）；桌面 SRT/VTT（**FR-080**：空文本与无可用时间文本均不生成字幕条，无可用时间项列入导出报告，不自动编造时间、不改原内容）、批量片段与媒体导出（**EF-010**：默认扩展到完整标注边界、预览实际导出范围后确认，不按时间比例截文字或静默丢标注）及版式预设复用（**EF-013**）统一排入**第二程 #285**，复用切片 6 的 `ExportPlan` / `ExportReport` 底座。
7. **FR-045 与 FR-030 对象澄清**：**FR-045** 专指外部既有分析历史语料（Toolbox / FLExText / EAF 等）连同词·语素·gloss 分析迁入（归切片 6 导入映射与第二程深化），`#326` 解语早期浏览器 Dexie/JYB 旧库迁入维持关闭不重启；**FR-030** 指外链视频参考与同时间轴上的独立起止跨度多模态层，不是替换主转写录音，与 ADR-0085「一份文稿一条主录音」不冲突，排入**第二程 #285**（不自动包含 EF-015 参照网格，亦不同于 EF-004）。

## 1. North Star（产品定位）

解语是 **本地优先（local-first）的桌面多工作台**，面向濒危语言研究与协作。

- **长期目标**：田野录音 → 转写标注 → 词典/语料 → 出版与存档，在一台机器上闭环完成。

- **形态**：Electron 桌面应用（路线 C；React + Vite 渲染层 + Worker/WASM），非移动。原纯 Web 形态（浏览器 + Dexie/IndexedDB）为历史基线；Electron 骨架跑通后只作开发与测试，E2E 迁完、旧库迁完后删除（[ADR-0063](../../adr/0063-desktop-only-after-electron-skeleton.md)、[ADR-0064](../../adr/0064-storage-freeze-until-desktop-opens-real-projects.md)）。
- **数据真源**：本机项目文件夹。文件夹里放什么以 [ADR-0085](../../adr/0085-desktop-project-one-sqlite.md) 为准（音频原文件、一份 `project.sqlite`，文稿是表里的一行）；交换包和每日 JYM 备份仍以 [ADR-0046](../../adr/0046-desktop-sqlite-project-folder.md) 第 2、6 条为准。哪一条有效见 [ADR 目录](../../adr/README.md)。D14 冻结于 user_version 27，1a 升到 28，1b-0 按 [ADR-0122](../../adr/0122-integer-milliseconds-and-optional-media.md) 升到现行 29。之后改表要新决定。桌面版剥离协作、密钥托管与遥测（ADR-0047）；**协作云（Supabase）为可选增强**，非真源，**独立切片**推进。
- **独立性**：与 Rushi（如是我闻）**无运行时依赖、无能力互补承诺**；解语缺口在本仓内解决或显式标为非目标。
- **刻意不做**：每 PR 全量重型 gate、高频依赖自动化、多角色评审路由、为形式的全量 E2E、通用多智能体 swarm / 云端多租户。成熟度检查留在 `package.json` 的按需分组，不接回 PR CI。

技术边界：[ADR-0063](../../adr/0063-desktop-only-after-electron-skeleton.md)（只交付桌面版；`browserslist` 为 Electron 44 的 Chromium 152）、[PWA / 离线壳预期](../../architecture/offline-pwa-first-visit-expectations.md)（只约束开发与测试用的浏览器构建）。[#328](https://github.com/Abe-Junwei/Jieyu/issues/328) 已撤下浏览器支持承诺。

## 2. 切片通用规则与 Agent 架构轨

> 旧 §2 切片总览与依赖图（Stage A/B/C）已移到[历史快照](../../history/解语-主路线图-历史-2026-06-01至2026-11-20.md)；当前顺序只看唯一执行队列。

### 2.1 切片落地定义（DoD，每片通用）

每个切片"完全落地"必须同时满足（本地闭环口径）：

1. **数据层**：经存储接口写入并读回校验。#275 的 SQLite 实现落地前沿用 Dexie 写路径；落地后新增操作只写并读回 SQLite 实现，不再两边都写（ADR-0064 第 4 条）。**写 → reload/requery → readback 验证**（不止字段存在）。
2. **UI 层**：入口、状态、交互闭环接线完成；用户可见文案走 `dictKeys` / 字典，不留硬编码。
3. **编排纪律**：重逻辑下沉 controller/service/纯函数；不在页面层堆业务（copilot-instructions §一/§三）。
4. **验证证据**：`npm run typecheck` + 触及域定向 `vitest`；触交互/ReadyWorkspace/侧栏/时间轴加 `npm run test:e2e:chromium`（#329 搬完的那几组改跑 Electron E2E）；触编排加 `npm run check:architecture-guard`；触 AI 加 `npm run check:agent-evals:smoke`；触桌面壳/存储加 Electron 构建与主进程测试。
5. **可回滚**：高风险或 UI 觉察大改套 feature flag（`src/ai/config/featureFlags.ts`），`false` 合并、自用后切默认。
6. **SDD**：中等以上复杂度（≥1 新 controller / ≥1 新 service / 跨 ≥3 controller）先写 `docs/execution/specs/<slug>/` 三件套再编码。

> 「前后端完全落地」在本项目 = **持久化（存储接口；#275 后为 SQLite）+ UI 三层贯通且可 readback**；协作云同步属 C4 独立切片，不作为本地切片的落地门槛。
