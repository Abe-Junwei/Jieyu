# FLEx 与 ELAN 导入字段映射

决策见 [ADR 0039](../../adr/0039-flex-elan-import-field-map.md)。它收窄 [ADR 0038](../../adr/0038-eaf-tier-pick-by-content.md) 里 FLEx 槽位的含义。本文保持 `active`。完成只在切片合并之后标 `done` 并写 `closed_at`。

不新增 controller，不新增 Dexie 版本，不新增 feature flag，因此不写 SDD。分类是纯函数。`useImportExport.importHandlers.ts` 不增加判断分支。`EafService.ts` 只做门面。导出、导入和逐层分桶在 `src/services/eaf/`。

开放语料在 `tests/fixtures/open-corpora/`，文件不在仓库里。每条规则用合成文件做必过测试。本机有开放语料时再加跳过式对照。

## 1. 现在写错什么

| 来源                                             | 现在                                                                 | 文档要求                                                              |
| ------------------------------------------------ | -------------------------------------------------------------------- | --------------------------------------------------------------------- |
| 多续语 `A_word-gls`、`A_morph-gls`、`A_word-pos` | 转写页翻译行。父层尚未登记时，子层从 `translationTiers` 的末尾掉进去 | 词注释、语素注释、词性。转写页只有短语转写和短语翻译                  |
| 多续语 `A_phrase-segnum-en`                      | 转写正文是 `1`、`2`、`3`                                             | 段号进备注。时间取自这一层。没有短语 `txt` 时，正文是 `word` 的 `txt` |
| flextext 词性                                    | 只读 `item type="ps"`                                                | 官方类型是 `pos`。XSD 没有 `ps`                                       |
| flextext 时间                                    | 属性数字原样当秒。导出也写秒                                         | Ken Zook 与 ELAN 手册都是毫秒                                         |
| flextext 词注释语言                              | 写死 `eng`                                                           | 用 `item@lang`                                                        |
| 说话人                                           | 每个 `PARTICIPANT` 各建一人，包括 `***` 和词层上的同一代码           | 短语层的参与者 id。`***` 不建人                                       |

## 2. 调研

复用 ELAN 和 FLEx 已经写明的槽位，不新做一套层名打分。

- ELAN 手册把 flextext 编成 `<Speaker>_<element>-<item-type>-<language>`，解码时按这个槽位还原。说话人前缀默认是 A、B、C。
- Ken Zook 的行名表和 `FlexInterlinear.xsd` 规定 `gls` 在 `phrase`、`word`、`morph` 上分别是自由翻译、词注释、词位注释。词性是 `pos`，语素语法是 `msa`。
- EAF 3.0 规定语言类型只说明时间怎么挂。`Included_In` 的词层（卡希纳瓦语的 `wd`）仍是词，不因为可时间对齐就变成翻译。
- 不引入新库。Pepper、Corflow、reBabel、flibl 的取舍仍以 ADR 0036、0037 为准。

## 3. 切片

每条先有失败测试，再改生产代码。已保存的 `eafTierRoles` 优先。

### 3.1 EAF：词和语素不再掉进翻译行

`eafTierPick` 对拆开的层名：翻译只来自短语元素（含 ADR 0039 的闭集别名）上的 `gls`、`lit`。`word`、`morph` 上的 `gls`、`pos`、`msa` 返回词字段，不进 `translationTiers`。挂靠按 `PARENT_REF` 是否已在词层集合里判断，不看该父层在本轮循环里有没有先被处理。

验证：

- 合成 EAF：父层 `A_phrase-segnum-en`，子层依次是 `A_word-txt`、`A_word-gls`、`A_word-pos`、`A_morph-gls`，且词层出现在短语层之前。`translationTiers` 不含这四层。`word-txt` 成为 `unit_tokens.form`，`word-gls` 成为 `gloss`，`word-pos` 成为 `pos`，`morph-gls` 成为语素 `gloss`。
- 现有 `eafTierPick` 与 `EafService` 测试仍通过。阿拉帕霍语式的 `tx`、`ft`、`wd`、`gl`、`ps` 归类不变。
- 本机有 `duoxu.eaf` 时，`A_word-gls-zh-CN` 不在 `translationTiers` 里。

### 3.2 EAF：段号、短语译文、词形基线

`segnum` 父层提供时间，编号写入已有的句子备注。它不占据转写正文，也不因为 ADR 0038 的最后退回变成转写层。同一短语下有 `word` + `txt` 时，句子正文是这些词形按 `PREVIOUS_ANNOTATION` 拼成的文本。没有词形时正文留空。短语 `gls`、`lit` 仍是翻译行，按 `ANNOTATION_REF` 挂到该句。

验证：

- 合成文件：只有 `phrase-segnum`（值为 `1`）和 `phrase-gls`（值为句子译文），另有 `word-txt`（值为 `aa`、`bb`）。语段正文是 `aa bb`，译文层含该译文，备注含 `1`。
- 合成文件：没有 `word-txt`。语段正文为空，译文仍在。
- 合成文件：`A_Transcription-txt-woe` 与 `A_Translation-gls-en`。转写层是前者，翻译层是后者。
- 本机有 `duoxu.eaf` 时，语段正文不是 `1`。本机有 `palauan.eaf` 时，转写样本含 `Dechedech`，`Frog, where are you?` 在翻译层。

### 3.3 EAF：备注和说话人

解析结果带上已分类的备注和说话人。现有写入循环只抄这些字段。

- 短语 `note`：句子 `user_notes`，类别 `comment`。
- `interlinear-text` 的 `title`：`texts.title` 仍空时写入；已有标题时写成文本级备注。
- `source`：文本级备注，类别 `fieldwork`。
- `comment`、`description`、`title-abbreviation`：文本级备注，类别 `comment`。
- 短语层的 `PARTICIPANT` 建成 `speakers.name`，句子 `speakerId` 指向该 id。同一代码在词层上不重复建人。值为 `***` 或空白时不建人。
- 元素是 `participant`、项目类型是 `note`、正文非空时，写入该说话人的 `notes`。

验证：

- 合成文件：`PARTICIPANT="***"` 的短语层不产生说话人。`PARTICIPANT="Lenny Saumar"`、层名以 `A_` 开头时，说话人名字是 `Lenny Saumar`。
- 合成文件：`interlinear-text-title-en` 的值在文档标题仍空时进入 `texts.title`，不进入翻译层。
- 合成文件：短语 `note` 的正文在句子备注里，不在翻译层里。

### 3.4 flextext：按 XSD 和行名表读写

`parseFlexPhrase` 读 `pos`，不再只读 `ps`。`msa` 进入语素 `pos`。短语 `gls` 和 `lit` 按 `lang` 各成一行，不把词级 `gls` 算进短语译文条数。短语 `note` 进入句子备注。`phrase@speaker` 进入说话人。时间导入除以 1000，导出乘 1000。词注释和语素注释的语言键用 `item@lang`。

现有夹具里的 `end-time-offset="1"` 若表示 1 秒，改成 `1000`。

验证：

- 合成 flextext：`word/item type="pos"` 进入 `unit_tokens.pos`。`morph/item type="msa"` 进入语素 `pos`。
- 同一短语有 `gls` 的 `en` 和 `zh`，翻译行是两条。词级 `gls` 不增加这个条数。
- `begin-time-offset="1000"` 读成 1 秒。导出后再导入，时间仍是 1 秒。
- `cf`、`hn`、`punct`、`variantTypes`、`text-is-translation` 不产生层。

### 3.5 丢失清单

没有写入的已知类型记一条已有丢失清单能表达的代号，带计数。已经写成句子、翻译、词项或备注的，不再报丢失。不新增代号也能用现有代号时，沿用现有代号。

验证：合成 flextext 含 `cf` 和 `text-is-translation` 时，完成结果的清单里能看到它们被跳过，短语译文条数不因此增加。

### 3.6 EAF：`ph` 是语音转写层

决策见 [ADR 0040](../../adr/0040-eaf-ph-phonetic-transcription.md)。层名整词是 `ph` 时，非空音标进入 `extraTranscriptionTiers`。不进翻译行，不计 `unmapped-field`。已保存的层角色优先。

验证：

- 合成 EAF：`ph` 挂在 `mb` 下，正文 `phon`。`extraTranscriptionTiers` 有这一层，丢失清单只有 `doreco-mb-algn`。
- 本机有 `tabaq.eaf` 时，确认角色之后 `ph@NHK` 仍是附加转写层，不在翻译行里。

### 3.7 EAF：`nt` 进备注，`fn` 是译文

决策见 [ADR 0041](../../adr/0041-eaf-nt-note-fn-translation.md)。整词 `nt` 写入句子 `user_notes`，类别 `comment`。`<p:>` 和 `****` 不写。整词 `fn` 与 `ft` 一样各成一条翻译行。已保存的层角色优先。

验证：

- 合成 EAF：`fn` 正文是国家语译文，`nt` 正文是备注。翻译行含 `ft` 和 `fn`，不含 `nt`。备注类别是 `comment`。
- 本机有 `tabaq.eaf` 时，确认角色之后 `nt@NHK` 不在翻译行，备注里能看到 “Sudanese Ar. yes”，`fn@NHK` 仍是翻译行。

### 3.8 EAF：层名未知时，日期正文记入丢失

决策见 [ADR 0042](../../adr/0042-eaf-unnamed-date-tier.md)。层名对不上已有记号，且去掉 `<p:>` 和 `****` 后至少五分之四是闭集日期时，记入 `unmapped-field`。不进翻译行，不当转写，不进角色对话框。`tx`、`ft`、`dt` 仍按层名。不加录音机型号、自由译文或音标的正文判断。

验证：

- `10/Apr/2013` 与 `2013-04-10` 夹着占位，判为日期层。同一列里句子占多数时不判。
- 独立层 `when` 只有日期、旁边有句子层时，转写层是句子层。只有日期层时没有转写层。
- 合成 EAF：`when@NOBODY` 在丢失清单，`ft` 仍是翻译。层名是 `tx` / `ft` 而正文是日期时，仍分别是转写和翻译。

## 4. 非目标

- 时间轴按内容加宽。那条实现在另一分支，不在本计划里移植。
- TextGrid、Toolbox、TRS 的「第一条当转写」。
- 改 `proposeEafTierRoles` 的先到先得。
- 把 LIFT `morph-type` 映射进 DMLex。
- 为 `cf`、`hn`、语素类型、`variantTypes`、`text-is-translation` 加字段或加 Dexie 版本。
- 用子串把 `Transcribe` 以外的陌生元素升成转写。闭集见 ADR 0039 第 3 条。
- 新交换格式、新 controller、feature flag、0 时长空音频。

## 5. 落地顺序

3.1 → 3.2 → 3.3 → 3.4 → 3.5 → 3.6 → 3.7 → 3.8。3.1 和 3.2 只改 EAF 解析和分桶。3.3 让现有备注和说话人循环消费已经分好的结果。3.4 只改 `FlexService` 和它的测试夹具。3.5 只补清单。3.6 只把 `ph` 送进已有的附加转写层。3.7 只改 `nt` 和 `fn` 的分桶。3.8 只在层名未知时把闭集日期记入丢失。

合并前跑 `npm run typecheck`、上述 vitest、`npm run check:architecture-guard`、`npm run check:docs-governance`。3.1 和 3.2 改了转写页会看见的层，补一次 Chromium 走查：多续语或合成的 `segnum` + `word-txt` + `phrase-gls` 在转写页只有句子和翻译两行，词注释不在层列表里。
