## 2. 写入路径
1. `resolveToolDecisionPipeline`（`src/ai/chat/toolDecisionPipeline.ts:131`，调用点 `useAiChat.streamCompletion.ts:596`），约 25 个依赖由 React hooks 注入。
2. 策略 → 写入门禁 `assertAiChatToolWriteAllowed`（`toolDecisionPipeline.ts:378-379` → `src/ai/runtime/toolWriteGate.ts:52`）。**注意：门禁受 `featureFlags.aiToolWriteGateEnabled` 控制，dogfood 为 true、prod 默认 false**（`src/ai/config/featureFlags.ts:198`，`featureFlags.environmentMatrix.test.ts:91,107`）。
3. 需确认 → `useAiChat.pendingToolCall.ts:69` 挂起；确认后 `executeConfirmedToolCall`（`useAiChat.confirmExecution.ts:223`）；免确认 → `useAiChat.autoExecute.ts`。
4. 真正执行：`onToolCall` = `handleAiToolCall`（`src/pages/useTranscriptionAiController.ts:321`，注入点 :473）→ `aiToolCallHandler(materializeAiToolCall(call))`。**语音也用同一个 handler**（:598 `executeVoiceToolCall`），可作为语音与聊天共用审批的接入点。
5. 副作用提交：`commitToolEffects`（`src/ai/runtime/commitToolEffects.ts:91`；调用于 `useAiChat.autoExecute.ts:175`、`confirmExecution.ts:462,963`、`streamCompletion.ts:423`）。
6. 幂等：`useAiChat.toolAudit.ts:44` 的 `executedRequestIds` + `hasPersistedExecutionForRequest`。
