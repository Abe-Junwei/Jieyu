# EAF 默认选层

决策见 [ADR 0038](../../adr/0038-eaf-tier-pick-by-content.md)。它取代 [ADR 0036](../../adr/0036-eaf-import-is-interchange.md) 第 3 条的默认选层，以及第 10 条里「主转写下每条 `Symbolic_Subdivision` 都是词层」。能拆成 FLEx 层名时，槽位写进哪一栏见 [ADR 0039](../../adr/0039-flex-elan-import-field-map.md) 和 [FLEx 与 ELAN 导入字段映射](./FLEx与ELAN导入字段映射-2026-09-28.md)。本文保持 `active`。完成只在切片合并之后标 `done` 并写 `closed_at`。

不新增 controller，不新增 Dexie 版本，不新增 feature flag，因此不写 SDD。选层是纯函数。`useImportExport.importHandlers.ts` 不增加判断分支。

开放语料在 `tests/fixtures/open-corpora/`，文件不在仓库里。每条规则用合成 EAF 做必过测试。本机有开放语料时，再加一条跳过式对照，写法与 `tests/fixtures/open-corpora/openCorporaImport.test.ts` 相同。

## 1. 现在选错什么

| 文件 | 现在的转写层 | 句子实际在 |
| --- | --- | --- |
| 24 份 DoReCo，如 `arapaho.eaf` | `ref@说话人`，正文是编号或 `<p:>` | 子层 `tx` |
| `kamas.eaf`、`dolgan.eaf` | 无语段。根层类型不可时间对齐 | 子层 `tx` |
| `okinawan-itoman-yukkanuhii.eaf` | 空的 `document_notes` | 子层 `transcription` |
| `duoxu.eaf` | `A_phrase-segnum-en` | 句子层，不在编号层 |
| `sundanese-north-wind.eaf` | `Sundanese` 正确 | 英语和 IPA 被折进词项 |
| `cashinahua.eaf` | `ref@JC` 的 `<p:>` | `tx` 被折进词项 |
| `multi-tier-ipa.eaf` | `default` 正确 | 独立的 English、Chinese 因没有媒体被跳过 |

`proposeEafTierRoles` 只看有没有父层。一个独立层时不弹窗，默认仍是文档顺序。

## 2. 切片

每条先有失败测试，再改生产代码。已保存的 `eafTierRoles` 优先于默认判断。

### 2.1 按正文和层名选转写

新纯函数读层 id、父层、是否可时间对齐、非空条数、锚点比例。记号只来自层名，语言类型 id 不参与。记号表以 ADR 0038 第 2 条为准。

语段时间取锚点或父层。转写正文取子层里按 `ANNOTATION_REF` 对齐的文本。锚点编号写入已有的父标注注释。

没有转写记号时，退回第一条非空且不像锚点的独立时间对齐层，再退回今天的第一条独立时间对齐层。

验证：

- 合成文件：独立 `ref` 的值是 `0001_doreco_x` 和 `<p:>`，子层 `tx` 是句子，子层 `ft` 是译文。导入后语段正文是句子，译文层是 `ft`，编号在父标注注释里。
- 合成文件：`ref` 的语言类型 `TIME_ALIGNABLE="false"`，子层 `tx` 有可对齐时间和句子。语段条数大于 0，正文是句子。
- 合成文件：第一条独立层 `document_notes` 为空，后面的 `transcription` 子层有句子。转写层不是 `document_notes`。
- 合成文件：第一条是 `segnum`，值是数字，子层是句子。转写正文不是数字。
- `tests/golden/eaf/minimal.eaf`、`five-unit-thai.eaf`、`mvm-muya-real.eaf` 的转写层名和语段条数与现在相同。
- 本机有 `arapaho.eaf` 时，转写样本以句子开头，不是 `0001_doreco_`。有 `kamas.eaf` 时，语段正文含 `Tumo`。

### 2.2 一句对一句的细分层不当词

某个父标注下有两条及以上子标注，或层名像词层时，维持词切分。一个父标注最多一条子标注、且层名像转写或翻译时，该层进入短语级结果。

验证：

- 合成文件：主层下两条 `Symbolic_Subdivision`。一条每个父标注只有一条、层名含 `Translation`；另一条每个父标注有多条、层名含 `words`。前者进翻译层，后者仍是词项。
- 本机有 `sundanese-north-wind.eaf` 时，翻译层能读到 `The story is about`。有 `cashinahua.eaf` 时，转写正文不是 `<p:>`，词层仍有词项。

### 2.3 没有媒体时独立翻译挂到已有语段

`useImportExport.additionalTierHandlers.ts` 里，独立时间边界的翻译层在没有 `mediaId` 时：本次已有语段，就走现有的时间重叠；没有语段，才整层跳过并计入 `dropped-translation`。不新建音频行。

验证：用 `multi-tier-ipa.eaf` 走导入写入，项目没有媒体。转写是 `tɕʰa mo ɣa ra`，同一语段能读回 `The tea is hot` 和 `茶很烫`。媒体行数不变。没有语段可挂的独立翻译，完成提示仍有对不上的译文。

### 2.4 对话框只用同一套判断

短语级转写候选不少于两个，或没有转写记号且独立短语层不少于两个时，抛出现有的 `EafTierRolesRequiredError`。词层不在 `tiers` 里。默认角色来自 2.1。判断唯一时不抛。

生产路径继续用 `useTranscriptionImportExportInput` 里已有的确认开关。直接调用 `useImportExport` 且不传该开关的测试不弹窗。

验证：

- 两个独立层都叫 `tx` 时，开关打开且未确认，不写语段，对话框里两个层名都在，默认第一条转写。
- 合成的 `ref` + `tx` + `ft` 在开关打开时不弹窗，直接写入句子。
- `multi-tier-ipa.eaf` 在开关打开且未确认时仍弹窗。`default` 默认转写，`English` 和 `Chinese` 默认翻译。

### 2.5 完成提示写出选中的层

选中的转写层不是第一条独立时间对齐层时，清单加 `guessed-tier`，名字是层 id。字典加一句，中英都写。已经写成转写正文的句子不进清单。

验证：2.1 的 `ref` + `tx` 文件，完成提示含 `tx` 的层 id。`minimal.eaf` 的完成提示没有这句。

## 3. 非目标

- TextGrid、flextext、Toolbox 的默认「第一条当转写」。ADR 0037 第 4 条不动。
- TRS 弹层角色对话框。
- flextext 短语级译文只有一条时改去拼词级译文。
- LIFT `morph-type` 映射进 DMLex，或对正常词典停止报这条诊断。
- 新交换格式、新 controller、新 Dexie 版本、feature flag、0 时长空音频。
- 用语种识别或模型给层打分。

## 4. 落地顺序

2.1 → 2.2 → 2.3 → 2.4 → 2.5。2.1 和 2.2 只改解析。2.3 只改没有媒体时的写入条件。2.4 接上现有对话框。2.5 只加一条清单代号。

合并前跑 `npm run typecheck`、上述 vitest、`npm run check:architecture-guard`、`npm run check:docs-governance`。2.3 和 2.4 改了导入后的时间轴正文，补一次 Chromium 走查：阿拉帕霍语或合成 `ref`+`tx` 的转写轨是句子；`multi-tier-ipa.eaf` 在没有媒体时能看见英语和汉语。
