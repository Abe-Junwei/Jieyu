### 产品前提（2026-04-21 起写入）

以下前提**若成立**，本规划中的「收口」可采取 **更激进、无过渡期** 的实现（与主规划 §5 前提一致，此处单列便于实施勾选）：

- **无历史数据**：不导入旧 `jieyu` dump；不要求旧浏览器 localStorage profile 行为不变。
- **无向后兼容需求**：允许改 localStorage 键名、删迁移 shim、删「legacy 表兜底」导入路径（若产品确认）。
- **不留 legacy**：时间轴相关代码以 **单路径** 为准；兼容分支需有明确删除期限或不得新增。

**仍须保留的边界**：除非产品明确 **不做互操作导出**，否则 **`timelineMode` 等作为导出/交换格式标签** 仍可按 [ADR-0009](../../adr/0009-greenfield-timeline-single-source-freeze.md) 决策 4/5 保留在 **导出上下文**，与「运行时去 mode 化」不矛盾。

### 阶段 G — 声学长于文献轴：完整显示波形（2026-06-26，已修订并落地）

**最终决策（用户拍板）**：当 `mediaDur > documentSpanSec`（声学比当前文本轴长）时，**完整显示波形时长**（铺轨 / 标尺 / 建段上界 / 播放都跟到完整声学），**仅不延伸持久化的文本逻辑时长**（`logicalDurationSec` 不被更长声学抬高）。

**走过的弯路（勿重蹈）**：初版（2026-06-26 上午）把「导入冻结」误用到**显示跨度**——`resolveTimelineBindingExtentSec` 文献优先返回文献跨度，且在 `useZoom` 引入「对称 tier-primary」把波形钳在文献轴内。结果更长声学被截断、波形 / 标尺到不了声学尾部。用户判定此钳制不合理，已**全部回退**：

- `resolveTimelineBindingExtentSec` 改回 `max(文献, 声学)`（显示跨度不冻结）。
- 回退 `useZoom` / `TimeRuler` / `waveformBridgeTierScrollSync` 的对称 tier-primary，恢复 `isExtendedDocumentTimeline`（仅 `doc > media` 时 tier 主导；`media ≥ doc` 时 WaveSurfer 主导，波形完整可滚）。
- 移除 `playbackExtentSec` / `resolvePlaybackCapSec` / `clampTimeToPlaybackCap` 整条链路（2026-06-26 审计修复）；播放/seek 上界 = **`player.duration`**。
- 删除 `isTierPrimaryTimeline` / `resolveWaveformScrollClampSec` 等新增对称助手。

**保留**：导入冻结只作用于持久化 `logicalDurationSec`（`mergeImportedTimelineMetadata` / `resolveLogicalDurationAfterAudioImport` 不变）；ADR-0004 实现记录已同步修订。

**保留的独立修复（与本决策无关，继续生效）**：

- B1 hover：extended-document（`doc > media`，tier 主导）时 hover 时间用 `tier.scrollLeft` 并钳到 `documentSpanSec`，不再读被钳的 `ws.getScroll()`（`src/pages/waveformBridgeHoverScrollRaf.ts`）。
- `TimeRuler` 刻度密度按可见窗口 `viewWidthPx / windowSec`（`resolveTimeRulerPxPerSec`），`resolveTimeRulerSpanSec` 复用 `resolveTimelineBindingExtentSec`（现 = max）。
- **100% fit（2026-06-26 补充）**：`fitPxPerSec` 以 `resolveTimelineFitSpanSec`（= `max(文献轴, 声学)`，文献侧用 `documentSpanWithoutAcousticAnchor`）为分母，更长声学时 100% 一屏铺满整段波形；`documentSpanSec` 仍只表文献/语段轴，供 tier-primary 判定与语段坐标，**不**因 fit 抬高持久化 `logicalDurationSec`。

**连带清理（已完成）**：导入冻结期新增的 `duration_long` 提示在 `max` 语义下永不触发（`d > bindingExtent` 恒假），已整条移除——`timelineAxisStatus` 的 `duration_long` 联合分支与 `documentSpanSec` 入参、`timelineAxisStatusExpand` 的对应分支、`TimelineAxisStatusStrip` 渲染分支、i18n `acousticBeyondBindingExtent`（`dictKeys` + en/zh）、`useReadyWorkspaceAxisStatus` 的 `documentSpanSec` 透传及相关测试。声学超出语段仍由既有 `duration_short` 提示覆盖。

**非目标（原）→ backlog（2026-06-26 产品拍板）**：
