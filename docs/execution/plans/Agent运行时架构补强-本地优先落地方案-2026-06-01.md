### 3.1 A6 — F4 Batch B/C + 工业三开关 evidence

`agentRunId` 贯穿 tool decision / loop step / MCP audit；metadata：`userTextDigest`、`sourceScopeSummary`、`workflowId`。

`src/ai/security/semanticGuard.ts`；`before_model` / `before_client`；CorpusSourceSet `trustTier`；SDD：`agent-runtime-security-semantic-guard/`；flag `aiSemanticGuardEnabled`。
