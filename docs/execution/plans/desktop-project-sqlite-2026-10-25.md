# 桌面项目单库

依据 [ADR-0085](../../adr/0085-desktop-project-one-sqlite.md)、[ADR-0086](../../adr/0086-desktop-release-scope-and-format-freeze.md) 的范围/冻结安排和 [ADR-0087](../../adr/0087-project-deletion-retention-and-media-cleanup.md) 的删除规则。旧的 SQLite `StoragePort` 停在现在的样子，不补拒绝的方法，现在也不删。半成品库文件不迁移。

## 调用

```ts
const project = await openProject(folder);
const manuscript = await project.manuscripts.create({ title, mediaId });
const layer = await project.layers.create({
  manuscriptId: manuscript.id,
  key: 'tx',
  name: { zh: '转写' },
  tierType: 'time-aligned',
  contentType: 'transcription',
});
const unit = await project.units.create({
  layerId: layer.id,
  startTime: 0,
  endTime: 1.2,
  text: '…',
});
```

`units.create` 在同一事务里写 `units` 和一行 `unit_texts`（`role` 为 `transcription`），读回这两行之后才提交。返回的语段带 `text: string`。按 id 读返回同一种形状。

### M6-D 路由接替（2026-10-28）

生产入口改走桌面库复用桌面路由与 controller，不将旧 hook 的存储机械平移。旧文件留着：M7-C 已核对替代，证据不齐，未删。这一节是实施依据，不替代上表 M6-D 的终验条件。既定合成工程路由接替已通过，首发模型链路与旧路径退出继续独立跟踪。不据此关闭 #275/#280/#325。

外壳和选路已接上。Electron 不挂载旧库检查、定时备份和旧目录弹窗。桌面页在 `CatalogProjectGate` 外面选路，不把桌面会话 id 写进旧项目状态。没有会话或会话过期回文件夹页。转写页在 `ProjectLanguageListsLoader` 之前离开；有会话时转写路由进已有的桌面文稿页。正文的一步逆操作已记下。语段切分和合并的一步逆操作已记下。说话人可以一次改派，备注和目录的列表与编辑已记下。首页打开文件夹后能读到项目名，关掉再打开仍在。语料页定位时带上文稿、层和语段。导入当前打开的项目不重新开库，文件选择和导出保存已接上。分析页已能接受真实建议并恢复快照，核对的是当前凭据。对话可以创建、列出和选择。追加消息和改标题都要求对话已经存在。语言目录、正字法和桥从桌面会话打开，不经过旧项目门禁。结构模板没有桌面表，不打开旧页。桌面构建不打开协作日志，也不因协作通知清掉旧项目编号。脚本不打开桌面会话。导入脚本只写文件夹，占着的项目拒绝写入。点名的测试脚本留下。终验已通过。已勾 M6-D。

选路分三种。桌面宿主可用走桌面页。Electron 里桥接未就绪，显示不可用；旧试用开关已清除。浏览器开发环境走旧页。没有会话或会话过期，回文件夹页，不打开旧库。`readDesktopProjectHost()` 返回空只表示宿主不可用。

桌面分支在 `CatalogProjectGate` 外面选路。这道门看的是旧 `activeProjectTextId`。不把桌面会话 id 写进旧项目状态。`/lexicon`、语言目录、正字法和桥在有会话时走桌面页。结构模板没有桌面表，不打开旧页。浏览器里这些目录弹窗仍看旧项目编号。

外壳单独一片。`useAppDataResilienceEffects` 在路由之前就会检查旧库并做定时备份。Electron 不挂载它，也不挂载这些旧目录弹窗。旧实现留下，不改它们的存储。转写正文的早退要在 `ProjectLanguageListsLoader` 之前。

撤销是当前会话里的一步逆操作，不建表。记下逆操作要的状态，执行前核对对象仍是那次写入之后的样子。后面又改过、换了项目或关了会话，就清空记录，不用旧记录盖住新状态。正文的逆操作恢复旧字符串，并在同一次事务里恢复写入前的分析图和关联。切分的逆操作去掉新语段，以及它的备注、词、语素和链接。合并先定留下哪个 id，另一语段的关联按这个决定处理。再调一次切分或合并并不是撤销。时间映射用现有回滚。新函数在同一次事务里核对、执行并读回。

对话要能创建、列出或选择。`desktopCall` 已有 `conversations.create`、`conversations.list`、`messages.append` 和 `conversations.patch`。追加和改标题都要求对话已经存在。不恢复会话记忆、嵌入、任务和审计。

导入导出已接到主进程。`desktopCall` 已有 `exchange.importFile`、`exchange.exportJyt`、`exchange.exportJym` 和 `exchange.exportManuscript`，文件选择和导出保存已接上。库的变更一次事务完成。文件失败沿已有的清理边界退回。导入当前打开的项目时不重新开库，以免撞上项目锁。

语段的切分、合并和分析节点的 `analysis.split` 分开。说话人批量改派单独一次事务。目录调用按列表和编辑逐项核对，不能只看已有的 create/get。语料页跨路由定位时带上文稿、层和语段 id。分析页的 `accept` 和 `restore` 要有真实候选或快照，以及当前凭据。词典不挂 LIFT、引用跳转、多义项编辑、删除和附件画面。脚本先查调用者，测试工具按用途决定留不留。

证据分两组。隔离：从真实路由和外壳进入，旧 hook、旧服务和旧存储入口没有被调用；覆盖无会话、过期会话、宿主未就绪和目录弹窗。只渲染桌面子页不算。持久化：写入片从页面操作，经真实桌面库函数落盘，关掉再打开后由页面读回。结构片还要验失败回滚、撤销和关联还在。首页和语料页验导航和读取。

顺序是：外壳与选路，转写正文（一步逆操作已落地），语段切分合并及逆操作（一步逆操作已落地），说话人备注和目录（已落地），首页（已落地），语料页（已落地），导入导出（已落地），分析页，对话，然后词典门禁、协作日志和脚本调用者。

### 当前已确定的删除边界
