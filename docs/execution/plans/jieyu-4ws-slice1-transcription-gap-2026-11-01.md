## 切片 1 精稿交付清单（定稿）

1. 区域：左轨｜上下文（稿件／层／片段列表）｜主区（播放／波形／多轨／当前片段原文·译文）— 对齐板 51；无右栏检查器。
2. 主操作：播放／循环、改正文保存（切片 0／1a）、进标注、查找替换、片段拆合删（菜单见板 52）。
3. 键盘：焦点环与选中分色；IME 不穿透（切片 0 已有）。
4. 状态：保存中／未知／失败+草稿（53–55）、离开守卫（56–57）、1280／窄窗／暗色／空媒体（58–61）。
5. 组件映射：见 spec design §3／§6（Waveform／受控 Timeline／draft guard）；旧 VerticalView 不得直接挂桌面。

**定稿结论**：精稿可作切片 1 UI 对照（flag 默认 `false`）。1a 先落保存回执／持久草稿／离开；1b 再接波形／时间轴受控展示。禁止第二套转写样式；禁止按废弃板 27 实现。
