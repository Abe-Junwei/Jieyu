# 手工验收执行脚本 — 标注页 M1 开放（2026-09-11）

对应 SDD：`docs/execution/specs/annotation-m1-open/`。自动化：`npx vitest run src/pages/annotation src/pages/AnnotationPage.test.tsx src/ai/AutoGlossService.test.ts src/ai/autoGlossPreview.test.ts`；E2E：`npm run test:e2e:chromium -- tests/e2e/criticalPaths.spec.ts`。

## 准备

1. 打开转写工作台，导入一段音频并至少切 2 条句段，保存。
2. 进入 `/annotation`（默认 flag 开）。应看到 IGT 工作台，而不是「标注工作台未开放」。
3. 用 `VITE_ANNOTATION_PAGE_ENABLED=false` 启动一次，确认占位面板仍可用。

## 步骤

| # | 操作 | 期望 |
| --- | --- | --- |
| 1 | 行聚焦按 Space | 当前句段音频从 start 播到 end；再按暂停 |
| 2 | Enter 进入输入态，在 POS/gloss 按 Space | 格子出现空格，不切换播放 |
| 3 | 无媒体或时间相等的句段按 Space | 不抛错；提示无媒体 |
| 4 | 写备注、选分类、保存；刷新或离开再进 | 备注与分类仍在 |
| 5 | 改自我确信度 | reload 后该句段仍是所选值；转写文本/时间码不变 |
| 6 | 对无 gloss 的 token 点「预览自动对译」 | 列出建议；此时库中 gloss 仍空 |
| 7 | 点「采纳建议」 | gloss 与词典链接写入；再 reload 仍在 |
| 8 | 对已有 gloss 或未提交草稿的 token 预览 | 该 token 不出现在建议里 |

## 不验收

- 二次自动分词、ChatWindow AutoGloss 工具、语料库 flag、EAF 导出。
