# 对外发布前最小检查（单人维护草案）

本文档配合 `docs/execution/plans/单人AI协作改进计划-拍板决策-2026-05-11.md`（决策 **1B**：半年内可能对外）。以下为「上线或多用户试用」前的最小自检项，可按实际托管形态增删。

## 数据与隐私

- 明确本地 IndexedDB / 导出归档中含哪些字段；若启用协作云，列出同步范围与用户可见提示文案。
- 确认匿名遥测、OTEL、Sentry（若开）的采样与脱敏策略符合预期。

## 构建与门禁

- `npm run typecheck`、`npm run check:architecture-guard`、与改动相关的 vitest 子集。
- 面向宿主环境的构建：`npm run build` 或 CI 等价流水线。
- 交付浏览器矩阵的快速验证：`npm run test:e2e:chromium`（或与改动相关的 grep）。
- Knip 治理：CI 用 `npm run check:knip:ci`（窄范围、不可降级）；本地 `npm run check:knip:full` 仍可看到 `unused exports` 的长期收敛清单，详见 `docs/execution/governance/knip-exception-ledger-2026-05-08.md`。
