# 分析与时间（技术审阅稿）

沿用完整分析图为真值、线性投影显式派生；现有`surfaceParts`、稳定node/relation id与字段修订可复用。资格信息应在同一图载荷版本内明确，不把缓存flag变成第二份分析真值。

## 依赖、对应与资格

每个字段/关系保存`{revision,reviewState:valid|pending,sourceDependencies,reviewedAgainst?}`的版本化资格元数据；完整度由字段值及模型约束派生，缺失不等于pending。生命周期epoch独立于字段修订，删除再恢复不会因文本相同复活旧AI任务。

| 改变 | 必须重新检查的依赖 |
| --- | --- |
| 原文字符/范围 | 对应词形、跨度、词序与以这些对象为宿主的语素/关系；无关唯一对应项保留 |
| 词边界/顺序 | 含该边界的语素划分、对应及词距；不把远处无变化gloss全部失效 |
| 语素边界/来源 | 该语素与依赖关系/gloss/义项的对应资格；保留可查看旧值 |
| gloss文本 | 标签识别、相关AI/查询依赖；不使词形边界失效 |
| 义项内容 | 绑定展示取最新，gloss保持独立，不制造差异警告 |
| 时间/映射 | 对齐、声学/时间查询、相应AI；不使无音频依赖的语言分析失效 |
| 说话人 | 依赖说话人的结果/候选，不对所有语言分析一刀切 |

原文差异先从明确编辑范围与基准版本计算；可唯一定位的未改区域映射保留身份/资格。重复词候选有多个、边界相交或无法证明未变则pending，绝不以启发式最高分当唯一。新位置仅偏移而内容/边界结构未变可以更新对应并记录，不重建新词身份。拆合才新身份。旧span按原文UTF-16索引沿既有协议，编辑器显示与选择按字素边界，禁止切开代理对/组合簇；规范化只用于比较，不偷偷更改原文位置。

复核批次构建依赖闭包，用户保留/修正/解除后，校验节点存在、位置范围、顺序、宿主、引用和字段定义；提交时再核依赖版本。未选择的pending项保持；不能只勾“已确认”绕过不合法边界。投影、资格、修订及历史同事务，查询/导出用统一资格判定器，AI另走相同领域读取规则。

## 零语素、非表面形式与附着

- 词节点明确原文范围；语素`surfaceParts`可零/一/多块。空数组本身不等于零语素，需显式`alignmentKind=zero`及所属词、词内序位/边界锚点；不造零宽字符或假token。
- `alignmentKind=discontinuous`有同词多个有序不重叠范围；`non-surface`保分析形式与说明、来源词关系，不要求去分隔符后逐字等于原文。
- 附着关系显式记`boundaryKind=clitic`、附着方向及宿主；输出`=`而非所有边界`-`。跨词附着验证同稿关系，不把它变成跨稿图边。复杂跨词不连续仅结构化备注，不伪造可查询覆盖。
- 图载荷增加这些语义字段需要版本化严格schema；不藏进任意features实验键就宣布协议完成。首发UI至少能表示、人工确认并保存重开，格式不能表达则报告损失。

## 历史、拆合与引用

HistoryVersion=`{versionId,targetRef,originalText,textRevision,graph,definitionRevisions,source,timeMappingRevision,operationId,createdAt,reason}`。首次有效→pending保快照；之后连续输入不重复快照。复核/拆合/批量采纳/恢复建新完整版本。普通同一状态的微编辑仍由撤销覆盖，不能误称每按键永久有历史。

拆合操作预览请求带原句段、相关字段修订、文字分割/拼接方案、时间方案、引用迁移表及歧义清单。提交核全部预览集合，分配新段id，旧段退出当前集合但映射/历史保留；新词/语素仅确有结构拆合才新id。可唯一迁移关联记录来源，否则脱离为待定位，不改例句快照文本。

历史恢复是新操作：默认转候选；连原文恢复先建立影响闭包。当前后来修改的备注正文不被历史覆盖；关联恢复和正文恢复分开。清理预览给受保护版本、可删版本、需放弃候选/撤销及已删对象历史列表；commit重查集合/修订。当前、最近有效、正式词典/语料、待复核依赖受保护；到期前对象自身恢复最低所需数据不能删。

## 文献轴、媒体轴与毫秒

提案：持久文献时间`d_ms`为整数，timeMapping沿用`media_seconds = scale * (d_ms / 1000) + offset_seconds`；逆变换`d_ms = roundHalfUp(1000 * (media_seconds-offset_seconds)/scale)`。scale必须有限且>0，offset沿桌面manuscripts.ts为非负有限值；已核`LinguisticService.timeMapping.ts`使用offsetSec + scale * documentSeconds，适配器按此方向，既有预览clamp不能拿来静默修正非法持久边界。

量化仅在写入持久文献边界时进行；播放转换用浮点秒不再反复量化。导入有媒体时码先逆映射再量化一次，文献时码直接量化；相同来源边界共用一次确定性换算结果。精确半毫秒按向后取整，不以二进制浮点近似误判来源十进制tie，解析十进制时间为整数/有理数再量化。

映射后媒体范围检查使用映射值与媒体时长，不拿文献时码直接比较；媒体缺失仍可查文献范围，无法验证媒体范围明确待核对。映射改变预览涉及片段与音频候选，原文资格按依赖保留。缩放可能使逆变换短段量化塌缩，阻提交并列明位置；不能自动转点、拉长、丢弃或改邻段。

区间`[start_ms,end_ms)`、start<end；点层只有time_ms，不能塞进相等起止区间。同层区间不交叠；同层点唯一时刻；导入点精度碰撞需人工合文/调时/分层。媒体终端点归最后一个覆盖媒体结尾的合法区间；没有这种区间则无归属，不凭“最后一段”跨空隙认领点。

## 结构操作与验证

单边拖动只改选中边界；共边联动显式提交两段patch。无效拖放回原有效值并说明；手输半成品可保存inactive草稿。层结构变更/删除先枚举全部标注、子层、查询与引用，迁移只能到类型/语言/宿主兼容目标，成环/跨稿父子关系禁止；不能只换标签。

测试例：`1.0004→1000`、`1.0005→1001`、同边两侧同值；scale=1.5正逆、负offset拒绝、媒体缺失；量化后两端相等；同层重叠拒绝而跨层合法；共边点和终端空隙；重复词歧义、纯后移不失效、同值改回修订仍冲突；零语素/`=`/不连续往返项目包；历史清理不能破坏待复核和软删恢复。上述是验收输入，未运行即不勾产品通过。
