# Tasks — desktop-project-deletion

## 开始条件

- [ ] M1 不扩范围；M2/M3 所需单库 API/宿主已就绪，完成实际入口及写入链 Explore。
- [ ] 核对 schema/API 提案、所有生产/后台写入、默认读过滤和清除/恢复竞态；补齐每片实际文件清单后确认实施。

## D1：删除与恢复

- [x] 文稿 `deleted_at` 为空表示有效。标记删除和恢复各推进 `lifecycle_generation`。普通列表不含已删除文稿，也不列出它的层、语段、备注、词和词条链接。专用列表只含文稿行。已删除期间正文写入被拒绝。仍在运行的转写使删除不生效。恢复后旧运行不能接受，新运行可以。关掉再打开仍在。不开放删除界面。提醒展示和垃圾箱未做。
- [x] `manuscripts` 与 `media` 已有 `deleted_at`、`retain_until`、`reminder_shown_at`。文稿删除写下 `retain_until`（加 90 天）和空的 `reminder_shown_at`。恢复清空文稿和该录音的周期。user_version 升到 23，旧文件只拒绝。删除录音会标记录音并连带有效文稿，已删除文稿的期限只延长。提醒展示、删除界面和垃圾箱仍未做。
- [x] 删除前可读取影响范围。文稿预览给出录音路径，并标出这份文稿是否已删除、是否有运行中的转写。录音预览只列出引用它的文稿。预览不写库。确认界面和字典未接。删除入口仍不开放。
- [x] 删除界面列出录音路径。取消不删除。转写还在运行时不能确认。确认后才标记删除，普通列表不再出现这篇文稿。提醒界面和垃圾箱未做。
- [x] 同一次验收：运行中的删除不写标记，已保存正文还在，停止后的运行不能续写。删除后正文和旧转写都写不进，另一份文稿可以改。恢复后旧转写仍拒绝，新转写和正文可以写。关掉再打开仍是新正文。聊天和本机上下文工具没有文稿或录音的删除、恢复、清除。删除入口仍不开放。

## D2：编辑与任务

- [x] 转写收尾、预览和放弃在同一次事务核对文稿生命周期。对不上就拒绝，运行行保持原样。删除再恢复后，删除前的运行不能预览、放弃或接受。新的运行可以。
- [x] 停止只打断这份文稿或这条录音上仍在运行的转写。另一份继续运行。停止不写入删除标记；仍有运行中的任务时删除不生效，已经打断的运行保持打断。缺目标时停止失败，已有运行不变。项目库没有另行的未提交编辑缓冲。删除入口仍不开放。
- [x] 分析建议和快照在保存时抄下文稿生命周期。删除再恢复后，之前的建议不能接受，之前的快照不能恢复，正文代数不变。之后新提交的建议可以接受。
- [x] 已删除文稿不能再写入词条链接、词素链接、转写接受、接收批次、本地 id 和备注字段。另一份文稿仍可写。恢复后这些写入可以。清除仍能删掉这些行。转写还在运行时删除不生效。项目库没有未提交的编辑缓冲。
- [ ] 本机转写接入后复用并回归门禁，不为了测试循环提前要求其整单完成。

## D3：期限与项目包

- [x] 本周期第一次看到提醒才写下时点，再看不改。没看过、未满保留期或未满展示后 7 天都不清除。到期清除在同一次事务删掉文稿、层、语段、词和备注，共享录音、说话人、词条和另一份文稿还在。关掉再打开仍如此。提醒界面未做。
- [x] 普通 JYT 按 id 和正文对拍。完整包带已删除文稿。坏包和已有目标都不改源库。普通文稿导出只含选中的有效文稿。含音频的 JYM 导入空文件夹后，录音字节和哈希对得上，已删除文稿的录音也在包里。坏哈希和越界路径不写目标。
- [x] JYM 带上附件字节。导入空文件夹后哈希对得上。坏哈希不写目标。JYT 仍不含这些字节。缺文件不能导出。
- [x] 每日备份也带上附件字节。当前项目删掉附件后，备份里的副本还在。恢复到另一文件夹后文件读得回。
- [x] 导入完整包后清掉旧提醒。文稿和录音仍是已删除，保留期限不变。没有新的提醒展示就不能清除。包里仍留着原来的提醒时点。
- [x] 每天一份含音频 JYM，放在项目外，保留 3 份。同一天再存换掉当天那份。恢复到另一文件夹后录音哈希对得上，播放区间读出的字节一致。
- [x] 两份文稿、两份可播放录音的每日备份恢复到另一文件夹后，id、正文、哈希和采样都对得上。系统能打开这两份录音。导入到已有项目被拒绝，源库不变。界面里还没有从备份打开播放。
- [x] 打开项目会话时写入当天的 JYM。同一天再打开换掉当天那份。缺了录音文件就不留下会话，也不留下当天的包。备份目录在项目里时不建目录。
- [ ] 项目一直开着不会另存。界面里还没有播放。
- [x] 文件夹页列出最多 3 个日期快照，新的在前。没有就写明没有。upgrade.jym 不列出。恢复前先说明不改当前项目、不删快照，确认后再选空文件夹。成功只显示路径，不打开、不播放。目标不是空文件夹就拒绝。
- [x] 到期提醒写明清除只删当前项目，已有备份还在。没有独立隐藏目录。
- [x] 清除取保留期限和提醒后 7 天的较晚者。只过其中一个、没看过提醒，或恢复后再删除的新周期，都不清除。已经清除的文稿不能恢复。录音文件还在。提醒界面未做。
- [x] 文件夹页打开到期提醒后才记下时点。保留期限前 7 天之内的已删除文稿和录音才会出现。没到期的不出现，也不会被记下。再次打开不改时点。关闭提醒不清除。垃圾箱未做。
- [x] 过期的每日备份恢复到另一文件夹后清掉旧提醒。文稿仍是已删除，保留期限不变。没有新的提醒展示就不能清除。重新看到提醒后再留 7 天。包里仍留着原来的提醒时点。当前项目清除后，这份备份还在。

## D4：音频收尾

- [x] 满足全部引用与提醒条件才清除，操作进度入项目库，trash 成功才清登记并解除来源。失败或未知留下记录。同路径另一份文件不移走。主进程调用可以清录音。界面没有按钮。
- [x] 重新登记给新 id。哈希撞上仍在的已删除录音时只列出候选，不新建。确认后只恢复选中的录音，文稿保持已删除，来源不接回。已有有效录音的哈希拒绝。主进程调用可以重新登记和恢复。界面没有按钮。
- [x] 磁盘适配失败注入与真实 Electron 临时文件验收；无真实用户数据操作。垃圾箱拒绝仍是失败，不记成已移走。文件还在则是 unknown。macOS Electron 已把临时文件送进垃圾箱。Linux/Windows 未跑。
