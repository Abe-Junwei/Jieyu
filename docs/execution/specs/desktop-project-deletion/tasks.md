# Tasks — desktop-project-deletion

## 开始条件

- [ ] M1 不扩范围；M2/M3 所需单库 API/宿主已就绪，完成实际入口及写入链 Explore。
- [ ] 核对 schema/API 提案、所有生产/后台写入、默认读过滤和清除/恢复竞态；补齐每片实际文件清单后确认实施。

## D1：删除与恢复

- [x] 文稿 `deleted_at` 为空表示有效。标记删除和恢复各推进 `lifecycle_generation`。普通列表不含已删除文稿，专用列表只含它们。已删除期间正文写入被拒绝。仍在运行的转写使删除不生效。恢复后旧运行不能接受，新运行可以。关掉再打开仍在。不开放删除界面。期限、提醒、录音连带和垃圾箱未做。
- [ ] schema.ts 中必要删除周期/期限/提醒状态，普通查询排除与专用已删除读取。
- [ ] 文稿/录音连带标记与选择性恢复同事务，范围确认和字典。
- [ ] 关闭重开、关联期限保留、不影响其他文稿、AI 只读状态测试；D2 通过前不开放删除入口。

## D2：编辑与任务

- [ ] 保存/停止/等待及失败语义；持久写门禁覆盖所有写入，恢复后旧任务也无效。
- [ ] 受控任务重现删除中/删除后/恢复后的迟到结果，合法新任务仍可写；与 D1 联合验收。
- [ ] 本机转写接入后复用并回归门禁，不为了测试循环提前要求其整单完成。

## D3：期限与项目包

- [ ] 实际展示提醒后至少 7 天，受控时间和重开检查；文稿清除同事务删所属标注备注，保留共享录音。
- [ ] 完整包/备份保留已删除对象及音频，恢复重给提醒窗口；普通文稿导出过滤。
- [ ] 边界时间、长期未开、重新删除、清除与恢复竞态、过期包恢复测试。

## D4：音频收尾

- [ ] 满足全部引用与提醒条件才清除，操作进度入项目库，trash 成功才清登记/来源关联。

- [ ] 磁盘适配失败注入与真实 Electron 临时文件验收；无真实用户数据操作。
