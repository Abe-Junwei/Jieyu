# Requirements — desktop-project-deletion

## 1. 目的与范围

执行 [ADR-0087](../../../adr/0087-project-deletion-retention-and-media-cleanup.md) 的 #325 删除生命周期，不改 M1。文稿标记删除和恢复已写入；期限、提醒、录音连带、删除界面和垃圾箱仍未写。
按四个有依赖的切片交付，每片完成读写、过滤与重开验证；先追实际入口再填实施文件清单。

## 2. 场景

1. 用户删除文稿或录音及其文稿，在项目内已删除列表可恢复，普通查询不再出现其内容。
2. 90 天及实际提醒后至少 7 天均到期，清除文稿；录音还要等无任何文稿引用，之后送系统垃圾箱。
3. 保存/任务停止失败、事务失败、磁盘失败或崩溃，保留可核查状态，不猜测成功、不丢原件。

## 3. 验收

- [ ] 仅用户界面明确发起并确认，AI 无删除/恢复入口，普通内容工具排除已删除内容。
- [ ] 删除/恢复状态多行事务原子；所有普通列表、搜索、统计、导出及后台任务遵守可见性。
- [ ] 删除前保存、停止等待；失败无删除标记，已保存/停止效果不补偿；恢复后旧任务仍不能写。
- [ ] 单独文稿删除保留所有标注/关联；恢复该文稿同时恢复录音，不恢复其他文稿或旧任务。
- [ ] 删除录音的关联文稿期限只延长不缩短；音频窗口内留在项目中。
- [ ] 未展示提醒不清除；最早清除时点为保留期限与本周期提醒展示后 7 天的较晚者；重开一致。
- [ ] 录音清除还需全部文稿已清除；单独清除文稿不删音频，来源最终解除关联不删来源。
- [ ] trash 成功才清理登记；失败/未知有持久进度；同路径替换文件不可被误删。
- [ ] 重新登记新 id；命中尚未清除的已删除录音时提示恢复，不自动恢复文稿。
- [ ] 完整包/备份保留未清除对象与音频；恢复重给提醒窗口，普通文稿导出不含已删除文稿。
- [ ] 当前项目清除不追删旧备份，界面如实说明；首发不做独立隐藏。

## 4. 代码落位候选

- src/db/desktop/schema.ts：删除状态、写入代际与未完成清除记录；manuscripts.ts、media.ts、units.ts 和相关领域查询接门禁。
- 主进程磁盘操作服务与有限 IPC；renderer 仅发有限命令；UI 接项目删除确认、已删除列表和提醒，字典走 dictKeys。
- 各片实际 controller/service、AI 工具与读模型路径在 Explore 后补清单；不新增通用任务编排框架。

## 5. 退出

#325 四片通过、含持久化与真实 Electron 文件操作证据后完成；M4 不替代本验收。触交互跑仓库 E2E，触 AI 跑完整 agent eval。
