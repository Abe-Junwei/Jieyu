# Design — 工程合同与验证边界

## 1. 成熟方案扫描 / Research

- 复用项目单库业务事务、ADR-0091 字段修订、诊断补交、快照文件保护；不另造多库提交或整行覆盖。
- [SQLite 在线备份](https://www.sqlite.org/backup.html)支撑一致数据库快照；数据库快照不等于媒体字节已备份，发布包前仍核文件清单。
- [ANNIS AQL](https://korpling.github.io/ANNIS/4/user-guide/aql/)提供对象＋关系；[操作符](https://korpling.github.io/ANNIS/4/user-guide/aql/operators.html)的 token 覆盖不等于时间重叠，距离单位也不直接照搬。
- [ELAN 多层查询](https://www.mpi.nl/tools/elan/docs/manual/Sec_Multiple_Layer_Search_Tab.html)的时间关系命名可适配；不用其 XML 查询文件冒充解语语言。
- 决定：解语版本化小语言＋既有定位复用；文本／构建器共享结构，无关复杂语法不引入，正式文法在专业查询 SDD 定稿。
- [EAF 3.0 XSD](https://www.mpi.nl/tools/elan/EAFv3.0.xsd)、[TextGrid 格式](https://www.fon.hum.uva.nl/praat/manual/TextGrid_file_formats.html)、[DMLex 1.0](https://docs.oasis-open.org/lexidma/dmlex/v1.0/os/dmlex-v1.0-OS.html)、[LIFT](https://github.com/sillsdev/lift-standard)为格式依据。
- [Leipzig](https://www.eva.mpg.de/lingua/resources/glossing-rules.php)与[gb4e](https://ctan.org/pkg/gb4e)支撑出版表达；LaTeX不当项目往返格式。
- 反模式：IPC未知盲重试、500ms保存全量复制历史、把时间重叠当结构对应、把未复核项筛掉重排、直接覆盖旧文件、把整个50GB包读入内存。
- 已知坑：零语素／不连续／多语与格式损失；EAF当前非标准扩展属性，TextGrid单层重叠、IGT强制连字符均不能据旧测试称支持。
- 本阶段未选正则引擎／新依赖；实现前比较正确性、可终止性、8GB性能、维护、打包体积及许可，不默引 graphANNIS 等第二套引擎。

## 2. 领域状态与一致性

| 维度 | 状态及转换约束 |
| --- | --- |
| 保存 | 内存修改→排队→写入→成功／确认未提交失败／结果未知；仅最新输入持久成功才已保存，未知先查回执 |
| 发布资格 | 合法内容成功保存→正式；不完整内容成功保存→未生效草稿；草稿基准变化→冲突，不能直接覆盖 |
| 分析 | 字段／边界依赖有效→受影响部分待复核→完整依赖校验→分批生效；完整度与有效性不同 |
| 查询 | 准备（IME结束、保存、等写入）→取得全项目锁→执行→完成或取消中→确认退出→解锁；失败准备不能遗留锁 |
| 结果 | 完整／截断／未完成，与最新／过期是两组独立状态，不混成单一布尔值 |
| AI | 运行／本地取消中／本地停止／中断；建议未保存／已保存／过期／曾采纳分开，不把曾采纳当当前有效 |
| 文件 | 预览确认→逐稿完整提交或临时文件生成→校验→发布；原件与已成功稿件不随失败误删 |
| 窗口 | 一写者＋只读观察者；提交后整体版本刷新；退出写者不自动授予另一窗口权限 |

正式模型、投影、字段修订与回执必须共享业务事务；UI只持草稿、选择、焦点与可见状态。项目级协调负责写入准入，不能仅禁用按钮。具体接口签名、回执存储、崩溃核实、文件发布原语仍须专项定稿，未在本轮假定已有实现。

## 3. 最小可执行验收矩阵（全部待产品实测）

| ID／ADR条款 | 入口→数据→读回及故障证据 |
| --- | --- |
| V01／E01 | UI输入→保存→关闭重开同值；500ms／5s与IME；旧回执晚到不盖新输入；提交后断IPC查询回执仅一次效果 |
| V02／E01–02 | 每种离开入口等待／重试／放弃；字段列表准确；已保存未生效草稿重开可续，非法时间不污染正式时间 |
| V03／E03 | 改字、重复词、边界合拆→局部失效→重开→检索／统计／AI／导出同一资格；只gloss过期不阻词序；无关gloss修改不废另一词建议，依赖改回同值仍按修订拒旧建议 |
| V04／E04 | 两对象批量修改→任一对象撤销→所有读回恢复；后改阻止；历史恢复／清理保护待复核和对象恢复能力 |
| V05／E05 | 全DMLex字段含重复／嵌套保存重开；义项改后gloss不动；首次填空、换义项可选；例句来源快照差异 |
| V06／E06 | 同层拒重叠、跨层允许；手输／拖动／联动；舍入、共边点、零时长和终端点；映射非整数scale的正逆换算、量化位置和塌缩；拆合引用与迟到任务 |
| V07／E07 | 各宿主×类型×重复／多语／引用写重开查询；定义变更不全合规则不提交；冲突不盖新值；必填阻清除 |
| V08／E08 | 两窗口同时打开单写者；整体刷新；只读查询先等IME保存；主窗口取消；写者退出不自动接管 |
| V09／E09 | 默认范围、锁前保存失败、并发AI内存候选、取消5s升级、线程崩溃、迟到结果、超时和限条均确认解锁 |
| V10／E09–10 | 固定答案集验证对象作用域、否定缺值、距离、结构／时间关系、同范围合并、稳定截取、版本过期定位 |
| V11／E10 | 文本→构建器→文本语义等价；超能力文本保留／只读；非法、失效引用、复杂度和正则准确错误位置 |
| V12／E11 | 重复AI请求复用、未知云结果不重发、按依赖冲突整批不写；重新对应后人工提交；退出拒迟到结果 |
| V13／E11 | 多文件导入第n稿注错，仅本稿回滚，共享依赖和前稿保留；重复文件不盖原稿；取消退出清理完成 |
| V14／E11 | 错媒体指纹阻重定位；新录音迁移新身份、原引用保留；未核时不进时间用途，文本有效项仍可用 |
| V15／E12 | 编辑中取快照→继续编辑→包仅包含快照版本；复制中清理不得移媒体；写满磁盘／取消保旧目标文件 |
| V16／E12 | 已保存版导出与未保存恢复文件区分；草稿冲突逐项解决；含媒体包恢复副本，历史／字段／草稿读回 |
| V17／E12 | EAF XSD及ELAN保存再导回；TextGrid区间／点经Praat；DMLex schema及独立读取；LIFT经FLEx；LaTeX实际编译 |
| V18／E13 | 损坏立即停写且可抢救；诊断无研究正文／凭据；键盘、IME、焦点、两主题、字体放大与减少动态实测 |
| V19／E14 | 受控合成容量、记录硬件／构建／数据种子；冷／热P95和全部进程内存；普通编辑和文件任务交叉运行 |

每条记录 build、入口、输入、基准版本、预期／实得、失败注入点、重开读回和证据路径；不以mock调用数或静态画板替代。准确用例与测试文件在每个实施切片确认，现有通用命令不冒充这些新增用例已存在。

| 合成数据／性能／快捷键／代码分片 | [执行验收](../desktop-engineering-verification/design.md) |

这些是已确认行为的技术实现提案，保持draft供审阅；不等于用户已批准具体新增依赖、接口编码或产品能力已交付。回执/草稿、字段载荷、JQ1、ZIP64适配均未实施；包装器版本、包体积、资源初值及平台文件替换能力须实测锁定。没有把数值目标写成测得结果。

`corpusQuery.ts`当前为基础筛选，`openProject.ts`占用报busy不是只读会话；`projectExchange.ts`32MiB同步ZIP和直接writeFile也不满足新容量/发布合同。当前EAF非标准绑定属性、TextGrid单层重叠/点、IGT强制连字符、DMLex顶层子集和LIFT截取缺口已逐项纳入格式矩阵。

2026-11-01先前核查的6个格式测试78项只证明既有子链；后续最新定向命令与结果另记，不与新增接口/外部工具或8GB性能验收混用。

## 5. 后续实施边界与验证

`state`留controller管理草稿／焦点；`derived`纯函数处理资格／映射；`effect/actions`走领域service和主进程事务；`routing`仅透传上下文。不在页面累积数据库流程。优先复用上述入口，具体新文件须切片Plan确认；遵守300行／12hooks、两层边框及默认关闭flag的规则。

本轮文档验证：`npm run check:docs-governance`、`npm run check:spec-research-filled`、`git diff --check`。后续产品每片必有`npm run typecheck`、定向vitest，交互含`npm run test:e2e:chromium`及Electron实际入口；AI、结构守卫按触及域执行。技术设计未齐、不宣称进入实现。

## 6. 2026-11-01 规格一致性审查结论

已修正：prepare锁死自身flush、退出先保存而被查询锁阻塞、未提交结果缺迟到请求栅栏、旧版本重试压过新输入、备份快照至媒体pin的竞态、主文件/报告假原子与替换结果未知；并补齐多值否定、跨段缺有限关系、媒体轴小数时间、复合义项身份和字段迁移集合漂移。具体反例随对应专项稿保留，后续必须实现故障断言。

本轮只通过文档静态一致性审查；包装器/ZIP64/文件原语的实测锁定、载荷版本冻结、外部工具往返及8GB容量仍未通过。不能把审查通过当作任何产品门通过，代码实施仍须首片Plan确认。
