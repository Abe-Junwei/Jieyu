# 录音层转写模型接入（范围已校正，精稿待确认）

## 1. 目标与边界

- 口译和语音转录层均可从已保存录音调用模型，生成对应文字子层草稿；用户确认才保存正文。
- 先交付本机 Whisper，再接一种已有回环 HTTP 服务；云与局域网分期，不静默回退。
- 不做边录边识别、说话人分离、强制对齐、自动翻译、任意权重运行或批量自动覆盖。
- 阶段 A 归切片 **5a**（不是1b或5b）：记住本机模型配置、两类已存录音识别与草稿确认、超过 30 秒的硬切；阶段B/C/D（随包引擎、模型下载、任意格式转码、已有服务与云端）归第二程 #285，与仍打开的 #303/#305 一起处理。默认关闭，不关闭 #303/#305/#306，不增加首发阻断。

- #603已交付的口译短录音保存、播放和转文字不重做；1b继续时间、拆合与无录音文稿。5b听写属助手对话，走ToolLoopAgent；录音层继续既有草稿确认。

## 2. 用户场景

1. 首次选择本机模型并完成检测；重开应用恢复配置、重新验证资源，再从录音卡片直接转写。
2. 为不同语言的口译/语音录音指定识别语言；超过 30 秒仍完整处理，结果进入自己的文字子层。
3. 专业用户选择已支持的服务协议、地址和模型，测试后使用；服务失败保留音频并可重试。

## 3. 验收标准

- [ ] 两类录音均走 source fileId + session/unit/layer 固定身份；不误用主媒体或另一个录音。
- [ ] 重启恢复模型配置，但不自动重跑任务；资源丢失/哈希改变时不可继续使用旧授权。
- [ ] 未配置/模型缺失/无权限/忙碌/超时/静音或空结果均有明确恢复入口，不写伪候选。
- [ ] 层 language_id 仅在明确映射到该模型支持码后传入；无法映射时让用户本次选择支持语言或显式自动检测。不裁剪 ISO 639-3、自定义码、Glottocode、BCP-47 或界面 locale 猜参数。
- [ ] 后端允许则整段，否则按 maxAudioSec 无重叠硬切，包含末块；全部成功才交一份草稿，任一失败不提交。硬切可能切开词或在边界重复，A 不承诺消除该误差。
- [ ] 切项目/关窗/主动取消后无迟到写入；本机子进程退出、临时文件释放；自建服务不被杀掉。
- [ ] 源录音替换/删除或目标文字草稿变化后，旧结果拒绝；已有文字不覆盖，确认读回来源一致。
- [ ] 不支持的字段不发送，不伪造词时间和置信度；不把转写识别成翻译。
- [ ] 候选面板与两类录音卡片入口共用默认关闭开关；关闭时不可触发转写，开启且未配置时有准备入口。
- [ ] B 阶段普通用户本机路径不依赖终端环境变量；Mac arm64 和 Windows x64 随包分别验收。
- [ ] 外发需项目授权且注明目的地；密钥不进项目/导出/日志；本机失败不自动上传。

## 4. 代码地图

| 域 | 复用落位 | 拟改动 |
| --- | --- | --- |
| Electron | `electron/main.ts`、`electron/preload.ts`、`src/desktop/projectReadHost.ts` | 受限配置/检测/取消 IPC；进程生命周期 |
| 调用 | `src/desktop/projectTranscription.ts`、`modelHost.ts`、`localWhisper.ts` | 配置恢复、语言、任务身份、分块与提供方适配 |

| 页面 | `src/pages/oralControllerApi.ts`、`TimelineTranslationAudioControls.tsx` | 选择模型引导、状态、取消与重试 |
| 配置UI | 既有设置宿主及独立页面 controller | 本机/服务配置，不向页面放持久化或推理逻辑 |
| 测试/打包 | `src/desktop/*.test.ts`、`tests/e2e-desktop/`、`electron-builder.yml` | 契约、真引擎、重开、退出与安装包 |
