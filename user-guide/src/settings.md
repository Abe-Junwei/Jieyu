# 设置与快捷键

统一设置入口标题为 **设置**（关闭为「关闭设置」）。标签页：**外观**、**语言**、**快捷键**、**AI**、**播放**、**数据**、**关于**。

默认快捷键定义在 `src/services/KeybindingService.ts`，可在设置里改，并可用「恢复默认 / 全部恢复默认」。

## 目标

**打开设置 → 按需改外观/语言/播放默认 → 查阅或自定义快捷键 → 用空格在波形区验证播放/暂停。**

## 适用场景

- 换浅色/深色、界面中英文、字号。
- 记不住快捷键，或与系统冲突需要改键。
- 调整默认播放速度、跟随选区、双击波形行为。

## 前置条件

能打开解语主界面。部分 **AI**、**数据** 项依赖构建与环境，本页只列用户可见标签，不展开未开启的供应商配置细节。

## 界面定位

应用壳上的设置按钮（语音控件旁常见齿轮一类入口；无障碍名以「设置」相关文案为准）→ 对话框 **设置**。

也可在转写台使用备注等入口间接触达相关面板；**快捷键总表以设置 → 快捷键为准**。

## 逐步操作

### 1. 外观

1. 打开 **外观**。
2. **主题**：浅色 / 深色 / 跟随系统。
3. 可调配色方案、主题色、字体缩放（自动/手动）、图标效果（Material 默认 / 动效增强）。动效会在系统「减少动态效果」时自动关闭。

### 2. 语言

1. 打开 **语言**。
2. **界面语言**：中文 / English。  
   使用说明网站英文页仍为占位；应用内英文界面与本站中文教程并行时，以你当前界面语言为准。

### 3. 快捷键

1. 打开 **快捷键**。
2. 分类：**播放控制**、**编辑操作**、**导航**、**视图**、**语音智能体**。
3. 点一项 → 「请按下快捷键…」录入；**Esc** 取消。
4. **恢复默认** 或 **全部恢复默认**。

#### 默认快捷键一览

**全局（输入框聚焦时通常仍生效的一类）：**

| 动作 | 默认 |
| --- | --- |
| 撤销 | Mod+Z |
| 重做 | Mod+Shift+Z 或 Mod+Y |
| 搜索替换 | Mod+F |
| 切换备注面板 | Mod+Shift+N |
| 语音智能体 | Mod+Shift+. |

**波形区（焦点在波形、且不在文本输入时）：**

| 动作 | 默认 |
| --- | --- |
| 播放/暂停 | Space |
| 标记句段 | Enter |
| 取消 | Escape |
| 删除句段 | Delete 或 Backspace |
| 合并上一个 | Mod+Shift+M |
| 合并下一个 | Mod+M |
| 分割句段 | Mod+Shift+S |
| 选到开头 / 结尾 | Shift+Home / Shift+End |
| 全选 | Mod+A |
| 上一 / 下一句段 | ← / → |
| Tab 播放下一 / 上一 | Tab / Shift+Tab |
| 后退 / 前进一帧 | , / . |
| 下一 / 上一低置信度句段 | ] / [ |

**其它：**

| 动作 | 默认 |
| --- | --- |
| 批量句段操作面板 | Cmd/Ctrl+Shift+B（批量面板提示文案） |

`Mod` = macOS 上的 Meta（⌘），其它系统多为 Ctrl。

### 4. 播放

打开 **播放**，常见项：

- 默认播放速度  
- 自动跟随选中语段  
- 吸附到零交叉  
- 默认缩放模式：适应全部 / 适应选区 / 自定义  
- 视频布局：上方 / 左侧 / 右侧；预览高度、右侧面板宽度  
- 波形双击：缩放到选区 / 按双击区间创建语段  
- 新建语段后：自动选中新建 / 保持当前选中  

改完后到转写台用一条短媒体验证空格播放与双击行为。

### 5. AI / 数据 / 关于

- **AI**：选择服务商与密钥等（完整连接测试常在 AI 对话面板中进行，以界面说明为准）。
- **数据**：本地数据相关选项（备份仍建议用 [导入导出与备份](/export) 的 JYT/JYM/JYB）。
- **关于**：版本与产品信息。

具体子项随版本增减；以你安装的对话框为准。

## 结果核对

| 核对项 | 期望 |
| --- | --- |
| 主题/语言 | 界面立即或重载后符合选择 |
| 快捷键 | 波形区 Space 能播放/暂停（未改键时） |
| 自定义键 | 列表显示「已自定义」；恢复默认后回去 |
| 播放默认 | 新的播放速度对后续播放生效 |

## 常见问题与处理

1. **快捷键没反应** → 焦点是否在文本框；波形类快捷键需要波形区焦点。  
2. **与系统快捷键冲突** → 在设置里改掉该动作。  
3. **英文界面但教程是中文** → 对照侧栏图标位置，或把界面切回中文阅读本站。
