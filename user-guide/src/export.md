# 导出与建档

::: warning 占位
档案导出 / 建档排在存储冻结解除之后。桌面版要先能打开真项目（[ADR-0064](https://github.com/Abe-Junwei/Jieyu/blob/main/docs/adr/0064-storage-freeze-until-desktop-opens-real-projects.md)）。本页不提供导出步骤。
:::

工作区的末端是把材料带出项目：导出，以及把一次调查收成可归档的包。冻结解除、建档导出可用之后，再在这里写格式、入口和检查方式。

在那之前，不要按本页操作。应用里若已有别的导出入口，以其界面和仓库里的工程师文档为准。
