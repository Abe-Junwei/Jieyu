# 导入导出与备份

本页写**应用里已经出现的交换与备份入口**（转写工具栏「导入与导出」分组、项目中心）。  
**档案级「建档」流程**仍受桌面存储冻结影响，文末单独占位——不要把占位节当成可点步骤。

## 目标

学会区分四类动作，并完成至少一次导出核对：

1. **导入媒体**（音视频文件）— 详见 [录音与转写](/recording)  
2. **导入标注文件**（EAF / TextGrid / TRS / FLEx / Toolbox）  
3. **导入项目或备份**（`.jyt` / `.jym` / `.jyb`）  
4. **导出**交换格式、字幕/表格、项目包与整库备份  

## 适用场景

- 与 ELAN / Praat / FLEx / Toolbox 交换层与时间码。
- 把当前项目备份成 JYT（无音频）或 JYM（含音频）。
- 整库备份 JYB（含或不含音频）。
- 出字幕（SRT/VTT）或表格（CSV/TSV）、Leipzig IGT LaTeX。

## 前置条件

1. 导出 **JYT / JYM** 前必须先打开项目（否则提示请先打开项目再导出）。
2. 大包可能触发「过大」类失败提示；先用小项目练习。
3. 读懂：**项目包不能走「导入标注」**——会提示改用「导入项目」。

## 界面定位

| 入口 | 文案 |
| --- | --- |
| 工具栏分组 | 「交换」/「导入与导出」 |
| 导出菜单总览 | 「导出 EAF / TextGrid / TRS / FLEx / Toolbox / JYT / JYM / SRT / VTT / CSV / TSV」 |
| 导入菜单总览 | 「导入 EAF / TextGrid / TRS / FLEx / Toolbox / JYT / JYM」 |
| 项目中心 | 「导入项目或备份（.jyt / .jym / .jyb）」「导入标注文件（EAF/TextGrid/TRS/FLEx/Toolbox）」；「导出」分区 |
| 时间戳说明 | 导出时间戳按**项目逻辑时间轴（文献秒）**标注；与解码媒体时间轴秒数不一定一一对应 |

| 导出为 TextGrid | Praat；「TextGrid 已导出。」 |
| 导出为 Transcriber (.trs) | 「TRS 已导出。」 |

| 导出为 Toolbox (.txt) | 「Toolbox 已导出。」 |
| 导出当前项目为 JYT（不含音频） | 仅当前项目 |
| 导出当前项目为 JYM（含音频） | 含录音与附件 |
| 导出整库备份 JYB（含音频，默认） | 整库 |
| 导出整库备份 JYB（仅数据，不含音频） | 整库无音频 |
| 导出原始恢复快照（.zip，含音频） | 原样数据，不是 JYB；导入需走对应「从原始恢复快照导入」路径 |

## 逐步操作

### A. 导出交换格式（例：EAF）

1. 打开目标项目与媒体，确认句段与层符合预期。
2. 打开工具栏 **导出** 菜单 → **导出为 EAF (.eaf)**。
3. 等待「EAF 已导出。」类提示；在下载目录打开用 ELAN 等检查媒体链接与层。

其它格式同理，选对应菜单项。

### B. 导出当前项目 JYT / JYM

1. 确认已打开项目。
2. 选 **导出当前项目为 JYT（不含音频）** 或 **JYM（含音频）**。
3. 完成提示应区分「不含音频」与「含录音与附件」。
4. JYM 过大时会失败提示；可改 JYT 或精简媒体。

### C. 整库 JYB 备份

1. 选 **导出整库备份 JYB（含音频，默认）** 或 **不含音频**。
2. 保管好文件；不含音频的包恢复后录音可能显示为缺失，需再挂接。

### D. 导入标注文件

1. 项目中心或导入菜单 → **导入标注文件（EAF/TextGrid/TRS/FLEx/Toolbox）**。
2. 按对话框选择层角色与冲突处理（以当前版本对话框为准）。
3. **不要**把 `.jyt` / `.jym` 丢进这个入口。

### E. 导入项目或备份

1. **导入项目或备份（.jyt / .jym / .jyb）**。
2. JYB 可能要求选择：逐项目导入、灾难恢复、是否恢复偏好、是否含 AI 记忆等——逐项阅读警告。
3. 若提示覆盖会丢掉本机录音字节，优先改为「恢复为新项目」或先导出含音频备份。
4. 覆盖类操作常需**再点一次确认**；覆盖前可能自动存快照。

## 结果核对

| 动作 | 期望 |
| --- | --- |
| 导出 EAF 等 | 完成 toast；外部工具能打开 |
| JYT/JYM | 文件生成；JYM 体积明显大于 JYT（有音频时） |
| 导入标注 | 句段/层出现在转写台；媒体仍可能需单独导入 |
| 导入项目 | 首页出现项目或当前项目内容按模式更新 |
| 未混用入口 | 未对项目包使用「导入标注」 |

## 常见问题与处理

1. **JYT/JYM 提示先开项目** → 先新建或打开项目。  
2. **JYB 灾难恢复被禁用** → 读「会丢掉本机 … 字节」类说明；先导出含音频包。  
3. **逻辑秒 vs 媒体秒** → 以项目中心导出说明为准，字幕轴若错位先核对逻辑时间轴。  
4. **加密导出** → 若出现「加密项目文件已导出」类提示，按当时对话框保管口令（本站不臆造口令流程）。
