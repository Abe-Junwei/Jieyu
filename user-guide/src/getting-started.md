# 快速开始

按教程体写：先定目标，再列前置，再逐步操作，最后核对结果和常见坑。按钮名称以你当前安装的界面文案为准（中文界面示例见下文）。

## 目标

在本机完成解语的第一条最短路径：

**新建项目 → 导入一条录音（媒体）→ 切出语段并写下一句转写 → 确认材料还在当前项目里。**

走完后，你就知道「一次田野工作」在解语里落在哪里，以及下一步该去哪一页。

## 前置条件

1. **能打开解语。** 公开安装包的下载步骤还没写进本说明。从源码启动见仓库 [README](https://github.com/Abe-Junwei/Jieyu/blob/main/README.md)：安装依赖后执行 `npm run dev`。产品目标是桌面应用；浏览器构建主要用于开发与测试，不作为对终端用户的支持承诺。
2. **准备一条短录音。** 转写工作区「导入音视频」对话框支持的常见格式包括：MP4、MP3、WAV、WebM、MOV、MKV、OGG、M4A、FLAC。先用一两分钟的文件练习即可。
3. **知道数据在哪。** 录音、转写、标注和词典默认留在**本机当前项目**里。协作同步另见 [协作与同步冲突](/collaboration)（该页仍是占位）。

## 逐步操作

### 1. 打开应用并进入工作台

1. 启动解语后，你会看到**工作台首页**（侧栏或顶栏里可回到「工作台」一类入口）。
2. 首页用来查看**本地转写项目**，以及每条**声文稿**（主时间轴上的声学媒体）上的进度。
3. 若列表是空的，会提示还没有项目——这是正常起点。

### 2. 新建项目

1. 打开转写工作区（首页「进入转写」，或侧栏进入转写相关入口）。
2. 在工具栏点 **新建项目**。
3. 在「新建项目」对话框里至少填写：
   - **项目主显示名**（例如：白马藏语田野调查）
   - **目标语言**（可从列表选，或选「其他」后填 ISO 639-3 三字母代码）
   - 按需要添加**工作语言**、选择或新建**正字法 / 书写系统**
4. 点 **创建项目**。成功后界面会提示类似「项目创建成功，请导入媒体」。

> 没有活动项目时，词典、语言目录等页面只会显示「请先选择项目」，不会读写目录数据。先建好项目再往下走。

### 3. 导入一条媒体

1. 确认当前已打开刚建的项目。
2. 点工具栏 **导入媒体**（空时间轴上也可能看到「导入媒体文件」一类入口）。
3. 在「导入音视频」对话框中选择文件，确认格式在支持列表内。
4. 若项目里已有媒体或占位轴，对话框可能让你选择：
   - **覆盖当前所选媒体**（语段仍绑同一媒体 ID，适合换成同一录音的更新版）
   - **新增一条媒体轨**（新建独立媒体行）
5. 若文件时长与当前逻辑时间轴不一致，按对话框提示阅读说明后再确认导入。
6. 导入成功后应看到时间轴 / 波形区域出现可播放的媒体，并有「媒体 … 导入成功」一类提示。

### 4. 切出语段并写转写

任选一种入门方式（不必一次全会）：

1. **自动分段：** 工具栏 **一键 VAD 自动分段**（运行中会显示「自动分段运行中…」）。完成后会提示新建了多少个句段。
2. **手动建段：** 在波形或时间轴上用拖选 / 套索划出一段时间范围，松开后生成句段（界面上常称为「句段」或「语段」）。
3. **改边界：** 在句段上用右键或浮层菜单做 **拆分句段**、**合并**、**删除** 等（具体菜单项以当前版本为准）。
4. **写正文：** 选中一个句段，在转写层编辑区输入对象语言转写文本并确认已写入（可选中后播放该段核对听感）。

更细的导入模式、VAD、拆分合并与核对清单见 [录音与转写](/recording)。

### 5. 回到首页核对进度（可选）

1. 打开工作台首页。
2. 在「转写项目」列表里找到当前项目。
3. 进度里的「转写」大致表示非空语段占比；有媒体时也会汇总音频时长等信息。数字不必完美，只要能看到项目和媒体即可。

## 结果核对

走完上面步骤后，应同时满足：

| 核对项 | 期望 |
| --- | --- |
| 项目 | 首页或项目中心能看到刚建的项目名称 |
| 媒体 | 转写工作区能播放刚导入的文件 |
| 语段 | 时间轴上至少有一个句段（自动或手动） |
| 转写 | 至少一个句段有非空转写正文 |
| 落点 | 以上都还在**同一个本地项目**里，没有要求你先做云端同步 |

若某一步对不上，先看下方「常见坑」，再对照 [录音与转写](/recording) 的坑节。

## 常见坑

1. **还没有公开安装包说明。** 目前按仓库 README 从源码启动；不要假设应用商店或独立安装包已经就绪。
2. **先建项目再导入。** 未创建项目时，导入与许多目录页会直接要求你先选项目或创建项目。
3. **多条占位时间轴时要先选对轴。** 若提示「请先在时间轴上选中要挂接音频的那一条，再导入」，先点选目标轴再点导入媒体。
4. **浏览器构建 ≠ 产品承诺。** 开发时可用浏览器打开；对使用者的产品形态以桌面为准。数据默认在本机，换电脑或清站点数据可能导致看不到原项目（备份与交换包细节见导出相关页；建档导出在存储冻结解除前仍是占位）。
5. **标注 / 导出先别深挖。** Morph、B4 行际操作说明，以及解冻后的建档导出，本站仍标为稍后补全；本教程只保证「能进转写路径」。
