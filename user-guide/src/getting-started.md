# 快速开始

按教程体写：目标 → 适用场景 → 前置 → 界面定位 → 逐步操作 → 核对 → 常见坑 → 下一篇。按钮名称以当前中文界面为准。

## 目标

在本机走通解语最短路径：

**新建项目 → 导入一条媒体 → 切出语段并写下一句转写 → 在首页看到该项目与进度。**

走完后，你就知道「一次田野工作」落在哪个本地项目里，以及侧栏下一步该去转写细页还是标注/词典。

## 适用场景

- 第一次打开解语，想确认「能建项目、能听见、能写字」。
- 给同事演示：一分钟内从空工作台到一句转写。
- 不适合：完整 IGT、整库备份策略、多人同步——那些见后文链接。

## 前置条件

1. **能打开解语。** 公开安装包下载步骤还没写进本说明。从源码启动见仓库 [README](https://github.com/Abe-Junwei/Jieyu/blob/main/README.md)：安装依赖后执行 `npm run dev`。产品目标是桌面应用；浏览器构建主要用于开发与测试，不作为对终端用户的支持承诺（见 [ADR-0064](https://github.com/Abe-Junwei/Jieyu/blob/main/docs/adr/0064-storage-freeze-until-desktop-opens-real-projects.md)）。
2. **准备一条短录音或视频。** 「导入音视频」对话框支持：**MP4、MP3、WAV、WebM、MOV、MKV、OGG、M4A、FLAC**。建议先用一两分钟的文件练习。
3. **知道数据在哪。** 录音、转写、标注和词典默认留在**本机当前项目**里。协作同步见 [协作与同步冲突](/collaboration)（该页说明未落地边界）。
4. **可选：麦克风权限。** 本教程主路径是「导入已有文件」。若稍后要在翻译层点「开始录音翻译」，浏览器/系统需允许麦克风（详见 [录音与转写](/recording)）。

## 界面定位

| 你要找的 | 在哪 |
| --- | --- |
| 工作台首页 | 侧栏 **首页**（文案「工作台首页」），路由 `/` |
| 转写工作区 | 侧栏 **转写**，或首页 **进入转写**，路由 `/transcription` |
| 新建项目 | 转写工具栏 **新建项目**（项目分组） |
| 导入媒体 | 转写工具栏 **导入媒体**；空时间轴也可能显示 **导入媒体文件** |
| 项目列表 / 切换 | 工具栏旁 **打开项目中心**；首页项目卡片 **打开项目** |
| 进度含义 | 首页副标题：「查看本地转写项目与每条媒体（声文稿）上的进度」 |

术语：**声文稿** = 主时间轴上的一条声学媒体（不含纯逻辑占位行、也不含译文附属录音行）。

## 逐步操作

### 1. 打开应用并进入工作台

1. 启动解语后，侧栏点 **首页**，应看到「工作台首页」。
2. 若「转写项目」列表为空，会提示还没有项目——这是正常起点。
3. 点 **进入转写**，或侧栏 **转写**，进入转写工作区。

### 2. 新建项目

1. 在转写工具栏点 **新建项目**（对话框标题同为「新建项目」）。
2. 至少填写：
   - **项目主显示名**（占位例：白马藏语田野调查）
   - **目标语言**（从列表选；或选 **其他（手动输入 ISO 639-3 代码）** 后填三字母代码，如 `bfy`）
3. 按需要：
   - 填 **项目英文回退名**
   - 点 **再加一种目标语言** / **添加工作语言**
   - 选或 **新建** **正字法 / 书写系统**（没有可用正字法时会有提示）
4. 点 **创建项目**（创建中会显示「创建中...」）。
5. 成功后应看到类似：**项目「…」创建成功，请导入媒体。**

> 没有活动项目时，词典等页面会要求你先打开项目（例如「先打开一个项目。词典只显示这一份项目的词条。」）。先建好项目再往下走。

### 3. 导入一条媒体

1. 确认顶栏 / 项目中心显示的是刚建的项目。
2. 点 **导入媒体**。对话框标题为「导入音视频」一类；点 **点击选择音视频文件**，选文件后 **确认导入**。
3. 若项目里已有可选中的媒体，对话框可能让你选：
   - **覆盖当前所选媒体**：语段仍绑同一媒体 ID（换同一录音的更新版时优先）
   - **新增一条媒体轨**：新建独立媒体行；旧语段仍挂在原先媒体上
4. 若文件时长与当前逻辑时间轴不一致，先读完对话框说明，再勾选「我已了解，继续导入」一类确认。
5. **多条占位轴**：若提示先选中要挂接音频的那一条，先在时间轴点选目标轴再导入。
6. 成功后应能播放，并有「媒体 … 导入成功」一类提示。

**硬限制（来自代码）：** 体积过大（约超过 512 MiB）或时长超过约 **3 小时** 时，应用可能**取消导入**或**跳过波形解码**（文字时间轴仍可能可编辑）。练习请用短文件。详见 [录音与转写](/recording)。

### 4. 切出语段并写转写

任选一种入门方式：

1. **自动分段：** 工具栏 **一键 VAD 自动分段**（运行中变为「自动分段运行中…」）。结束后应提示新建了多少句段。  
   - 默认分段参数（代码）：最短约 **0.3 秒**、单段最长约 **30 秒**、邻近语音间隔合并约 **0.3 秒**。过碎或过长可用手动拆合调整。
2. **手动建段：** 在波形或时间轴空白处拖选一段时间范围，松开后生成句段。
3. **改边界（可选）：** 播放头停在句段内 → **从当前位置拆分句段** / **拆分句段**；选中相邻句段 → **合并** / **向前合并** / **向后合并**；删除时若有正文通常会二次确认。
4. **写正文：** 选中句段，在**转写层**编辑区输入对象语言文本。可用空格播放/暂停（焦点在波形区时；见 [设置与快捷键](/settings)）。

### 5. 回到首页核对进度（推荐）

1. 打开 **首页**。
2. 在转写项目列表找到当前项目；可点 **打开该声文稿（定位到对应媒体）**。
3. 进度里「转写」大致 = 非空语段占比；也可能汇总音频时长。数字是快照，大改后可在转写台点 **刷新数据**。

## 结果核对

| 核对项 | 期望 |
| --- | --- |
| 项目 | 首页能看到刚建的项目主显示名 |
| 媒体 | 转写工作区能播放刚导入的文件 |
| 语段 | 时间轴上至少有一个句段 |
| 转写 | 至少一个句段转写层非空 |
| 落点 | 都在同一本地项目，未要求先做云端同步 |
| 导航 | 侧栏 **标注** / **词典** 可点开（无项目时词典会提示先开项目） |

## 常见坑

1. **还没有公开安装包说明。** 目前按 README 从源码启动。
2. **先建项目再导入。** 未创建项目时导入会要求先创建项目。
3. **选错导入方式。** 「新增媒体轨」不会自动把旧语段挂到新文件；换同一条录音的新版本优先「覆盖」。
4. **占位轴未选中。** 多条占位时间轴时必须先点选再导入。
5. **文件过大/过长。** 触发波形保护后不要反复点确认导入；换短文件或只做文字时间轴编辑。
6. **浏览器构建 ≠ 产品承诺。** 清站点数据可能导致看不到原项目；重要材料请尽早用 [导入导出与备份](/export) 做 JYT/JYM/JYB。
7. **分析页写着「受限工作台」。** 入门阶段不必进入分析。
