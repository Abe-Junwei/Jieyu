# 标注与 IGT

标注工作台（侧栏 **标注**，路由 `/annotation`）在**已有转写句段**上做行际标注（IGT）：切词、写 gloss/词性、切词素、链接词典、播放句段、写备注与自我确信度。**原文与时间码在此页只读**——要改转写正文或边界，请回 [录音与转写](/recording)。

> 功能开关：`featureFlags.annotationPageEnabled` 默认 **开启**。若构建用环境变量关掉，页面会显示「标注工作台未开放」占位，而不是本教程步骤。

## 目标

对一条已转写句段完成：

**打开标注工作台 → 选中句段 →（可选）切成词 → 填写 gloss/词性 →（可选）按 -/= 分词素并保存 →（可选）链接词典 → 播放核对 → 保存状态为「已保存」。**

## 适用场景

- 转写层已有正文，要做 Leipzig 式行际。
- 需要把词链到项目词典，或预览自动对译建议。
- 不适合：还没导入媒体、还没有句段——请先完成转写路径。

## 前置条件

1. 当前项目里至少有一条带正文的转写句段（见 [快速开始](/getting-started)）。
2. 从侧栏进入 **标注**，或从转写相关入口跳转「在转写中打开」的反向路径。
3. 若列表为空：会看到「还没有可浏览的转写记录。请先打开转写工作台。」——点 **打开转写工作台**。

## 界面定位

| 元素 | 文案 |
| --- | --- |
| 页标题 | 标注工作台 |
| 摘要 | 编辑当前转写范围内句段的词性、gloss、词素与词典链接；可播放句段、写备注与自我确信度，并预览后采纳自动对译。原文与时间码只读。 |
| 侧栏 | 当前句子 / IGT 列表 |
| IGT 行名 | 词、语素形式、标注、词性、词目、直译 等 |
| 行操作 | 加一层、上移、下移、删除这一层 |
| 词操作 | 切分、与下一词合并、删除词、编辑词义和词性 |
| 词素 | 按 -/= 分词素、保存词素 |
| 词典 | 链接词条、解除链接、义项选择 |
| 播放 | 播放句段 / 暂停 |
| 自动对译 | 预览自动对译、采纳建议 |
| 备注 | 备注、备注分类、保存备注；自我确信度（不理解/不确定/确定） |
| 导出此句 | 下载 CLDF / CoNLL-U / Ligt / LaTeX；以及 FLEx/ELAN **说明**（说明文件，不是整项目 EAF 导出——整项目交换见 [导入导出与备份](/export)） |

键盘提示（界面原文摘要）：行聚焦时**空格**播放或暂停当前句段；输入态空格写入格子。**Enter** 保存并留在当前行；**Ctrl+Enter** 仅在保存成功后跳下一行。

## 逐步操作

### 1. 进入并选中句段

1. 侧栏点 **标注**。
2. 在列表中选一句；侧栏「当前句子」应显示原文摘要。
3. 需要听原声时点 **播放句段**（无媒体时提示「当前句段没有可播放的媒体」或「这一句没有可画的录音」）。

### 2. 切成词

1. 若还只有整句表面形式，使用 **切成词**（或工作台提供的分词入口）。
2. 可用 **切分** / **与下一词合并** / **删除词** 调整 token。删除词时若已有语素或词典链接，会提示将失去多少条。
3. 可选 **预览二次分词** → **确认二次分词** / **覆盖分词**（以界面是否提供为准）。

### 3. 填写 gloss 与词性

1. 在 **标注（gloss）**、**词性** 等行编辑对应格子。
2. 可用 **编辑词义和词性**；批量类操作如 **应用到同形词**、**按这个注释其余同形**（有则用之）。
3. 关注保存状态：**正在保存** → **已保存**。若「已写入，视图还没刷新」，可 **重新刷新**。

### 4. 词素（Morph）行

1. 在词的形式中用 `-` 或 `=` 标出词素边界（例如 `abc-def`）。
2. 点 **按 -/= 分词素**。若形式中没有 `-` 或 `=`，会提示「词素切分需要形式中含 - 或 =」。
3. 编辑 **词素形式** / **词素 gloss** 后点 **保存词素**。
4. 行显示名：**语素形式**。更复杂的关系（并入、交替形、异干、声调等）以界面「关系」菜单实际出现的项为准；没有的项不要当作已交付。

### 5. 链接词典

1. 选中词 → **链接词条**；选择义项（「义项：…」）。
2. 成功后可见「已链接 {lemma}」；可 **解除链接**。
3. 若提示词条引用断裂，到 [词典](/lexicon) 检查词条是否还在。

### 6. 备注、确信度与自动对译

1. **备注** + **备注分类**（评论/问题/待办/语言学/田野/修订）→ **保存备注**。
2. **自我确信度**：未标记 / 不理解 / 不确定 / 确定。
3. **预览自动对译** → 核对「形式 → gloss」建议 → **采纳建议**。无建议时：「没有可采纳的自动对译建议。」

### 7. 结构校验与模板（可选）

侧栏或面板可能出现 **结构校验**、**打开标注模板**、Leipzig 缩写提示等。校验失败或「需复核」时，按提示改 gloss 或模板，不要强行当作已通过。

### 8. 导出当前句（可选）

**导出** / **导出此句** 菜单中的 CLDF、CoNLL-U、Ligt、LaTeX 等针对**当前句分析**。整轨/整项目 EAF、JYM 等走转写台交换菜单。

## 结果核对

| 核对项 | 期望 |
| --- | --- |
| 范围 | 能看到句段列表，不是「标注工作台未开放」 |
| 只读边界 | 改时间码/整句转写需回转写台 |
| Token | 词行有合理切分 |
| Gloss/POS | 保存状态为已保存 |
| 词素（若做） | 分词素成功且可再打开见到 |
| 词典（若做） | 显示已链接 |
| 播放 | 有媒体时可播放当前句 |

## 常见问题与处理

1. **页面是「未开放」占位** → 当前构建关掉了标注 flag；无法按本页操作。
2. **列表空** → 先在转写台造句段并写正文。
3. **词素切分失败** → 形式里加入 `-` 或 `=` 再点「按 -/= 分词素」。
4. **保存失败** → 读「保存失败：…」；可重试或刷新。
5. **多词表达** → 需选**连续**的词；有未保存格子时先保存（「先保存正在编辑的格子…」）。
6. **与 FLEx Morph 的差异** → 解语提供 IGT 工作台与词素/关系控件；不要假设完整 FieldWorks 分析器已内置。
