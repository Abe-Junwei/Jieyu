# 词典

词典工作台（侧栏 **词典**，路由 `/lexicon`）收录**当前项目**里的词条与义项，并与标注中的词典链接、转写命中互相跳转。

## 目标

学会：

**打开有项目的词典 → 搜索或新建词条 → 编辑义项/词形 →（可选）导入/导出 LIFT 或导出 DMLex → 从「转写命中」跳回转写。**

## 适用场景

- 田野中随手收词、补义项。
- 与 FLEx 等工具用 **LIFT 0.13** 交换词表。
- 导出 **DMLex** JSON 做下游处理。

## 前置条件

1. 已打开一个项目。否则会看到：「先打开一个项目。词典只显示这一份项目的词条。」
2. 从侧栏进入 **词典**。
3. **附件**（图片/音频/文档）：功能开关 `lexiconAttachmentsEnabled` **默认关闭**。默认构建里看不到附件区时，不要当作故障；开启方式属开发/构建配置，本站不写操作步骤。

## 界面定位

| 元素 | 文案 |
| --- | --- |
| 标题 | 词典工作台 |
| 搜索 | 「按词元、释义或语言筛选词条」 |
| 列表 | 词条列表；「当前结果 {count} 条」 |
| 详情 | 词条详情 / 词条概览 / 义项 / 词形 / 备注 |
| 新建 | 新建词条（词头必填） |
| 交换 | 导出 DMLex、导出 LIFT、导入 LIFT |
| 命中 | 转写命中；「在转写页打开此命中」 |
| 快捷 | 打开正字法管理器 |

字段示例：语言、引文形式、词条类型、发音、词源、字面意义、概要定义、语素类型、使用次数、最近更新等。

## 逐步操作

### 1. 打开并确认项目

1. 侧栏 **词典**。
2. 若提示先打开项目，回首页或转写台选好项目再来。

### 2. 搜索与浏览

1. 在搜索框按词元、释义或语言筛选。
2. 左侧点选词条，右侧看 **词条概览**、**义项**、**词形**、**备注**。
3. 空列表文案：「当前词典里还没有词条；后续可从导入、标注回链或人工创建补齐。」

### 3. 新建词条

1. 点 **新建词条**。
2. 填写 **词头**（必填；缺则「词头必填。」）。
3. 按需填其它字段与义项后保存；新词条应出现在左侧列表。

### 4. 编辑已有词条

1. 选中词条 → 进入编辑（界面「编辑词条」）。
2. 改义项、词形、备注等后保存。
3. 引用失效时可能看到「引用已失效」；可 **删除引用**。

### 5. 转写命中回链

1. 打开词条的 **转写命中**。
2. 加载后列出关联的 token/morpheme；空则「当前库中暂无与该词条关联的转写 token/morpheme。」
3. 点 **在转写页打开此命中** 跳到对应句段。

### 6. 导入 LIFT

1. 点 **导入 LIFT**，选择文件。
2. 仅支持 **LIFT 0.13**。不支持时提示「只支持 LIFT 0.13。」
3. 空文件 / 无法读取会有对应提示。
4. 部分 LIFT 内容可能进不了 DMLex 字段；界面会汇总未映射类型（额外词头、语素类型、注释、逆序等）。

### 7. 导出

1. **导出 DMLex**：下载项目词条的 DMLex 表示。
2. **导出 LIFT**：生成 LIFT；若有 XML 净化提示，按界面说明阅读。

## 结果核对

| 核对项 | 期望 |
| --- | --- |
| 项目门禁 | 有项目时能见列表或空列表，而不是「先打开项目」挡死操作后无说明 |
| 新建 | 词头保存后出现在列表 |
| 搜索 | 关键字能筛到刚建词条 |
| LIFT 导入 | 词条数增加或给出明确失败原因 |
| 命中 | 已在标注里链接过的词能列出命中 |

## 常见问题与处理

1. **没有附件区** → 默认 flag 关闭，属预期。
2. **LIFT 版本不对** → 先在外部工具导出 0.13。
3. **导入后缺字段** → 读未映射诊断；不是静默丢光。
4. **想从标注建词** → 在 [标注与 IGT](/annotation) 用「链接词条」；也可在本页手工新建再链。
