# 语料库

语料库页（侧栏 **语料库**，路由 `/corpus`）提供**只读**浏览与**临时工作集**（界面徽章：「临时工作集（不保存）」）：筛选句段、多选、复制到剪贴板或下载打包。**默认不写回转写**。

> 功能开关：`corpusLibraryPageEnabled` 默认开启。关掉时显示「语料库未开放」占位。

## 目标

**打开语料库 → 筛选句段 → 加入工作集 → 复制纯文本/Markdown/HTML 或下载工作集打包 →（可选）在转写中打开某句。**

## 适用场景

- 为报告、讲义临时摘一批句子。
- 把选中句段交给外部编辑器，而不改项目内转写。
- 不适合：永久语料库归档、档案级建档（见 [导入导出与备份](/export) 占位节）。

## 前置条件

1. 项目中已有可浏览的转写记录。否则：「还没有可浏览的转写记录。请先打开转写工作台。」
2. 理解工作集是**会话级临时**的，刷新或离开后不要假设还在。

## 界面定位

| 元素 | 文案 |
| --- | --- |
| 标题 | 语料库 |
| 侧栏 | 当前范围；「{count} 条句段」；「已选 {count} 条」 |
| 筛选 | 「筛选句段」；占位「按文本或媒体筛选」 |
| 选择 | 「加入工作集」 |
| 跳转 | 「在转写中打开」 |
| 导出动作 | 复制纯文本、复制 Markdown、复制 HTML、下载工作集打包 |

## 逐步操作

### 1. 进入并确认范围

1. 侧栏点 **语料库**。
2. 等待「正在载入语料范围」结束；失败时读「无法载入语料范围。」

### 2. 筛选

1. 在筛选框按文本或媒体缩小范围。
2. 无结果：「没有符合筛选的句段。」

### 3. 建立临时工作集

1. 对目标句段点 **加入工作集**。
2. 侧栏「已选 {count} 条」应增加。

### 4. 复制或下载

1. **复制纯文本** / **复制 Markdown** / **复制 HTML** → 成功时「已复制到剪贴板」。
2. **下载工作集打包** → 成功时「已下载工作集打包」。
3. 未选句段：「请先在工作集中选择句段（CORPUS_EXPORT_EMPTY）。」
4. 过大：「工作集过大，无法导出（CORPUS_EXPORT_TOO_LONG）。」
5. 剪贴板不可用：「无法复制到剪贴板（CORPUS_EXPORT_CLIPBOARD_UNAVAILABLE）。」

### 5. 回到转写改内容

需要改正文或时间码时，点 **在转写中打开**，不要在语料库页找编辑器。

## 结果核对

| 核对项 | 期望 |
| --- | --- |
| 能看见句段列表或明确空状态 | 是 |
| 工作集计数 | 与加入次数一致 |
| 复制/下载 | 成功提示，或带错误码的失败提示 |
| 转写未被悄悄改写 | 回到转写台内容与导出前一致 |

## 常见问题与处理

1. **工作集丢了** → 设计为不保存；需要持久化请用项目备份或外部文件。
2. **想要 Word 直出** → 当前动作为纯文本/Markdown/HTML/打包；以界面按钮为准。
3. **智能体分析** → 「规划覆盖」里提到的智能体辅助属后续能力；本页只保证列表与工作集出站。
