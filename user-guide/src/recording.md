# 录音与转写

在**转写工作区**（侧栏「转写」，路由 `/transcription`）处理当前项目里的媒体：导入音视频、在时间轴上切句段、写转写，以及在支持音频的**翻译层**上做口译录音。

## 目标

学会日常循环：

**打开项目 → 导入或更换媒体 → 自动/手动切段 → 编辑转写 → 播放核对 →（可选）翻译层录音 → 用首页进度抽查。**

## 适用场景

- 田野回来后把录音挂进项目并切段转写。
- 已有 EAF/TextGrid 等标注要导入时，媒体与标注入口要分开（见下文「导入标注」）。
- 需要给某一句录口译音频（翻译层麦克风）。

本页不展开 Morph 行际细操（见 [标注与 IGT](/annotation)），也不展开档案建档流程（见 [导入导出与备份](/export) 中的占位节）。

## 前置条件

1. 已按 [快速开始](/getting-started) 建好项目，或首页已有可打开的项目。
2. 手头有支持格式的文件：**MP4、MP3、WAV、WebM、MOV、MKV、OGG、M4A、FLAC**（对话框文案「支持 MP4、MP3、WAV、WebM、MOV、MKV、OGG、M4A、FLAC」）。
3. 了解硬限制（`waveformDecodeGuard`）：
   - 文件约 **> 512 MiB**，或时长约 **> 3 小时**：可能**取消导入**或**跳过波形**（提示类似「这条录音太长…已跳过波形，文字时间轴仍可编辑」）。
   - 若上次解码该媒体时崩溃，下次可能直接跳过波形以免再次崩溃。
4. 若要做翻译层录音：系统/浏览器允许麦克风；目标层须为 **audio / mixed** 模态，或勾了接受音频（`acceptsAudio`）。否则会提示「当前层不支持录音…」。

## 逐步操作

### 1. 打开项目与转写台

1. 首页找到项目 → **打开项目** / **进入转写**，或打开某一条声文稿。
2. 或在转写台打开 **项目中心**，在「所有项目」里切换。
3. 确认当前项目名称正确。无项目时导入会要求先创建项目。

### 2. 导入或更换媒体

1. 点 **导入媒体** → 在「导入音视频」中选择文件 → **确认导入**（进行中有进度文案）。
2. **导入方式**（已有可选中媒体时）：
   - **覆盖当前所选媒体**：保持同一媒体 ID，句段仍绑在这条上。
   - **新增一条媒体轨**：新建媒体行；旧句段仍挂旧媒体，需自行切换后再对齐。
3. **时长不一致**：阅读对话框说明（扩展逻辑轴、超出部分可能无法与播放对齐、首次绑定按比例压缩等），确认后再导入。
4. **内容校验**：重新挂接时若 SHA-256 与原录音不一致，会询问是否仍挂接；取消则提示已取消重新挂接。
5. **多条占位轴**：先点选目标轴再导入。

导入成功后应能播放。若提示「已导入，但逻辑时间轴调整未完成」或「未挂到录音上的语段没能挂接」：**不要重复导入同一文件**，先检查时间轴与所选媒体。

#### 删除媒体字节（危险）

工具栏 **删除当前媒体** 会删除录音字节；句段、时间码与转写可保留，录音标为「缺失」并可再挂接。界面会强调删除字节不可撤销——操作前读确认文案。

### 3. 切分句段

#### 3.1 一键 VAD 自动分段

1. 媒体可播放后点 **一键 VAD 自动分段**。
2. 结束后应提示新建句段数量；时间轴出现区间。
3. 失败时会出现「VAD 分段失败」——改用手动建段，并检查文件是否损坏。

**默认分段参数（代码 `DEFAULT_VAD_SEGMENTATION_PARAMS`）：**

| 参数 | 默认值 | 含义（简述） |
| --- | --- | --- |
| 最短段 | 0.3 s | 更短的语音峰多被当作噪声丢掉 |
| 最长段 | 30 s | 过长语音会在内部再切刀 |
| 合并间隙 | 0.3 s | 间隔小于此的相邻语音倾向并成一段 |

这些不是设置页里的用户旋钮；结果不满意请用手动拆合或批量操作微调。

#### 3.2 手动建段与改边界

1. **拖选 / 套索建段：** 在波形或时间轴空白处拖出范围后松开。
2. **拆分：** 播放头在句段内 → **从当前位置拆分句段** / **拆分句段**（太靠边会失败并提示）。默认快捷键：**Mod+Shift+S**（波形区）。
3. **合并：** **合并** / **向前合并** / **向后合并**；快捷键默认 **Mod+M**（向后）、**Mod+Shift+M**（向前）。
4. **删除：** 单段或多段删除；有正文时常二次确认。可用 **撤销**（默认 Mod+Z）。
5. **标记句段：** 波形区默认 **Enter**。
6. **批量操作：** **Cmd/Ctrl+Shift+B** 打开批量面板（时间偏移、缩放、正则拆分、批量合并等）。

#### 3.3 低置信度跳转（若有）

工具栏可能显示低置信度角标；默认 **]** / **[** 跳到下一/上一个低置信度句段（见快捷键表）。

### 4. 写转写正文与层

1. 选中句段，在**转写层**输入对象语言文本。
2. 可用波形工具条调节该段播放速度后听改。
3. **翻译层 / 笔记层**：可另建层；导入已有标注时会选层角色——不要与「导入媒体」混淆。
4. **视图：**
   - **多轨时间轴**：横向时间编辑。
   - **双列对照**：按组向下浏览；若提示需要翻译层，先建翻译层再切换。

### 5. 翻译层麦克风录音（口译）

适用于「这句话要录一条口译音频」而不是录整场田野主录音。

1. 选中句段，切到支持音频的**翻译层**（或 mixed / acceptsAudio）。
2. 点句段相关控件上的 **开始录音翻译**（录音中为「录音中」；可用 **停止录音翻译**）。
3. 录完可 **播放录音翻译** / **暂停**；不要时用 **删除录音翻译**。
4. 启动失败常见提示：
   - 麦克风权限被拒
   - 未找到麦克风
   - 麦克风被占用
   - 通用「无法启动录音，请检查麦克风权限与设备」

应用使用浏览器 `MediaRecorder`，优先 **audio/webm;codecs=opus**，其次 webm / mp4。这不是外接调音台电平表：请在系统里先确认输入设备与音量（可对照 Audacity 习惯：录前听一下、避免削波）。

### 6. 播放与导航（波形区焦点）

默认快捷键（可在 **设置 → 快捷键** 改；完整表见 [设置与快捷键](/settings)）：

| 动作 | 默认 |
| --- | --- |
| 播放/暂停 | Space |
| 上一/下一句段 | ← / → |
| Tab 播放下一/上一 | Tab / Shift+Tab |
| 后退/前进一帧 | , / . |
| 全选 | Mod+A |
| 选到开头/结尾 | Shift+Home / Shift+End |

设置 → **播放** 还可改：默认播放速度、自动跟随选中语段、吸附到零交叉、默认缩放模式、视频布局、波形双击行为（缩放到选区 / 按双击区间创建语段）等。

### 7. 导入已有标注（不要走「导入媒体」）

- **导入标注文件（EAF/TextGrid/TRS/FLEx/Toolbox）**：项目中心或交换菜单的「导入标注」入口。
- **导入项目或备份（.jyt / .jym / .jyb）**：必须走「导入项目」，不能走「导入标注」（否则会提示项目包不能通过导入标注导入）。
- 格式清单与备份策略见 [导入导出与备份](/export)。

### 8. 首页进度抽查

回到首页查看转写进度（非空语段占比）与音频时长汇总。不准时在转写台点 **刷新数据**。

进度说明（首页文案摘要）：转写 = 非空语段占比；翻译 = 译层已有译文的句子占比；标注 = 转写层上 glossed/verified 语段占已有正文语段比。

## 结果核对

| 核对项 | 期望 |
| --- | --- |
| 当前项目 | 项目中心/顶栏名称正确 |
| 媒体 | 能播放；或明确为「缺失」待挂接 |
| 句段 | 时间范围合理；VAD 后可用拆合修 |
| 转写 | 至少一个句段转写层非空 |
| 播放对齐 | 点选句段听到的内容与文本大致对应 |
| 层录音（若做） | 状态为「已录音」，可回放 |
| 未误操作 | 未在未读时长说明时覆盖错媒体；未对超大文件反复导入 |

## 常见问题与处理

1. **未建项目就导入** → 先 **新建项目**。
2. **选错覆盖/新增轨** → 换同一录音新版本用覆盖；新材料用新增轨。
3. **占位轴未选中** → 先点轴再导入。
4. **导入失败后连点确认** → 若已提示后续步骤出错，先检查现状，避免双轨混乱。
5. **格式不支持或损坏** → 「请选择音视频文件（MP4、MP3、WAV、WebM 等）」或无法读取时长；换格式。
6. **波形被跳过** → 文件太大/太长或曾崩溃；文字时间轴仍可编辑，可外切短再导入。
7. **逻辑轴长于可播时长** → 超出区间可能无法与播放对齐；以界面状态为准。
8. **VAD 不可用** → 改用手动拖选与拆分。
9. **翻译层无法录音** → 检查层模态与麦克风权限。
10. **双列对照灰掉** → 可能需要先有翻译层（见工具栏提示「verticalViewRequiresTranslationLayer」类文案）。
