# 录音与转写

在转写工作区处理**当前项目**里的一条（或多条）媒体：导入音视频、在时间轴上切出句段、写下转写文本。语段的时间范围和转写正文属于这条录音，改完后仍留在同一本地项目，供后面的标注与词典使用。

## 目标

学会在转写工作区完成日常循环：

**打开项目 → 导入或更换媒体 → 自动或手动切段 → 编辑转写 → 用播放与进度核对。**

本页不写 Morph / B4 行际标注步骤（见 [标注与 IGT](/annotation) 占位说明），也不写解冻后的建档导出（见 [导出与建档](/export)）。

## 前置条件

1. 已按 [快速开始](/getting-started) 建好项目，或首页里已有可打开的项目。
2. 手头有支持格式的音视频文件（对话框文案：MP4、MP3、WAV、WebM、MOV、MKV、OGG、M4A、FLAC 等）。
3. 进入**转写工作区**（路径一般为 `/transcription`；也可从首页「进入转写」或「打开该声文稿」进入并定位到对应媒体）。

## 逐步操作

### 1. 打开项目与转写台

1. 在工作台首页找到项目，点 **打开项目** / **进入转写**，或打开某一条声文稿。
2. 也可在转写台侧栏打开 **项目中心**（「打开项目中心」），在「所有项目」里切换。
3. 确认顶栏或项目中心显示的**当前项目**名称正确。没有项目时，导入会提示「请先创建项目」。

### 2. 导入媒体

1. 点工具栏 **导入媒体**（空状态也可能显示「导入媒体文件」或「请导入媒体或文本文件开始工作」）。
2. 在「导入音视频」对话框中 **点击选择音视频文件**，选好后点 **确认导入**（导入中会显示进度文案）。
3. **导入方式**（项目里已有可选中的媒体时）：
   - **覆盖当前所选媒体**：语段仍绑定同一媒体 ID，适合替换为同一录音的更新版本。
   - **新增一条媒体轨**：新建独立媒体行；原时间线上的语段仍挂在原先所选媒体上，需要你自行切换媒体后再对齐。
4. **时长不一致**：若文件时长与当前逻辑轴或已有语段范围不一致，对话框会说明影响（例如扩展逻辑轴、超出部分可能无法与播放对齐、首次绑定按比例压缩等）。勾选「我已了解，继续导入」一类确认后再导入。
5. **多条占位轴**：若提示请先在时间轴上选中要挂接音频的那一条，先点选目标占位轴，再导入。

导入成功后应能播放波形，并看到成功提示。若提示「已导入，但逻辑时间轴调整未完成」或「未挂到录音上的语段没能挂接」，**不要重复导入同一文件**，先检查时间轴与所选媒体。

### 3. 切分句段

#### 3.1 一键 VAD 自动分段

1. 媒体可播放后，点工具栏 **一键 VAD 自动分段**。
2. 运行中按钮会变为「自动分段运行中…」。
3. 结束后应提示新建了若干句段；时间轴上出现对应区间。

VAD 依赖可分析的媒体。若失败，界面会提示「VAD 分段失败」——改用手动建段或检查文件是否损坏。

#### 3.2 手动建段与改边界

1. **拖选 / 套索建段：** 在波形或时间轴空白处拖出一段时间范围，松开后生成句段（创建预览时可能出现套索提示）。
2. **拆分：** 播放头停在句段内部后，用浮层菜单 **从当前位置拆分句段** / **拆分句段**（拆分点太靠近边界时会失败并提示）。
3. **合并：** 选中相邻（或按批量规则允许的）多个句段后，使用 **合并** / **向前合并** / **向后合并**；不满足条件时会提示先选择相邻句段等。
4. **删除：** 对单个或多个句段执行删除；有正文时通常会二次确认。可用撤销恢复（以当前版本撤销栈为准）。
5. **批量操作（进阶）：** 快捷键 **Cmd/Ctrl + Shift + B** 可打开「批量句段操作」面板（时间偏移、缩放、正则拆分、批量合并等）。入门阶段可先跳过。

### 4. 写转写正文

1. 在时间轴或列表中选中目标句段。
2. 在**转写层**编辑区输入对象语言文本。
3. 需要时用波形工具条调节该段播放速度，听完再改字。
4. 翻译层、笔记层的角色与导入标注文件时的层角色选择，属于进阶；本页只要求转写层有正文。

从 EAF / TextGrid / TRS / FLEx / Toolbox 等**导入已有标注**走项目中心的「导入标注文件」，不要和「导入媒体」混淆；项目包（`.jyt` / `.jym`）要用「导入项目」，不能走「导入标注」。

### 5. 用首页进度做抽查（可选）

回到工作台首页，查看该项目的转写进度（非空语段占比）与音频时长汇总。数字是快照统计，导入或大改后若暂时不准，可点首页 **刷新数据**。

## 结果核对

| 核对项 | 期望 |
| --- | --- |
| 当前项目 | 项目中心 / 顶栏显示的名称是你要做的那一次田野 |
| 媒体 | 能播放；文件名出现在媒体相关 UI 中 |
| 句段 | 时间轴上有区间；起止时间合理 |
| 转写 | 至少一个句段转写层非空 |
| 播放对齐 | 点选句段播放时，听到的内容与文本大致对应 |
| 未误操作 | 没有在「时长不一致」对话框未读说明时强行覆盖错媒体 |

## 常见坑

1. **未建项目就导入。** 会提示先创建项目。
2. **选错导入方式。** 「新增媒体轨」不会自动把旧语段挂到新文件上；「覆盖」才保持同一媒体 ID。换的是同一条录音的新版本时优先考虑覆盖。
3. **占位轴未选中。** 多条占位时间轴时必须先选中再导入。
4. **导入失败后重复点确认。** 若已提示「已导入但后续步骤出错」或时间轴调整未完成，先检查现状，避免同一文件导入两次造成双轨混乱。
5. **格式不支持或文件损坏。** 对话框会提示无效媒体、无法读取时长或无法解析；换格式或重导文件。
6. **自动分段不可用时。** 个别环境下可能提示自动切分尚不可用——改用手动拖选建段与拆分。
7. **逻辑时间轴与可播时长。** 语段结束晚于媒体可播时长时，超出区间可能无法与播放对齐；以界面状态提示为准。
8. **协作与导出。** 同步冲突说明见 [协作与同步冲突](/collaboration)（占位）。档案级建档导出仍受存储冻结影响，见 [导出与建档](/export)，本页不展开。
