# 协作与同步冲突

::: warning 占位
冲突处理步骤还没有写。协作方案跟踪 [GitHub #342](https://github.com/Abe-Junwei/Jieyu/issues/342)（草案：Loro CRDT 同步包先行，自建小服务后置）。
:::

需要和别人一起改同一个项目时，同步的是按项目裁剪的变更，不是把整台电脑上的库拷走。两端改了同一处时会出现冲突，必须先处理完，项目才和远端一致。

#342 还是草案。冲突界面、保留哪一侧、以及怎样确认已经同步，都等该问题落地后再补。在此之前，把未处理的冲突留在待处理，不要把它当成已经同步完成。
