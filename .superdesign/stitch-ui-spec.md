## 排版、尺寸和布局

- UI：Inter / Noto Sans SC / 系统回退；IPA：Charis SIL；时间码：JetBrains Mono，等宽数字。
- 正文14/22；密集信息12/18；工具栏13/20；区标题16/24；页标题20/28。字重400/500/600。
- 4px间距基准：4、8、12、16、24、32；分组内部8-12，区域内部16，章节24。
- 导航52；上下文240-320；检查器280-360；中央自适应。1280宽优先收起可选检查器，不遮挡编辑区。
- 标准控件32高，紧凑28，重要入口36。图标16/20；图标按钮32见方，紧凑28。
- 面板方角；控件6；菜单8；模态10。工作面无投影，浮层轻阴影，模态配遮罩。
- 分隔线1px；分栏拖拽命中宽6px。容器边框最多两层，表单边框和临时焦点轮廓不计作容器。
- 高度为默认字号下的最小值；字号放大后控件、行高随内容增长，不用固定高度裁切文本。桌面点击目标至少24×24，常用图标目标32×32。

### 暗色模式与字号适配（规范提案，未另出暗色画板）

暗色保持相同层级和组件，不简单反相。建议工作背景#181B21、面板#20242C、标题#272C35、浮层#2E3440、正文#F2F4F8、次文字#B4BDCC、常规分隔#465061；主按钮继续使用#7658F6白字，选中行用深紫底加浅色文字，实施前逐组合检查对比度。波形/播放头/选区必须重新配对验证，媒体内容不反色。图标随语义文字色，功能色保持意义但明度单独适配。多语种和放大字号下优先收起次级检查器，不隐藏核心编辑或错误信息。

## 组件交互规范

| 组件 | 规格与行为 |
|---|---|
| 按钮 | 主/次/文字/危险四类；每任务区最多一个主操作；默认/悬停/按下/焦点/禁用/加载必须齐全；加载保留尺寸 |
| 输入 | 常驻标签；placeholder仅为例子；错误在字段下并给出可修正原因；不能只变红 |
| 选择控件 | 原生语义优先；长列表用可搜索combobox；多选清楚显示已选数量与清除入口 |
| checkbox/radio/switch | 多项选择/互斥选择/即时开关分别使用，不相互替代 |
| 搜索 | 标明搜索范围；清除按钮；无结果区别于空数据；筛选条件可查看/移除 |
| 列表/树 | 32px密集/40px普通行；悬停浅灰；选中浅紫+3px侧标；树不无限嵌套，深层进入详情 |
| 表格 | 文字左对齐，数值右对齐，时间等宽；排序、选中、批量工具栏分开；截断可查看完整值 |
| 标签页 | 同一上下文的视图切换；当前项用下划线/文字权重，不能只有颜色；不代替任务按钮 |
| tooltip | 补充短说明与快捷键；不承载唯一操作入口；键盘可触发 |
| popover/menu | 邻近触发器、避开边缘；Esc关闭；关闭后焦点回到触发器；危险项有明确文案 |
| modal | 适用于阻断任务或危险确认；保存失败保留输入；取消不提交；明确关闭及焦点归还 |
| drawer/inspector | 展示当前对象属性与检查，不丢失中央选择；可收起；不得挡住主编辑内容 |
| AI聊天 | 独立于声学检查器；上下文、处理中、可取消、失败重试和修改审核要清楚；不能冒充已保存或已确认 |

## 转写与标注专用元素

- 时间轴：时间尺、播放头、选区、循环区、轨道标签、吸附引导各有独立视觉编码；播放头不能只靠颜色。
- 波形：深灰波形、浅紫选区、清楚边界；显示合成演示标记，不伪造声学读数。
- 控制：播放/暂停、前后跳转、倍速、缩放、定位、吸附；图标有工具提示与快捷键说明。
- 语段：整行选中；编辑焦点与选中分开；原文/翻译/词/词素/gloss用行标签和对齐建立层次。
- IGT：词素对齐、断词、gloss缩写与自由译文使用平面行网格；不把每个词或字段包装成卡片。
- 来源、说话人、语言、层名用明确标签；AI建议/人工确认/未检查不得混同。

## 次级功能面与通用模式覆盖

以下均复用已有规范，不应各自发明一套外观；主画板不等于所有弹窗均已逐一绘制。

| 实际功能面 | 统一设计模式 | 需覆盖的差异 |
|---|---|---|
| 项目创建/媒体导入 | 有步骤标题的表单模态 | 选择、处理中、失败、取消、格式/层不匹配确认 |
| 文稿/层管理 | 树列表+上下文菜单+编辑表单 | 当前层、可见/隐藏、只读、删除影响 |
| 说话人管理 | 列表-详情/小型编辑模态 | 未分配、已关联、重命名与引用范围 |
| 批量操作 | 选中计数+上下文工具栏/确认模态 | 范围、变更预览、进度、部分失败 |
| 搜索替换 | 非模态叠层 | 搜索范围、命中导航、替换一项/全部、无结果 |
| 撤销历史 | 紧凑操作列表popover | 当前点、可撤销项、不可逆边界 |
| 笔记与备注 | 常驻标签textarea/非模态笔记面板 | 空、编辑、保存中、失败保留输入 |
| PDF查看/附件 | 独立内容面+小型工具栏 | 页码、缩放、加载/文件不可用 |
| 视频播放器 | 媒体面+传输工具栏 | 比例、全屏、媒体不可用、时间同步 |
| 语音助手 | 独立小型控制浮层 | 未启用/监听/处理中/失败；明确麦克风状态 |
| 快捷键面板 | 按功能分组的键值表 | 搜索、平台修饰键、冲突说明 |
| 数据迁移/完整性阻断 | 高优先级阻断层 | 原因、可恢复操作、导出/恢复边界，不虚构成功 |
| 恢复/备份/离线提示 | 页面顶部语义条/任务级反馈 | 可关闭与不可关闭、具体范围与下一步 |
| AI修改与采用队列 | 差异预览+审核操作 | 拟修改/已采纳/失败/拒绝/回滚的不同状态 |
| 标注关系/替代分析 | 对齐文本+关系列表/图视图 | 当前分析、候选差异、关系方向、来源，不用颜色暗示候选已获确认 |
| 音标/语言/脚本选择 | 可检索选择器+字符网格 | IPA字体、完整名称与代码、键盘焦点，不用旗帜代替语言 |
| 受限分析/不可用能力 | 简洁可用性说明 | 解释限制、有效返回入口，不绘制假业务数据 |

## 状态矩阵与反馈（细则）

| 状态 | UI要求 |
|---|---|
| 初始空 | 说明缺什么、一个可执行入口，避免虚构示例统计 |
| 无结果 | 保留查询和过滤条件，提供清除入口 |
| 加载 | 保持布局，局部进度；不可预先显示成功 |
| 未保存/保存中 | 当前对象级别明确标识，不混同全项目状态 |
| 保存失败 | 保留输入、原因和重试；不能给绿色成功反馈 |
| 只读 | 说明原因，禁用写操作，保留复制/查看 |
| 媒体丢失 | 指明媒体不可用与可用恢复操作，不清空转写文本 |
| 离线/恢复 | 区分网络能力与本地编辑；恢复提示不能保证未经验证的数据安全 |
| AI待审核 | 明确拟修改范围、确认/拒绝；已采纳与已持久化分开 |
| 删除 | 说明对象和关联影响；可撤销才提供撤销，不虚构回收站 |

## 键盘、国际化与动效

- focus-visible：2px清晰轮廓+2px偏移，不能依赖阴影；键盘顺序遵循视线阅读顺序。
- 模态打开时焦点进入模态，Tab/Shift+Tab保持在模态内；关闭后归还触发器或下一合理任务位置；危险确认初始焦点优先取消。
- 列表方向键、Enter激活、Esc返回/关闭；复杂网格的键盘行为以实际组件为准，不能只画快捷键。
- 中文、英文、IPA与RTL的文本方向逐区设置；时间码不随RTL反转；布局避免长字符串遮挡。
- 动效100ms即时、200ms常规、300ms浮层上限；reduced-motion关闭位移；持续任务使用进度反馈。
