# 解语 UI 工程规范补全 · 评审版

日期：2026-10-24。范围：设计规则与验收标准，不修改产品逻辑。
本补充优先于旧Stitch手册中的冲突值；基础文档为 stitch-ui-spec.md。
以下尺寸、层级、事件规则是设计决定或建议，不是对当前运行代码的完成声明。

| --surface-header | #F6F7F9 | 局部标题/工具条 |
| --surface-elevated / --surface-overlay | #FFFFFF | 非模态浮层/模态主体 |

功能状态复用 --state-success/warning/danger/info-*，不新增status-*平行体系。
建议功能色：success文字#15803D/底#F0FDF4；warning文字#92400E/底#FFFBEB；danger文字#B91C1C/底#FEF2F2；info文字#1D4ED8/底#EFF6FF。须逐组合验证，不据此宣称全屏达标。

主按钮默认#7658F6，hover#6444E4，pressed#5335D2；禁用通过中性底/文字与disabled语义表达，不单独整体opacity使文字不可读。
选中/hover/焦点分别是持久选择、临时指针反馈和键盘定位，不能合并。

## 2. 字体、控件与组件对应

| 对象 | 默认规格 | 代码对应/约束 |
|---|---|---|
| 正文 | 14px/22px，400 | Inter + Noto Sans SC |
| 密集正文 | 12px/18px | 不用于压缩大段阅读文本 |
| 工具栏 | 13px/20px，500 | 标签与图标对齐 |
| 区/页标题 | 16/24、20/28，600 | 不以超大标题挤占编辑面 |
| IPA | Charis SIL，14/22起 | 组合符号不能被固定行高裁切 |
| 时间码 | JetBrains Mono | 等宽数字、独立LTR、显示精度由任务决定 |
| 按钮 | default32；sm28；compact28 | PanelButton现有size名，实施时映射CSS而非新增组件 |
| 重要任务入口 | 36px最小高 | 场景规格，不擅自新增PanelButton API |
| 按钮变体 | default/primary/ghost/danger/success | success仅在语义适用时保留，不代表操作已经成功 |
| 字段 | 常驻label，hint/error尾部 | FormField；error优先于hint，重要操作说明不随hint消失 |
| 弹窗 | 主体圆角10、控件6 | ModalPanel / DialogShell / DialogOverlay |
| 草稿输入 | dirty/saving/error | TimelineDraftEditorSurface；undefined不能被翻译为已验证保存 |
| 时间轴输入手势 | 编辑器内部处理 | TimelineLaneDraftEditorCell，避免点击编辑同时启动外层拖选 |

面板方角；菜单8；输入6；图标16/20；间距4/8/12/16/24/32。
尺寸是默认字号下的min-height；字号放大可增长，不能使用固定高度截字。
可操作目标至少24×24；常用图标按钮32×32；极细拖拽边界另有命中区与替代输入。
基础组件缺变体时先扩展既有组件；禁止重新建立一套Button/Input/Dialog平行库。

### 控件状态实现表

| 类型 | 默认/悬停/按下 | 焦点/错误/禁用/加载 |
|---|---|---|
| primary | #7658F6 / #6444E4 / #5335D2，白字 | 焦点2px强调轮廓offset2；禁用中性底/文案；加载保留标签与宽度 |
| default | 白底 / #EDF0F4 / #E1E6ED，主文案 | 不只改变文字色来表现按下；焦点轮廓与边框分离 |
| ghost | 透明 / #EDF0F4 / #E1E6ED | 无框仍需清楚标签、焦点；禁用无hover操作暗示 |
| danger | 危险文案+危险边界/浅红hover/更深危险色pressed | 与取消并置；危险动作不默认聚焦；执行中防重复 |
| 字段 | 白底+控件边界 / 更强边界 / 不另造pressed | focus强调轮廓；error危险边界+错误文本；error+focus同时保留 |
| 列表行 | 透明 / #F6F7F9 / #E1E6ED | selected浅紫+侧标；focus轮廓；disabled解释不可用原因 |
| checkbox/radio/switch | 未选/已选及明确图标或位置 | keyboard焦点围绕控件；mixed与checked区分；开关异步失败恢复实际值 |

结构分隔#CBD2DC不等于控件识别边界。若输入框/按钮仅靠描边才能识别，边界使用控件专用#7F8A9B（实施映射至独立语义变量，不覆盖全部结构线）。与白底对比3.494:1，与#EDF0F4对比3.056:1。
主按钮hover/pressed对白字分别6.019:1、7.480:1。计算仅针对指定纯色组合，透明/混色/实际截图须另验。
表单标签12/18、500字重，输入正文14/22，提示/错误12/18，控件与尾文间4px，字段组间16px。必要业务说明不能在报错后消失。
PanelSection对应无新增卡壳的标题/内容分组；PanelFeedback对应任务级反馈；PanelNote对应说明；PanelChip只承载短元信息/状态；PanelSummary对应确认摘要，均不能自行升级成额外主操作区。

## 3. 工作区与窗口

| 条件 | 分栏规则 | 滚动/浮层 |
|---|---|---|
| 1440×1000参考 | 轨52；上下文272；检查器默认300、可在280-360调节；中央余宽 | 各栏独立纵滚，局部工具栏保持可见 |
| 1280宽 | 优先收起检查器，再允许上下文栏收起 | 不把中央工作区变手机卡片 |
| 中央不足建议640 | 显示收起入口；仍不足则横向滚动 | 不用scale缩小全部文字，640是设计参考非现有工程下限 |
| 200%字号 | 减少同时展示的次级栏，工具栏有标注的溢出菜单 | 关键错误、保存状态与退出编辑入口不可被裁掉 |
| 超长IGT/宽表 | 保留语言/层标签的上下文，内容横滚 | 时间尺与轨道横滚保持一致 |

分栏显示1px分隔，6px拖拽命中；最小宽度到达后给出边界反馈，不继续压缩到不可用。
主窗口大小与用户缩放不同，分别测试；1000高为设计参考，不是阻止矮窗口的要求。
弹层在可用视口内翻转/偏移；锚点不在可见区时关闭或重新定位，不能悬在无来源位置。
长列表虚拟化时保留选中、焦点与当前位置；加载更多不能让当前编辑行跳走。
媒体内容不反色；暗色中的波形/标记/选区单独验证。RTL按区域设置，IPA/时间码/路径不盲目整体翻转。

## 4. 层级、关闭与焦点

建议局部stacking层级：内容0、sticky10、导航20、非模态检查器30、AI窗40、菜单50、tooltip60、模态100、完整性阻断120。它们是设计顺序，不是已存在的z-index事实。
模态内部菜单与tooltip使用模态自己的portal/stacking上下文；不能被全局层级压到遮罩下。

| 层 | 主区可操作 | 关闭方式 | 焦点 |
|---|---|---|---|
| tooltip | 是 | 指针离开/焦点离开/Esc | 不抢焦点 |
| menu/popover | 视内容而定，默认非模态 | Esc/外部点击；提交型表单保护脏内容 | 关闭后回触发器 |
| 声学检查器 | 是 | 关闭按钮；是否Esc由当前焦点宿主决定 | 不全局锁焦点 |
| 独立AI窗口 | 是 | 关闭/收起；运行任务按实际可取消能力处理 | 不将Esc误当任务取消 |
| 普通modal | 否 | 关闭/取消；脏表单先确认 | Tab循环，关闭后回触发器或合理任务位置 |
| 危险确认 | 否 | 显式取消/确认；背景点击不作为确认 | 初始焦点在安全操作 |
| 完整性阻断 | 否 | 仅允许提供的恢复动作 | 不可Esc或点击背景绕过 |

关闭浮层、取消任务、放弃编辑是三个动作，文案与快捷键不能相互冒用。
多浮层叠加时Esc只由最上层可关闭对象消费；输入法候选窗口优先。

## 5. 编辑状态组合与优先级

| 维度 | 所占视觉通道 | 不得混同 |
|---|---|---|
| 当前层 | 层头名称与活动标记 | 不等于所有层内语段已选中 |
| 选中单元/多选 | 浅紫区域底+选择计数 | 不等于正在输入 |
| 当前活动语段 | 3px侧标/明确标签 | 不跟随播放头自动覆盖用户多选 |
| 输入焦点 | 2px轮廓+2px偏移 | 不用背景色单独表达 |
| 正在拖动 | 边界/旧位置淡影/时间提示 | 不是持久化完成 |
| dirty/saving/error | 保留固定状态位；失败有文案与重试 | 错误不能被选中颜色遮掉 |
| AI confidence | AI来源的分数/等级与说明 | 不等于人工确信度 |
| selfCertainty/ambiguous/skip | 人工判断角标与文字 | 不等于模型概率或系统错误 |
| 重叠计数 | 例如1/3与切换入口 | 不等于所选项总数 |

组合优先：数据丢失/写入错误的可读反馈 > 输入焦点 > 拖动预览 > 活动/选中 > hover；不同通道尽量叠加而不是只留下最高项。
必须提供选中+焦点+保存失败、当前层+多选+播放、低置信度+人工已确认三种组合图。

## 6. 时间轴操作契约

| 操作 | 过程反馈 | 完成/取消 |
|---|---|---|
| 边界拖动 | 光标类型、旧范围、新时间、时长 | 松开后提交；失败反馈并按实际回滚机制表现 |
| 整体平移 | 整体位移预览，不改变时长 | 不能在松开前画保存成功 |
| 吸附 | 目标引导线+目标时间/类型 | 明确当前开关，不偷偷改变模式 |
| 越界 | 拒绝边界与原因 | 不无提示裁切或丢失文本 |
| 重叠 | 当前项1/N，切换入口可达 | 选中项与播放对象清楚区分 |
| 极短语段 | 保留可定位标记，详情显示完整文本 | 不夸大其真实时间宽度；命中区域可扩展 |
| 缩放/横滚 | 显示比例与当前可见时间 | 保留用户选择与播放定位上下文 |
| 取消拖动 | 设计目标为恢复原范围 | 具体键/实现需结合现有handler验证，不宣称已支持Esc |

视觉手柄建议2px、命中至少8px；窄片段手柄命中冲突时用独立起止时间编辑替代精拖。
窄片段压缩顺序：先隐藏常驻次级按钮，再缩为摘要，最后仅标记+详情；不得将文字缩到8px。
选区、循环区、播放头、吸附线使用不同形状/线型/标签；区间通常显示start–end及duration，边界包含规则以领域数据契约为准。
波形/频谱/基频/强度分别标注模式、单位、范围与数据不可用，不用装饰曲线代替测量。

## 7. 输入、草稿与IGT

这些是需要由页面adapter实现/核对的设计目标，TimelineDraftEditorSurface本身不拥有保存语义。
不得用“所有单行Enter保存”覆盖现有编辑器。已读到的实际键盘契约如下，设计提示按场景显示：

| 场景 | 已读源码行为 | 设计表达 |
|---|---|---|
| 时间轴annotation输入 | useTimelineAnnotationHelpers：IME组合中返回；Tab/Enter前后导航，Shift反向；Esc失焦并回波形区 | 提示“Enter下一项 / Shift+Enter上一项”，Esc不能标成撤销草稿 |
| 标注键盘状态机 | annotationKeyboardMachine：行焦点Enter进入输入；输入Enter提交留在当前，Ctrl+Enter提交下一项；有建议时Tab可接受建议；输入内空格插入，行焦点空格播放 | 行/输入两种模式分开提示，避免同一快捷键表误导 |
| 媒体层文字草稿 | useTimelineLaneTextDraftAutosave：变化排程自动保存，失焦清理计时并按差异写入 | 保存反馈跟随真实异步结果，失焦不能视为撤销 |
| 独立AI窗口 | TranscriptionPage.ChatWindow.layout：Cmd/Ctrl+J打开/还原/最小化；打开非最小化时Esc最小化 | Esc标成最小化，不写“取消AI任务” |

上述为函数/调用链读码结论，未作此次运行验收；不同adapter仍须分别核对。多行输入的Enter/提交快捷键按实际handler标注，不能统一改写行为。
IME组合期间Enter不触发提交、导航或播放；输入焦点内快捷键不得误触全局播放/删除。
仅在页面已定义“取消未提交编辑”的场景提供该动作及恢复路径；时间轴当前Esc为失焦，不能绘制成草稿撤销。其他页面若不支持草稿撤销，也不可虚构该能力。
失焦/切换文稿/切换层：保持或提交草稿，失败保留原输入；没有已实现的缓存时必须阻止丢弃并提示。
粘贴多行不能静默只取首行；对不适用格式提示限制。空字符串与字段未填写按实际业务区别，不自动补内容。
错误状态必须可键盘重试；重试中避免重复提交；undefined saveStatus仅为未提供状态。

IGT使用词边界列和语言行网格，长词可扩展，不强制各词等宽。原文/词/词素/gloss/逐字译/自由译/多语言行标签可见。
跨词单位选中范围、替代分析当前/候选、关系方向、来源和验证问题定位独立显示；不把候选着色为已确认。
分词、删词、重分词等会影响已有gloss或关系时，在操作前展示影响范围与保留/损失规则。
语言/脚本选择器显示名称与代码，长列表搜索，IPA组合附标不裁切；不以国旗替代语言。

## 8. 导入、删除、恢复

媒体导入流程：选择→预检→（有真实不匹配时）影响说明与确认→执行→可验证结果/失败。
不匹配展示incoming媒体时长、既有逻辑跨度/最大语段终点，以及是否重映射/存在超界；确认框仅在对应业务条件要求时出现。
删除层展示层名、类型、文本数及关联影响；保留单元与一并删除不是同一个结果，确认文案随选项变化。
不可撤销操作不得出现假撤销；取消作为安全默认；处理中按实际中断能力处理关闭，不虚构可取消。
备份恢复区分载入/校验/预览影响/应用/读回结果；应用失败保持错误与恢复路径。不能把备份存在等同于恢复已成功。
数据库打开失败与完整性失败采用不同解释和恢复动作；保留代码现有可用动作，不扩大“继续会话”的适用范围。
本地编辑可用、外部AI不可用和网络断开分别表达，不生成不存在的云同步流水线。

## 9. AI、信任与修改审核

任务阶段：上下文已选择→执行中→需澄清/需人工/失败或待审核→范围与前后差异→确认→写入中→成功/失败。
采用建议、授权执行、持久化成功是不同状态；操作成功反馈必须以真实结果为依据。
上下文说明至少包含项目/文稿/层/选区范围，切换对象后旧建议显示来源与过期条件，不盲目应用。
重试与重新生成分开；目标变化后先校验；多步执行应显示部分成功/失败的对象范围，不能一条绿色提示覆盖全部。
取消与回滚按实际能力分别提供；不可用时解释，不绘制无法执行的按钮。
API key默认遮蔽，显式查看；错误日志/截图文案不回显密钥。外部服务地址、连接失败、信任状态与普通偏好设置有清晰区别。
feature flag控制的路径在设计标为条件界面；不能把存在于代码中的所有面板都标成默认可用。

## 10. 资产、附件与数据密集界面

语言元数据自定义字段：定义/填值分开；类型变更提示已有值如何处理；重排显示目标位置；删除说明定义与值影响。
正字法桥接分别呈现源、目标、对应；无匹配/多匹配/无效/待核对不混同；批量修改先表明作用范围。
词典附件展示图片预览、音频传输控件、文档下载、文件内容缺失；解除关联不等于删除原文件。
检索展示项目/文稿/语言/层/时间范围和清除入口；切换页面时是否保留检索由现有状态语义决定并标明。
批量工具栏显示已选数量、范围和可用操作；“选择当前页”与“全部匹配结果”若无相应能力，不得互相冒充。
表格列宽、冻结列、长内容查看、排序与空值需逐列规定；不能仅画一张短数据表代表所有密集场景。

## 11. 设计验收矩阵

| 组别 | 必查样例 | 通过条件 |
|---|---|---|
| 核心组件 | 按钮/字段/选择/列表/菜单/模态 | 默认hover按下焦点禁用加载错误齐全且尺寸统一 |
| 专业编辑 | 转写/IGT/声学 | 选择、输入、播放、拖动、失败等组合互不遮蔽 |
| 任务闭环 | 导入/删除/批量/恢复/AI | 入口→进行中→结果→失败恢复路径连贯 |

## 13. 终审补充：遗漏任务与适用范围

- **音频层与混合层录音**：区分未录音、录音中、已有录音、播放中、转写中、失败、不可用。另一单元正在录音时，其他录音入口解释禁用原因；停止录音、暂停播放、取消转写是不同动作。麦克风权限未请求/拒绝/设备不可用提供对应说明，不用普通网络错误替代。依据 TimelineTranslationAudioControls 与媒体层modality分支；权限完整流程须另作运行验收。
- **桌面项目生命周期（条件界面）**：打开/锁被占用/同步盘风险/备份目录失败应分别提示，不保证可强制解锁、不虚构只读打开能力。桌面骨架 openProjectFolder 返回 lock、warning、backupDir，不证明全部已接真实产品。条件状态可以有设计规格，但必须标为目标/骨架路径。
- **关闭应用/项目/对象**：窗口关闭与关闭AI窗不同；保存中应表明尚未完成；脏草稿保护按实际可恢复能力实施。不能把模态取消或Esc最小化当成数据已保存。
- **导出与交换**：明确项目/文稿/层/选区范围、格式、媒体是否包含、附件省略、正在处理、失败与输出位置。仅真实支持时提供覆盖/取消/重试；导出完成不能表示文件已由目标软件正确打开。长文件名/无写入权限/位置失效用具体原因。
- **清理与重置**：清缓存、重置偏好、删除项目、解除媒体关联分别命名。SettingsDataTab 中部分“重置”只移除偏好键，不能画成已删除全部项目数据，也不能对用户保证项目数据不受所有重置分支影响，需逐路径核对。
- **技术错误与隐私**：界面先给可执行简述，详情展开显示错误码与可复制诊断；密钥、身份资料、原文内容和完整本机路径不默认暴露于日志/示例截图。示例AI推断必须标明合成说明，不包装成真实测量结果。
- **快捷键平台与冲突**：Mac显示Cmd，其他平台Ctrl，实际组合以action registry/handler为准；输入法、文本输入、最上层浮层优先消费相应键，不发明Cmd+[、Cmd+]、Cmd+Shift+A。需为精确拖拽提供数值输入或其他已实现替代，不只依赖鼠标。
- **模式与来源**：开发期、骨架、flag条件、设计目标、默认可见功能明确区分；没有读回或运行证据的写入不能贴已保存/已同步。设计图中的示例操作不构成真实产品能力承诺。

## 14. 最终对齐约束

1. 参考画布统一为1440×1000；1280用于适配检查，不写成产品强制断点；矮窗口另验。
2. PanelButton只有default/sm/compact三种现有size；36px是场景规格，不新增hero属性。
3. FormField真实接口为label/htmlFor/hint/error/span，required提示由调用方提供；不得写不存在的isRequired属性。
4. ModalPanel真实接口包含isOpen/onClose/title/footer/closeDisabled等；没有hasDirtyForm/onDismiss/trapFocus这些公共属性。焦点trap由组件内部处理，脏内容由业务onClose保护；closeDisabled不自动禁止所有关闭路径。
5. 真正组件名为TimelineLaneDraftEditorCell；saveStatus为dirty/saving/error或undefined，不能替换为虚构的isDirty/isSaving/hasError接口。
6. 完整性阻断层与危险确认分成两类：前者不能Esc绕过，后者取消须按onClose和任务可中断性执行，不混用120硬阻断。
7. 字号不得为可阅读信息使用8-11px；正文、密集信息、时间码均遵守排版规范。图标/几何标尺的尺寸不等于文字字号。
8. 文档与状态图不写Frozen、已上线、全部达标、已核验等无验证声明。单个纯色组合的计算不等于整屏可访问性通过。
9. 功能状态沿用--state-*-text/solid/bg/border语义，不再引入无后缀的--state-success等另一体系。
10. 历史自动生成图稿只作过程记录；当前本地HTML已直接审校。Stitch精确文本节点与本文件同步后才可作为实施依据，旧图稿的冲突文案不再有效。
